## LoadOptions class

Αντιπροσωπεύει τις επιλογές φόρτωσης εγγράφου κατά τη φόρτωση ενός εγγράφου.

Μάθετε περισσότερα:
- Loading documents: https://docs.groupdocs.com/display/watermarknet/Loading+documents
- Load from local disk: https://docs.groupdocs.com/display/watermarknet/Load+from+local+disk
- Load from stream: https://docs.groupdocs.com/display/watermarknet/Load+from+stream
- Load document of specific format: https://docs.groupdocs.com/display/watermarknet/Load+document+of+specific+format
- Load password-protected document: https://docs.groupdocs.com/display/watermarknet/Load+password-protected+document

Ο τύπος LoadOptions εκθέτει τα ακόλουθα μέλη:

| [format_family](/watermark/python-net/groupdocs.watermark.options/loadoptions/format_family/) | Η οικογένεια μορφής του εγγράφου, που υποδεικνύει τον τύπο του (π.χ., Image, Pdf, Spreadsheet, κλπ.). |
| [password](/watermark/python-net/groupdocs.watermark.options/loadoptions/password/) | Ο κωδικός πρόσβασης για το άνοιγμα ενός κρυπτογραφημένου εγγράφου. |
