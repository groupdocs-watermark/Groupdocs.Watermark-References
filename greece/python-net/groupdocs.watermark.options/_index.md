Κλάσεις επιλογών που διαμορφώνουν τις λειτουργίες του API.

### Κλάσεις

| :- | :- |
| [`CreatePageStream`](/watermark/python-net/groupdocs.watermark.options/createpagestream/) | Αντιπροσωπεύει μια μέθοδο που επιστρέφει μια ροή για την εγγραφή δεδομένων προεπισκόπησης σελίδας. |
| [`ILogger`](/watermark/python-net/groupdocs.watermark.options/ilogger/) | Ορίζει τη διεπαφή ενός καταγραφέα που χρησιμοποιείται για την καταγραφή συμβάντων και σφαλμάτων κατά τη διαδικασία υδατογράφησης. |
| [`LoadOptions`](/watermark/python-net/groupdocs.watermark.options/loadoptions/) | Αντιπροσωπεύει τις επιλογές φόρτωσης εγγράφου κατά τη φόρτωση ενός εγγράφου. |
| [`OoxmlLoadOptions`](/watermark/python-net/groupdocs.watermark.options/ooxmlloadoptions/) | Αντιπροσωπεύει τις επιλογές φόρτωσης εγγράφου για ένα έγγραφο OOXML. |
| [`PreviewOptions`](/watermark/python-net/groupdocs.watermark.options/previewoptions/) | Παρέχει επιλογές για τον καθορισμό απαιτήσεων και αντιπροσώπων ροής για τη δημιουργία προεπισκόπησης. |

| [`SaveOptions`](/watermark/python-net/groupdocs.watermark.options/saveoptions/) | Αντιπροσωπεύει τις επιλογές αποθήκευσης εγγράφου κατά την αποθήκευση ενός εγγράφου. |
| [`WatermarkOptions`](/watermark/python-net/groupdocs.watermark.options/watermarkoptions/) | Αντιπροσωπεύει τις επιλογές προσθήκης υδατογραφήματος κατά την προσθήκη υδατογραφήματος σε ένα έγγραφο. |
