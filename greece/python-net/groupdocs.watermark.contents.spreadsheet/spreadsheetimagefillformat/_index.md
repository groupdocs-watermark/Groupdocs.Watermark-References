## SpreadsheetImageFillFormat class

Αντιπροσωπεύει τις ρυθμίσεις μορφής γεμίσματος εικόνας σε έγγραφο Excel.

Ο τύπος SpreadsheetImageFillFormat εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | Η εικόνα φόντου. Επιστρέφει None εάν η εικόνα δεν έχει οριστεί. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | Η εικόνα επαναλαμβάνεται (tile) στο φόντο όταν είναι True· διαφορετικά η εικόνα τεντώνεται. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | Η διαφάνεια της εικόνας φόντου ως τιμή από 0.0 (αδιαφανής) έως 1.0 (πλήρως διαφανής). |
