## OfficeImageEffects class

Αντιπροσωπεύει εφέ που μπορούν να εφαρμοστούν σε υδατογράφημα εικόνας για ένα περιεχόμενο γραφείου.

Ο τύπος OfficeImageEffects εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Οι ρυθμίσεις μορφής γραμμής για το περίγραμμα της εικόνας. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | Η φωτεινότητα της εικόνας. Πρέπει να είναι αριθμός κινητής υποδιαστολής μεταξύ 0.0 (σκοτεινότερο) και 1.0 (φωτεινότερο). Η προεπιλεγμένη τιμή είναι 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | Η τιμή χρώματος της εικόνας που θα θεωρηθεί διαφανής. Η προεπιλεγμένη τιμή είναι ένα πλήρως διαφανές χρώμα. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Η αντίθεση για την καθορισμένη εικόνα. Πρέπει να είναι δεκαδικός αριθμός μεταξύ 0.0 (ελάχιστη αντίθεση) και 1.0 (μέγιστη αντίθεση). Η προεπιλεγμένη τιμή είναι 0.5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | Η ιδιότητα υποδεικνύει εάν μια εικόνα θα εμφανιστεί σε λειτουργία γκρι κλίμακας. |
