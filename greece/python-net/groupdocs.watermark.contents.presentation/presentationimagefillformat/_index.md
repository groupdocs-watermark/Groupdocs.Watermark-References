## PresentationImageFillFormat class

Αντιπροσωπεύει τις ρυθμίσεις μορφής γεμίσματος εικόνας σε έγγραφο PowerPoint.

Ο τύπος PresentationImageFillFormat εκθέτει τα παρακάτω μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | Η εικόνα φόντου. Επιστρέφει None εάν η εικόνα δεν έχει οριστεί. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | Η εικόνα επαναλαμβάνεται (tile) στο φόντο όταν οριστεί σε True· διαφορετικά τεντώνεται. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | Η διαφάνεια της εικόνας φόντου ως τιμή από 0.0 (αδιαφανής) έως 1.0 (πλήρως διαφανής). |
