## PdfXForm class

Αντιπροσωπεύει ένα XForm σε περιεχόμενο pdf.

Ο τύπος PdfXForm εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/height/) | Το ύψος του αντικειμένου. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/rotate_angle/) | Η γωνία περιστροφής του αντικειμένου σε μοίρες. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/width/) | Το πλάτος του αντικειμένου. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/x/) | Η συντεταγμένη x του αντικειμένου. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/y/) | Η συντεταγμένη y του αντικειμένου. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | Η συλλογή των μορφοποιημένων τμημάτων κειμένου αυτού του [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (κληρονομείται από το [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | Η εικόνα αυτού του PdfShape. Επιστρέφει None εάν το αντικείμενο δεν έχει εικόνα. (κληρονομείται από το [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | Η γονική σελίδα αυτού του PdfXObject. (κληρονομείται από [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Το κείμενο αυτού του [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (κληρονομείται από το [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
