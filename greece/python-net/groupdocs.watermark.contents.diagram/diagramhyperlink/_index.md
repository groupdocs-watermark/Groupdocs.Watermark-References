## DiagramHyperlink class

Αντιπροσωπεύει έναν υπερσύνδεσμο σε ένα έγγραφο Visio.

Ο τύπος DiagramHyperlink εκθέτει τα παρακάτω μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [address](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramhyperlink/address/) | Η διεύθυνση του υπερσυνδέσμου. |
| [description](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramhyperlink/description/) | Η περιγραφή του υπερσυνδέσμου. |
| [sub_address](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramhyperlink/sub_address/) | Η υποδιεύθυνση του υπερσυνδέσμου, μια θέση μέσα στο περιεχόμενο-στόχο στην οποία θα συνδεθεί. |
