## Watermark class

Αντιπροσωπεύει ένα υδατογράφημα που θα προστεθεί σε ένα έγγραφο.

Μάθετε περισσότερα

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Ο τύπος Watermark εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | Η ιδιότητα που υποδεικνύει εάν το μέγεθος και οι συντεταγμένες του υδατογραφήματος υπολογίζονται λαμβάνοντας υπόψη τα περιθώρια του γονέα. Εάν οριστεί σε True, οι υπολογισμοί λαμβάνουν υπόψη τα περιθώρια του γονέα· εξ ορισμού η τιμή είναι False και τα περιθώρια του γονέα αγνοούνται. |
