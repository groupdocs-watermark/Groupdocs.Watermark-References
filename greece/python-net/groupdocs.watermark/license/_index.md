## License class

Διαχειρίζεται την αδειοδότηση του GroupDocs.Watermark.

Οι αδειοδοτημένες εκδόσεις ξεκλειδώνουν το πλήρες σύνολο λειτουργιών του wrapper στο
χρόνο εκτέλεσης. Οι μη αδειοδοτημένες εκδόσεις λειτουργούν σε λειτουργία αξιολόγησης με το ίδιο API
επιφάνεια, αλλά με περιορισμούς στο μέγεθος εξόδου και το περιεχόμενο με υδατογράφημα.
