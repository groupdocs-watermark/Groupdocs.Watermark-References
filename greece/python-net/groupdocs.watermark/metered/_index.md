## Metered class

Διαχειρίζεται τη μετρημένη (πληρωμή ανά χρήση) άδεια.

Οι άδειες Metered χρεώνονται βάσει πραγματικής κατανάλωσης (συνήθως σελίδες ή
έγγραφα που επεξεργάζονται). Ορίστε το ζεύγος δημόσιου/ιδιωτικού κλειδιού μία φορά στο
εκκίνηση της εφαρμογής· το wrapper αναφέρει τη χρήση πίσω στο GroupDocs
διακομιστή αδειών στο παρασκήνιο.

Ο τύπος Metered εκθέτει τα ακόλουθα μέλη:

| Μέθοδος | Περιγραφή |
| :- | :- |
| [get_consumption_credit](/watermark/python-net/groupdocs.watermark/metered/get_consumption_credit/) | Επιστρέφει τον αριθμό των πόντων που έχουν καταναλωθεί μέχρι τώρα. |
| [get_consumption_quantity](/watermark/python-net/groupdocs.watermark/metered/get_consumption_quantity/) | Επιστρέφει το ποσό των δεδομένων που έχουν επεξεργαστεί μέχρι τώρα. |
| [set_metered_key](/watermark/python-net/groupdocs.watermark/metered/set_metered_key/#public_key-private_key) | Ενεργοποιήστε τη χρέωση Metered με το δοσμένο ζεύγος δημόσιου/ιδιωτικού κλειδιού. |
