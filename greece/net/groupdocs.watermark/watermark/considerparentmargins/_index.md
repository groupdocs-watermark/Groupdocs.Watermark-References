## Watermark.ConsiderParentMargins property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν το μέγεθος και οι συντεταγμένες του υδατογραφήματος υπολογίζονται λαμβάνοντας υπόψη τα περιθώρια του γονέα.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Εάν η τιμή είναι true, το μέγεθος και οι συντεταγμένες του υδατογραφήματος υπολογίζονται λαμβάνοντας υπόψη τα περιθώρια του γονέα. Από προεπιλογή, η τιμή είναι false, τα περιθώρια του γονέα αγνοούνται.
