## Watermarker.SearchableObjects property

Λαμβάνει ή ορίζει τα αντικείμενα περιεχομένου που θα συμπεριληφθούν σε αναζήτηση υδατογραφήματος.

```csharp
public SearchableObjects SearchableObjects { get; set; }
```

### Property Value

Τα αντικείμενα που θα συμπεριληφθούν σε μια αναζήτηση υδατογραφημάτων.

### Σχόλια

Αυτή η ιδιότητα καθορίζει επίσης αντικείμενα περιεχομένου που χρησιμοποιούνται στην αναζήτηση εικόνων. Για περισσότερες πληροφορίες δείτε τις μεθόδους [`Search`](../search) και [`GetImages`](../getimages).

Μάθετε περισσότερα για την αναζήτηση υδατογραφημάτων: [Αναζήτηση υδατογραφημάτων](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks).

### Παραδείγματα

Αφαιρέστε όλα τα XObjects και τα Artifacts από ένα PDF έγγραφο.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\test.pdf"))
{
    // Καθορίστε ότι μόνο τα XObjects και τα Artifacts πρέπει να αναζητηθούν.
    watermarker.SearchableObjects.PdfSearchableObjects
        = PdfSearchableObjects.XObjects | PdfSearchableObjects.Artifacts; 

    PossibleWatermarkCollection watermarks = watermarker.Search();

    // Αφαιρέστε όλα τα ευρεθέντα αντικείμενα.
    watermarks.Clear();

    // Αποθηκεύστε τις αλλαγές.
    watermarker.Save();
}
```
