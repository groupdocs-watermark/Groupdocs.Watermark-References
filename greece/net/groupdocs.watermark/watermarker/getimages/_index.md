## GetImages(ImageSearchCriteria) {#getimages_1}

### Σχόλια

Η αναζήτηση διεξάγεται σε αντικείμενα που καθορίζονται στο [`SearchableObjects`](../searchableobjects).

Μάθετε περισσότερα για την αναζήτηση υδατογραφιών [Αναζήτηση υδατογραφιών](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks).

### Παραδείγματα

Αφαιρέστε όλες τις εικόνες που είναι παρόμοιες με το αναφορά από ένα έγγραφο οποιουδήποτε υποστηριζόμενου τύπου.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    ImageThumbnailSearchCriteria criteria = new ImageThumbnailSearchCriteria("reference.png");
    WatermarkableImageCollection images = watermarker.GetImages(criteria);
    images.Clear();
    watermarker.Save(@"D:\output.doc");
}
```

## GetImages() {#getimages}

Βρίσκει όλες τις εικόνες στο έγγραφο.

```csharp
public WatermarkableImageCollection GetImages()
```

### Τιμή Επιστροφής

Η συλλογή των ευρεθέντων εικόνων.

### Σχόλια

Η αναζήτηση διεξάγεται σε αντικείμενα που καθορίζονται στο [`SearchableObjects`](../searchableobjects).

Μάθετε περισσότερα για την αναζήτηση υδατογραφιών [Αναζήτηση υδατογραφιών](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks).

### Παραδείγματα

Προσθέστε υδατογράφημα σε όλες τις εικόνες σε ένα έγγραφο οποιουδήποτε υποστηριζόμενου τύπου.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    // Αρχικοποιήστε κείμενο ή υδατογράφημα εικόνας.
    TextWatermark watermark = new TextWatermark("DRAFT", new Font("Arial", 19));

    // Βρείτε όλες τις εικόνες στο έγγραφο.
    WatermarkableImageCollection images = watermarker.GetImages();

    // Προσθέστε υδατογράφημα.
    foreach (WatermarkableImage watermarkableImage in images)
    {
        watermarkableImage.AddWatermark(watermark);
    }

    // Αποθηκεύστε τις αλλαγές.
    watermarker.Save(@"D:\output.doc");
}
```
