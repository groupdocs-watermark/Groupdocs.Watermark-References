## Watermarker.GetDocumentInfo method

Λαμβάνει τις πληροφορίες σχετικά με τη μορφή του φορτωμένου εγγράφου.

```csharp
public IDocumentInfo GetDocumentInfo()
```

### Τιμή Επιστροφής

Η παρουσία [`IDocumentInfo`](../../../groupdocs.watermark.common/idocumentinfo) που περιέχει τις εντοπισμένες πληροφορίες.

### Σχόλια

Μάθετε περισσότερα για την λήψη των πληροφοριών του εγγράφου [Λήψη πληροφοριών εγγράφου](https://docs.groupdocs.com/display/watermarknet/Get+document+info).

### Παραδείγματα

Λάβετε πληροφορίες για ένα έγγραφο οποιουδήποτε υποστηριζόμενου τύπου.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\test.ppt"))
{
    IDocumentInfo docInfo = watermarker.GetDocumentInfo();
    Console.WriteLine("Document size: {0}", docInfo.Size);
    Console.WriteLine("Document format: {0}", docInfo.FileType.FileFormat);
    Console.WriteLine("Document contains {0} pages", docInfo.PageCount);
}
```
