public bool RotateAroundOrigin { get; set; }

### Property Value

`true` εάν τα επαναλαμβανόμενα υδατογραφήματα πρέπει να περιστραφούν γύρω από το κάτω αριστερό σημείο του εγγράφου· διαφορετικά, `false`, σε αυτήν την περίπτωση η περιστροφή θα είναι σχετική με την αριστερή άκρη του εγγράφου. Η προεπιλογή είναι `false`.
