### Σχόλια

Αυτά τα κριτήρια αναζήτησης χρησιμοποιούν DCT‑βασισμένο αντιληπτικό hash εικόνας για τον υπολογισμό ομοιότητας εικόνων. **Μάθετε περισσότερα:**

* [Searching watermarks](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks)

### Παραδείγματα

Αναζητήστε εικόνες στα συνημμένα αρχεία (pdf).

```csharp
WatermarkerSettings settings = new WatermarkerSettings();
settings.SearchableObjects = new SearchableObjects
{
    PdfSearchableObjects = PdfSearchableObjects.All
};
PdfLoadOptions loadOptions = new PdfLoadOptions();
using (Watermarker watermarker = new Watermarker(@"D:\test.pdf", loadOptions, settings))
{
    // Καθορίστε δείγμα εικόνας για σύγκριση με τις εικόνες του εγγράφου.
    ImageSearchCriteria criteria = new ImageDctHashSearchCriteria(@"D:\sample.png");
    // Αναζητήστε παρόμοιες εικόνες
    PossibleWatermarkCollection possibleWatermarks = watermarker.Search(criteria);
    // Αφαιρέστε ή τροποποιήστε τα βρεθέντα υδατογραφήματα εικόνας.
    // ...
}
```
