## PdfContent.PageMarginType property

Λαμβάνει ή ορίζει τα περιθώρια σελίδας pdf που θα χρησιμοποιηθούν κατά την προσθήκη υδατογράφησης.

```csharp
public PdfPageMarginType PageMarginType { get; set; }
```

### Property Value

Περιθώρια σελίδας PDF που θα χρησιμοποιηθούν κατά την προσθήκη υδατογραφήματος.

### Σχόλια

Αυτή η ιδιότητα λειτουργεί μόνο όταν το [`ConsiderParentMargins`](../../../groupdocs.watermark/watermark/considerparentmargins) είναι ορισμένο σε true. Εάν το [`ConsiderParentMargins`](../../../groupdocs.watermark/watermark/considerparentmargins) είναι false, όταν το pdf CropBox χρησιμοποιείται ως περιοχή υδατογραφήματος.

Η προεπιλεγμένη τιμή είναι TrimBox.
