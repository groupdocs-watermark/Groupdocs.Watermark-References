### isLocked() {#isLocked--}
```
public final boolean isLocked()
```


Λαμβάνει μια τιμή που υποδεικνύει αν η επεξεργασία του σχήματος στο Excel απαγορεύεται.


**Returns:**
boolean - Εάν η τιμή είναι true, η επεξεργασία του σχήματος θα απαγορευτεί. Από προεπιλογή, η τιμή είναι false, το σχήμα μπορεί να επεξεργαστεί στο Excel.
