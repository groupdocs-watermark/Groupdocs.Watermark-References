## Margins class

Rappresenta le impostazioni di margine per ogni bordo di un oggetto.

Il tipo Margins espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | Inizializza una nuova istanza della classe [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/). |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | Inizializza una nuova istanza della classe [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) con il tipo, la posizione e le dimensioni specificati. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | Il margine inferiore. Rappresenta lo spostamento orizzontale dal bordo inferiore del genitore. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | Il margine sinistro, espresso come spostamento orizzontale dal bordo sinistro del genitore. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | Il tipo di margine, che determina come i margini sono interpretati; impostare un nuovo valore reimposta automaticamente tutti i margini ai valori predefiniti (zero). |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | Il margine destro come spostamento orizzontale dal bordo destro del genitore. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | Il margine superiore. |
