### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [a](/watermark/python-net/groupdocs.watermark.watermarks/color/a/) | Il componente alpha del colore. I valori validi sono da 0 a 255. |
| [b](/watermark/python-net/groupdocs.watermark.watermarks/color/b/) | Il componente blu del colore, con valori validi da 0 a 255. |
| [g](/watermark/python-net/groupdocs.watermark.watermarks/color/g/) | Il valore del componente verde del colore. |
| [is_empty](/watermark/python-net/groupdocs.watermark.watermarks/color/is_empty/) | La proprietà indica se questa struttura [`Color`](/watermark/python-net/groupdocs.watermark.watermarks/color/) è non inizializzata. |
| [r](/watermark/python-net/groupdocs.watermark.watermarks/color/r/) | Il componente rosso del colore. I valori validi sono da 0 a 255. |

### Esempio

```python
from groupdocs.watermark.watermarks import Color, TextWatermark, Font
from groupdocs.watermark import Watermarker

with Watermarker("document.pdf") as watermarker:
    watermark = TextWatermark("CONFIDENTIAL", Font("Arial", 48))
    watermark.foreground_color = Color.red
    watermarker.add(watermark)
    watermarker.save("watermarked.pdf")
```
