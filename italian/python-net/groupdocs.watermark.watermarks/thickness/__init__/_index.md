## __init__ {#left-right-top-bottom}

Inizializza una nuova istanza di Thickness con lunghezze specifiche applicate a ciascun lato del rettangolo.

```python
def __init__(self, left, right, top, bottom):
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
| left | `float` | Lo spessore per il lato sinistro del rettangolo. |
| right | `float` | Lo spessore per il lato destro del rettangolo. |
| top | `float` | Lo spessore per il lato superiore del rettangolo. |
| bottom | `float` | Lo spessore per il lato inferiore del rettangolo. |

```python
    ...
```

| Parametro | Tipo | Descrizione |
| :- | :- | :- |
