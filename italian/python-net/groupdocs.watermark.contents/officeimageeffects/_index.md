## OfficeImageEffects class

Rappresenta gli effetti che possono essere applicati a una filigrana immagine per un contenuto Office.

Il tipo OfficeImageEffects espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Le impostazioni del formato della linea per il bordo dell'immagine. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | La luminosità dell'immagine. Deve essere un valore float compreso tra 0.0 (più scuro) e 1.0 (più luminoso). Il valore predefinito è 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | Il valore di colore dell'immagine che verrà trattato come trasparente. Il valore predefinito è un colore completamente trasparente. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Il contrasto per l'immagine specificata. Deve essere un valore float compreso tra 0.0 (meno contrasto) e 1.0 (massimo contrasto). Il valore predefinito è 0.5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | La proprietà indica se un'immagine verrà visualizzata in modalità scala di grigi. |
