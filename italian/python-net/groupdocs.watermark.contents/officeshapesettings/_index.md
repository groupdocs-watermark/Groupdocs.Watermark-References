## OfficeShapeSettings class

Rappresenta le impostazioni che possono essere applicate a una filigrana di forma per un contenuto Office.

Il tipo OfficeShapeSettings espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | Il testo descrittivo (alternativo) che sarà associato a una forma. |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | Il nome della forma. |
