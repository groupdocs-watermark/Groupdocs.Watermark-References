## SpreadsheetAttachment class

Rappresenta un file allegato a un documento Excel.

Il tipo SpreadsheetAttachment espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | Carica un contenuto dal file allegato. (eredita da [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | (eredita da [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | Recupera le informazioni su un documento memorizzato nel file allegato. (eredita da [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/alternative_text/) | Il testo descrittivo (alternativo) associato al file allegato. |
| [content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/content/) | Il contenuto del file allegato. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/height/) | L'altezza del riquadro dell'allegato in punti. |
| [is_link](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/is_link/) | La proprietà indica se l'allegato contiene solo un collegamento al file. |
| [preview_image_content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/preview_image_content/) | L'immagine di anteprima del file allegato come array di byte. |
| [source_full_name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/source_full_name/) | Il nome completo del file allegato. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/width/) | La larghezza del riquadro dell'allegato in punti. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/x/) | L'offset orizzontale del riquadro dell'allegato dal bordo sinistro del foglio di lavoro in punti. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/y/) | La coordinata y del riquadro dell'allegato in punti. |
