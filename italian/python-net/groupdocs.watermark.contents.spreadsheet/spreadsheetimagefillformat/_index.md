## SpreadsheetImageFillFormat class

Rappresenta le impostazioni del formato di riempimento immagine in un documento Excel.

Il tipo SpreadsheetImageFillFormat espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | L'immagine di sfondo. Restituisce None se l'immagine non è impostata. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | L'immagine è ripetuta sullo sfondo quando True; altrimenti l'immagine è allungata. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | La trasparenza dell'immagine di sfondo come valore da 0.0 (opaco) a 1.0 (completamente trasparente). |
