## SpreadsheetChart class

Rappresenta un grafico in un documento Excel.

Il tipo SpreadsheetChart espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | Il testo descrittivo (alternativo) associato a questo [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | L'altezza di questo SpreadsheetChart in punti. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | Il collegamento ipertestuale associato a questo SpreadsheetChart. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | L'identificatore di questo SpreadsheetChart. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | Le impostazioni del formato di riempimento dell'immagine di questo SpreadsheetChart. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | Il nome di questo SpreadsheetChart. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | La larghezza di questo SpreadsheetChart in punti. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | Il foglio di lavoro genitore di questo SpreadsheetChart. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | L'offset orizzontale di questo SpreadsheetChart dal bordo sinistro del foglio di lavoro in punti. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | L'offset verticale di questo SpreadsheetChart dal bordo superiore del foglio di lavoro in punti. |
