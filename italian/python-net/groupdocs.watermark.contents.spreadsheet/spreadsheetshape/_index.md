## SpreadsheetShape class

Rappresenta una forma di disegno in un documento Excel.

Il tipo SpreadsheetShape espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/alternative_text/) | Il testo descrittivo (alternativo) associato a questo [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [auto_shape_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/auto_shape_type/) | Il tipo di forma automatica. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/formatted_text_fragments/) | La raccolta di frammenti di testo formattato di questo SpreadsheetShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/height/) | L'altezza di questo SpreadsheetShape in punti. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/hyperlink/) | Il collegamento ipertestuale associato a questo [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/id/) | L'identificatore di questo SpreadsheetShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image/) | L'immagine di questo SpreadsheetShape. Restituisce None se la forma non ha un'immagine. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image_fill_format/) | Le impostazioni del formato di riempimento immagine di questo SpreadsheetShape. |
| [is_word_art](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/is_word_art/) | La forma è un oggetto WordArt. |
| [mso_drawing_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/mso_drawing_type/) | Il tipo di disegno mso. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/name/) | Il nome di questo SpreadsheetShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/rotate_angle/) | L'angolo di rotazione di questo [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) in gradi. |
| [text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/text/) | Il testo di questo [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/width/) | La larghezza di questo SpreadsheetShape in punti. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/worksheet/) | Il foglio di lavoro genitore di questo SpreadsheetShape. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/x/) | L'offset orizzontale di questo SpreadsheetShape dal bordo sinistro del foglio di lavoro in punti. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/y/) | La coordinata y di questo SpreadsheetShape dal bordo superiore del foglio di lavoro in punti. |
