## SpreadsheetWatermarkBaseOptions class

Rappresenta la classe base per le opzioni di aggiunta di filigrana a un documento Spreadsheet.

Il tipo SpreadsheetWatermarkBaseOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetwatermarkbaseoptions/alternative_text/) | Il testo descrittivo (alternativo) che sarà associato a una forma. |
| [is_locked](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetwatermarkbaseoptions/is_locked/) | La proprietà indica se la modifica della forma in Excel è vietata. |
| [name](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetwatermarkbaseoptions/name/) | Il nome della forma. |

### Campi
| Campo | Descrizione |
| :- | :- |
| [DEFAULT](/watermark/python-net/groupdocs.watermark.options/watermarkoptions/default/) | Ottiene il valore predefinito per la classe. (ereditato da [`WatermarkOptions`](/watermark/python-net/groupdocs.watermark.options/watermarkoptions/)) |
