## SpreadsheetShapeSettings class

Rappresenta le impostazioni che possono essere applicate a un watermark forma per un documento Excel.

Il tipo SpreadsheetShapeSettings espone i seguenti membri:

| :- | :- |

| Proprietà | Descrizione |
| :- | :- |
| [is_locked](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetshapesettings/is_locked/) | La proprietà indica se la modifica della forma in Excel è vietata. |
