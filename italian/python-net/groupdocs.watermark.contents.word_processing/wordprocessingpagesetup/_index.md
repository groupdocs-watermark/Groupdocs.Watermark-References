## WordProcessingPageSetup class

Rappresenta le proprietà di stampa della pagina per una sezione di un documento Word.

Il tipo WordProcessingPageSetup espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/bottom_margin/) | La dimensione del margine inferiore in punti. |
| [different_first_page_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/different_first_page_header_footer/) | Il flag che indica se un'intestazione/piè di pagina diverso è usato per la prima pagina. |
| [height](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/height/) | L'altezza di una pagina di stampa in punti. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/left_margin/) | La dimensione del margine sinistro in punti. |
| [odd_and_even_pages_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/odd_and_even_pages_header_footer/) | La proprietà indica se intestazioni/piè di pagina diversi sono usati per le pagine dispari e pari. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/right_margin/) | La dimensione del margine destro in punti. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/top_margin/) | La dimensione del margine superiore in punti. |
| [width](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/width/) | La larghezza di una pagina di stampa in punti. |
