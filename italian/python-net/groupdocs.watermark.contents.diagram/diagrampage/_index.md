## DiagramPage class

Rappresenta una pagina di documento Visio.

Il tipo DiagramPage espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Trova le immagini in base ai criteri di ricerca specificati. La ricerca viene eseguita negli oggetti specificati in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) | (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | Trova i possibili watermark in base ai criteri di ricerca specificati. La ricerca viene eseguita sugli oggetti elencati in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) | (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [background_page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/background_page/) | La pagina di sfondo per questa DiagramPage. |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/bottom_margin/) | La dimensione del margine inferiore in punti. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/height/) | L'altezza di questa DiagramPage in punti. |
| [is_background](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_background/) | La pagina è una pagina di sfondo. |
| [is_visible](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_visible/) | Il valore che indica se la pagina è visibile nell'interfaccia utente. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/left_margin/) | La dimensione del margine sinistro in punti. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/name/) | Il nome di questa DiagramPage. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/right_margin/) | La dimensione del margine destro in punti. |
| [shapes](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/shapes/) | La raccolta di tutte le forme della pagina. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/top_margin/) | La dimensione del margine superiore in punti. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/width/) | La larghezza di questa DiagramPage in punti. |
