## DiagramShape class

Rappresenta una forma di disegno in un documento Visio.

Il tipo DiagramShape espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/formatted_text_fragments/) | La raccolta di frammenti di testo formattato di questo DiagramShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/height/) | L'altezza di questo DiagramShape in punti. |
| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | La raccolta di collegamenti ipertestuali allegati a questo [`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | L'identificatore di questo DiagramShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | L'immagine di questo DiagramShape. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | Il nome di questo DiagramShape. |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | La pagina genitore di questo DiagramShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | L'angolo di rotazione di questo DiagramShape in gradi. |
| [text](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/text/) | Il testo di questo DiagramShape. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | La larghezza di questo DiagramShape in punti. |
| [x](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/x/) | L'offset orizzontale di questo DiagramShape dal bordo sinistro della pagina in punti, cioè la sua coordinata x. |
| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | L'offset verticale di questo DiagramShape dal bordo inferiore della pagina in punti. |
