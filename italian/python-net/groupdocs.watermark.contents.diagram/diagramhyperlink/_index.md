## DiagramHyperlink class

Rappresenta un collegamento ipertestuale in un documento Visio.

Il tipo DiagramHyperlink espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [address](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramhyperlink/address/) | L'indirizzo del collegamento ipertestuale. |
| [description](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramhyperlink/description/) | La descrizione del collegamento ipertestuale. |
| [sub_address](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramhyperlink/sub_address/) | Il sottoindirizzo del collegamento ipertestuale, una posizione all'interno del contenuto di destinazione a cui collegarsi. |
