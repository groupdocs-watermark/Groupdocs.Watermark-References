## Watermark class

Rappresenta una filigrana da aggiungere a un documento.

Maggiori informazioni

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Il tipo Watermark espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | La proprietà che indica se le dimensioni e le coordinate del watermark sono calcolate considerando i margini del genitore. Se impostata su True, i calcoli considerano i margini del genitore; per impostazione predefinita il valore è False e i margini del genitore sono ignorati. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | L'altezza desiderata di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | L'allineamento orizzontale di questo Watermark. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | La proprietà che indica se il watermark deve essere posizionato sullo sfondo. Se true, il watermark è posizionato in basso; altrimenti, è posizionato in alto (il valore predefinito è False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | Le impostazioni dei margini di questo Watermark. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | L'opacità di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | Le impostazioni di configurazione delle pagine di questo Watermark. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | L'angolo di rotazione di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) in gradi. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | La proprietà indica se salvare le informazioni sui watermark aggiunti nei metadati del documento. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | Il fattore di scala di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/), che definisce come le dimensioni del watermark dipendono dalle dimensioni del genitore. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | Il tipo di dimensionamento della filigrana. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | Le opzioni per definire una filigrana ripetuta. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | L'allineamento verticale di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | La larghezza desiderata di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | La coordinata x di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | La coordinata y di questo [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
