## License class

Gestisce la licenza di GroupDocs.Watermark.

Le build con licenza sbloccano l'intero set di funzionalità del wrapper a
runtime. Le build non licenziate funzionano in modalità di valutazione con la stessa API
ma con limiti sulla dimensione dell'output e sul contenuto watermarked.

Il tipo License espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [set_license](/watermark/python-net/groupdocs.watermark/license/set_license/#license_source) | Applica una licenza al processo corrente. |
