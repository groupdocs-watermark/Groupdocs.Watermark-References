## PresentationSlide class

Rappresenta una diapositiva di un documento PowerPoint.

Il tipo PresentationSlide espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Trova le immagini in base ai criteri di ricerca specificati. La ricerca viene eseguita negli oggetti specificati in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) | (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | Trova i possibili watermark in base ai criteri di ricerca specificati. La ricerca viene eseguita sugli oggetti elencati in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) | (eredita da [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [layout_slide](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslide/layout_slide/) | La diapositiva di layout per questo PresentationSlide. |
| [master_slide](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslide/master_slide/) | La diapositiva master per questo PresentationSlide. |
| [notes_slide](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslide/notes_slide/) | La diapositiva delle note per questo PresentationSlide. |
| [charts](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/charts/) | La collezione di tutti i grafici della presentazione. (eredita da [`PresentationBaseSlide`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/)) |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/image_fill_format/) | Le impostazioni del formato di riempimento dell'immagine della presentazione. | [shapes](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/shapes/) | La collezione di tutte le forme della presentazione. (eredita da [`PresentationBaseSlide`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/)) |
