## PresentationImageFillFormat class

Rappresenta le impostazioni del formato di riempimento immagine in un documento PowerPoint.

Il tipo PresentationImageFillFormat espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | L'immagine di sfondo. Restituisce None se l'immagine non è impostata. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | L'immagine è affiancata sullo sfondo quando impostata su True; altrimenti è allungata. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | La trasparenza dell'immagine di sfondo come valore da 0.0 (opaco) a 1.0 (completamente trasparente). |
