## PresentationShapeSettings class

Rappresenta le impostazioni che possono essere applicate a una filigrana di forma per un documento PowerPoint.

Il tipo PresentationShapeSettings espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/__init__/) | Inizializza una nuova istanza di PresentationShapeSettings. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [is_locked](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/is_locked/) | La proprietà indica se la modifica della forma in PowerPoint è proibita. |
| [protect_with_unreadable_characters](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/protect_with_unreadable_characters/) | Il valore che indica se i caratteri della filigrana di testo sono mescolati con caratteri illeggibili. |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | Il testo descrittivo (alternativo) che sarà associato a una forma. (eredita da [`OfficeShapeSettings`](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/)) |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | Il nome della forma. (eredita da [`OfficeShapeSettings`](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/)) |
