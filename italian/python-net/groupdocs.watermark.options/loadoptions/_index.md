## LoadOptions class

Rappresenta le opzioni di caricamento del documento durante il caricamento di un documento.

Per saperne di più:
- Loading documents: https://docs.groupdocs.com/display/watermarknet/Loading+documents
- Load from local disk: https://docs.groupdocs.com/display/watermarknet/Load+from+local+disk
- Load from stream: https://docs.groupdocs.com/display/watermarknet/Load+from+stream
- Load document of specific format: https://docs.groupdocs.com/display/watermarknet/Load+document+of+specific+format
- Load password-protected document: https://docs.groupdocs.com/display/watermarknet/Load+password-protected+document

Il tipo LoadOptions espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options/loadoptions/__init__/) | Inizializza una nuova istanza della classe LoadOptions. |
| [__init__](/watermark/python-net/groupdocs.watermark.options/loadoptions/__init__/#password) | Inizializza una nuova istanza della classe [`LoadOptions`](/watermark/python-net/groupdocs.watermark.options/loadoptions/) con una password specificata. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [file_type](/watermark/python-net/groupdocs.watermark.options/loadoptions/file_type/) | Il tipo di file, che indica il suo formato (ad es., docx, pdf, xlsx, ecc.). |
| [format_family](/watermark/python-net/groupdocs.watermark.options/loadoptions/format_family/) | La famiglia di formato del documento, che indica il suo tipo (ad es., Image, Pdf, Spreadsheet, ecc.). |
| [password](/watermark/python-net/groupdocs.watermark.options/loadoptions/password/) | La password per aprire un documento crittografato. |
