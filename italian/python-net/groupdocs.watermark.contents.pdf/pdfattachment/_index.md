## PdfAttachment class

Rappresenta un file allegato a un contenuto pdf.

Per saperne di più:
- https://docs.groupdocs.com/display/watermarknet/Attachments+in+PDF+document

Il tipo PdfAttachment espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | Carica un contenuto dal file allegato. (eredita da [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | (eredita da [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | Recupera le informazioni su un documento memorizzato nel file allegato. (eredita da [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [content](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfattachment/content/) | Il contenuto del file allegato. |
| [description](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfattachment/description/) | La descrizione del file allegato. |
| [name](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfattachment/name/) | Il nome del file allegato. |
