## PdfAnnotation class

Rappresenta un'annotazione in un documento pdf.

Per saperne di più:
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

Il tipo PdfAnnotation espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | Il tipo di questo [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/height/) | L'altezza di questo PdfAnnotation in punti. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/page/) | La pagina padre di questo [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | L'angolo di rotazione di questo PdfAnnotation in gradi. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | La larghezza di questa PdfAnnotation in punti. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | L'offset orizzontale di questa PdfAnnotation dal bordo sinistro della pagina in punti. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/y/) | L'offset verticale di questo [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) dal bordo inferiore del foglio di lavoro in punti. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La collezione di frammenti di testo formattato di questo [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | L'immagine di questo PdfShape. Restituisce None se l'oggetto non ha un'immagine. (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Il testo di questo [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
