## PdfArtifact class

Rappresenta un artefatto in un contenuto pdf.

Per saperne di più:
- https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithartifacts

Il tipo PdfArtifact espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [artifact_subtype](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_subtype/) | Il sottotipo di questo [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [artifact_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_type/) | Il tipo di questo [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/height/) | L'altezza di questo [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) in punti. |
| [opacity](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/opacity/) | L'opacità di questo [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/page/) | La pagina genitore di questo [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/rotate_angle/) | L'angolo di rotazione di questo PdfArtifact in gradi. |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/text/) | Il testo di questo [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/width/) | La larghezza di questo [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) in punti. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/x/) | L'offset orizzontale di questo PdfArtifact dal bordo sinistro della pagina in punti. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/y/) | L'offset verticale di questo PdfArtifact dal bordo inferiore della pagina in punti. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La collezione di frammenti di testo formattato di questo [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | L'immagine di questo PdfShape. Restituisce None se l'oggetto non ha un'immagine. (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
