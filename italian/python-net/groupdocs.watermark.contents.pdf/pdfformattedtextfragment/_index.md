## PdfFormattedTextFragment class

Rappresenta un frammento di testo formattato in un documento pdf.

Il tipo PdfFormattedTextFragment espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [background_color](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfformattedtextfragment/background_color/) | Il colore di sfondo del testo. |
| [font](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfformattedtextfragment/font/) | Il carattere del testo. |
| [foreground_color](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfformattedtextfragment/foreground_color/) | Il colore di primo piano del testo. |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfformattedtextfragment/text/) | Il testo del frammento. |
