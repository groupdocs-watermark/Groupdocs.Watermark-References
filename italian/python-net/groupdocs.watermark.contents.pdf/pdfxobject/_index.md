## PdfXObject class

Rappresenta un XObject in un documento PDF.

Maggiori informazioni

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

Il tipo PdfXObject espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | L'altezza di questo PdfXObject in punti. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | La pagina genitore di questo PdfXObject. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | L'angolo di rotazione di questo PdfXObject in gradi. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | La larghezza di questo [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) in punti. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | L'offset orizzontale di questo PdfXObject dal bordo sinistro della pagina in punti. La coordinata x di questo PdfXObject. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | L'offset verticale di questo PdfXObject dal bordo inferiore della pagina in punti (la coordinata y). |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La collezione di frammenti di testo formattato di questo [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | L'immagine di questo PdfShape. Restituisce None se l'oggetto non ha un'immagine. (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Il testo di questo [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (eredita da [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
