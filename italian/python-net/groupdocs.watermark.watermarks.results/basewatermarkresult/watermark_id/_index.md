## watermark_id property

L'identificatore unico della filigrana, utilizzato per modificare la filigrana tramite i metodi Update o Delete.

L'identificatore viene impostato automaticamente dopo aver chiamato il metodo Add. Se l'identificatore è stato salvato in precedenza, può essere impostato manualmente per manipolare il watermark.
