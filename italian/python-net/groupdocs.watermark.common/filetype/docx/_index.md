## DOCX field

DOCX è un formato noto per i documenti Microsoft Word. Introdotto dal 2007 con il rilascio di Microsoft Office 2007, la struttura di questo nuovo formato di documento è stata modificata da puro binario a una combinazione di file XML e binari. Scopri di più su questo formato di file qui.
