## FileType class

Rappresenta il tipo di file.

Fornisce metodi per ottenere un elenco di tutti i tipi di file supportati da [`GroupDocs.Watermark`](/watermark/python-net/groupdocs.watermark/watermark/).

Il tipo FileType espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#other) | Determina se il [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) corrente è lo stesso dell'oggetto [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) specificato. |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#obj) | Determina se il FileType corrente è lo stesso dell'oggetto specificato. |
| [equals_file_type](/watermark/python-net/groupdocs.watermark.common/filetype/equals_file_type/) |  |
| [equals_object](/watermark/python-net/groupdocs.watermark.common/filetype/equals_object/) |  |
| [from_extension](/watermark/python-net/groupdocs.watermark.common/filetype/from_extension/#extension) | Mappa l'estensione del file al tipo di file. |
| [get_hash_code](/watermark/python-net/groupdocs.watermark.common/filetype/get_hash_code/) | Restituisce un codice hash per l'oggetto [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) corrente. |
| [get_supported_file_types](/watermark/python-net/groupdocs.watermark.common/filetype/get_supported_file_types/) | Recupera i tipi di file supportati. |
| [to_string](/watermark/python-net/groupdocs.watermark.common/filetype/to_string/) | Restituisce una stringa che rappresenta l'oggetto corrente. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [extension](/watermark/python-net/groupdocs.watermark.common/filetype/extension/) | Il suffisso del nome file (incluso il punto ".") es., ".doc". |
| [file_format_name](/watermark/python-net/groupdocs.watermark.common/filetype/file_format_name/) | Il nome del tipo di file, es., "Microsoft Word Document". |
| [format_family](/watermark/python-net/groupdocs.watermark.common/filetype/format_family/) | La famiglia di formato. |

### Esempio

```python
from groupdocs.watermark.common import FileType

def list_supported_formats():
    # Elenca tutti i tipi di file che la libreria può aprire
    supported_file_types = FileType.get_supported_file_types()
    for file_type in sorted(supported_file_types, key=lambda x: x.extension):
        print(file_type)

if __name__ == "__main__":
    list_supported_formats()
```
