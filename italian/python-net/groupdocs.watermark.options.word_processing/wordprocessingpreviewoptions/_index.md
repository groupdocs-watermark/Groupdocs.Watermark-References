## WordProcessingPreviewOptions class

Fornisce opzioni per impostare i requisiti e i delegati di flusso per la generazione dell'anteprima di un documento WordProcessing.

Il tipo WordProcessingPreviewOptions espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessingpreviewoptions/__init__/#create_page_stream) | Inizializza una nuova istanza di WordProcessingPreviewOptions che provoca la chiusura del flusso di output. |
| [__init__](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessingpreviewoptions/__init__/#create_page_stream-release_page_stream) | Inizializza una nuova istanza della classe WordProcessingPreviewOptions facendo restituire il flusso di output al client per un uso successivo. |
