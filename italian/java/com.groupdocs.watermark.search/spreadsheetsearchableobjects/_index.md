|
|  | [WorksheetBackgrounds](#WorksheetBackgrounds) | Cerca negli sfondi dei fogli di lavoro. |

|  | [Cells](#Cells) | Cerca nelle celle. |

|  | [Hyperlinks](#Hyperlinks) | Cerca nei collegamenti ipertestuali. |
|
|  | [AttachedImages](#AttachedImages) | Cerca nelle immagini allegate. |
|
|  | [All](#All) | Cerca in tutti gli oggetti di contenuto. |
