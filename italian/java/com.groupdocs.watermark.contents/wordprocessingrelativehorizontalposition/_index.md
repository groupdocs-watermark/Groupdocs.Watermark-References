Specifica a cosa è relativa la posizione orizzontale di un oggetto.

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [Margin](#Margin) | Specifica che il posizionamento orizzontale è relativo ai margini della pagina. |
|
|  | [Page](#Page) | L'oggetto è posizionato rispetto al bordo sinistro della pagina. |
|
|  | [Column](#Column) | L'oggetto è posizionato rispetto al lato sinistro della colonna. |
|
|  | [Character](#Character) | L'oggetto è posizionato rispetto al lato sinistro del paragrafo. |
|
|  | [LeftMargin](#LeftMargin) | Specifica che il posizionamento orizzontale è relativo al margine sinistro della pagina. |
|
|  | [RightMargin](#RightMargin) | Specifica che il posizionamento orizzontale è relativo al margine destro della pagina. |
|
|  | [InsideMargin](#InsideMargin) | Specifica che il posizionamento orizzontale è relativo al margine interno |
della pagina corrente (il margine sinistro nelle pagine dispari, quello destro nelle pagine pari).
|
|  | [OutsideMargin](#OutsideMargin) | Specifica che il posizionamento orizzontale è relativo al margine esterno |
della pagina corrente (il margine destro nelle pagine dispari, quello sinistro nelle pagine pari).
|
