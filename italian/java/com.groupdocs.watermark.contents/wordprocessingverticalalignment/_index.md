Specifica l'allineamento verticale di un oggetto fluttuante.

## Campi

| Campo | Descrizione |
| --- | --- |
|  | [Inline](#Inline) | Non documentato. |
|
|  | [None](#None) | L'oggetto è posizionato esplicitamente usando la sua coordinata y. |
|
|  | [Top](#Top) | Specifica che l'oggetto è in cima alla base di allineamento verticale. |
|
|  | [Center](#Center) | Specifica che l'oggetto è centrato rispetto alla base di allineamento verticale. |
|
|  | [Bottom](#Bottom) | Specifica che l'oggetto è nella parte inferiore della base di allineamento verticale. |
|
|  | [Inside](#Inside) | Specifica che l'oggetto è all'interno della base di allineamento orizzontale. |
|
|  | [Outside](#Outside) | Specifica che l'oggetto è al di fuori della base di allineamento verticale. |
|
