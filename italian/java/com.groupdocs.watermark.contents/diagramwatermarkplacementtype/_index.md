## Campi

| Campo | Descrizione |
| --- | --- |
|  | [ForegroundPages](#ForegroundPages) | Un watermark dovrebbe essere aggiunto solo alle pagine in primo piano. |
|
|  | [BackgroundPages](#BackgroundPages) | Un watermark dovrebbe essere aggiunto solo alle pagine di sfondo. |
|
|  | [AllPages](#AllPages) | Un watermark dovrebbe essere aggiunto a tutte le pagine. |
|
|  | [SeparateBackgrounds](#SeparateBackgrounds) | Le pagine di sfondo separate con un watermark dovrebbero essere create e assegnate a tutte le pagine senza sfondo. |

|  | [Default](#Default) | Lo stesso di `#ForegroundPages.ForegroundPages`. |
