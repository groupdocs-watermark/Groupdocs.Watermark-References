## WordProcessingHeaderFooter.IsLinkedToPrevious property

Ottiene o imposta un valore che indica se questa intestazione/piè di pagina è collegata all'intestazione/piè di pagina corrispondente nella sezione precedente.

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

True se questa intestazione/piè di pagina è collegata all'intestazione/piè di pagina corrispondente nella sezione precedente; false altrimenti.

### Osservazioni

Il valore predefinito è true. Nota, quando colleghi un'intestazione o un piè di pagina, il suo contenuto viene cancellato.
