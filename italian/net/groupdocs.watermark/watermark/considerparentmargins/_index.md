## Watermark.ConsiderParentMargins property

Ottiene o imposta un valore che indica se le dimensioni e le coordinate della filigrana sono calcolate tenendo conto dei margini del genitore.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Se il valore è true, le dimensioni e le coordinate della filigrana vengono calcolate considerando i margini del genitore. Per impostazione predefinita, il valore è false, i margini del genitore sono ignorati.
