## WordProcessingWatermarkPagesOptions.PageNumbers property

Ottiene o imposta i numeri di pagina a cui aggiungere il watermark.

```csharp
public int[] PageNumbers { get; set; }
```

### Property Value

I numeri di pagina a cui aggiungere la filigrana.

### Osservazioni

Tutti i numeri devono essere maggiori o uguali a 1. Questa proprietà è utilizzata solo quando si aggiunge la filigrana a un documento. Se questo valore è `null` o vuoto, la filigrana viene aggiunta a tutte le pagine.
