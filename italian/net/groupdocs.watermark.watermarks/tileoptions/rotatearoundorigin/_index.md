## TileOptions.RotateAroundOrigin property

Ottiene o imposta un valore che indica se le filigrane ripetute devono essere ruotate attorno al centro del documento.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` se i watermark ripetuti devono essere ruotati attorno al punto in basso a sinistra del documento; altrimenti, `false`, in tal caso la rotazione sarà relativa al bordo sinistro del documento. Il valore predefinito è `false`.
