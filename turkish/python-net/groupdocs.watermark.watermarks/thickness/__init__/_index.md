## __init__ {#left-right-top-bottom}

Dikdörtgenin her bir kenarına belirli uzunluklar uygulanarak yeni bir Thickness örneği başlatır.

```python
def __init__(self, left, right, top, bottom):
    ...
```

| Parametre | Tür | Açıklama |
| :- | :- | :- |
| left | `float` | Dikdörtgenin sol tarafı için kalınlık. |
| right | `float` | Dikdörtgenin sağ tarafı için kalınlık. |
| top | `float` | Dikdörtgenin üst tarafı için kalınlık. |
| bottom | `float` | Dikdörtgenin alt tarafı için kalınlık. |

## __init__ {#uniform_length}

Her bir kenara belirtilen tek tip uzunlukla yeni bir Thickness örneği başlatır.

```python
def __init__(self, uniform_length):
    ...
```

| Parametre | Tür | Açıklama |
| :- | :- | :- |
| uniform_length | `float` | Sınırlayıcı dikdörtgenin dört kenarına uygulanan tek tip uzunluk. |
