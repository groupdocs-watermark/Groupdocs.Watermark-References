## Margins class

Margins türü aşağıdaki üyeleri gösterir:

| Yapıcı | Açıklama |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | Yeni bir [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) sınıfı örneği oluşturur. |

| Özellik | Açıklama |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | Alt kenar boşluğu. Ebeveynin alt kenarından yatay offseti temsil eder. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | Sol kenar boşluğu, ebeveynin sol kenarından yatay offset olarak ifade edilir. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | Kenar boşluğu türü, kenar boşluklarının nasıl yorumlanacağını belirler; yeni bir değer ayarlandığında tüm kenar boşlukları otomatik olarak varsayılan değerlerine (sıfır) sıfırlanır. |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | Sağ kenar boşluğu, ebeveynin sağ kenarından yatay offset olarak. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | Üst kenar boşluğu. |
