## OfficeImageEffects class

Ofis içeriği için bir görüntü filigranına uygulanabilecek etkileri temsil eder.

OfficeImageEffects türü aşağıdaki üyeleri sunar:

### Özellikler
| Özellik | Açıklama |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Görüntü kenarı için satır biçim ayarları. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | Resmin parlaklığı. 0.0 (en karanlık) ile 1.0 (en parlak) arasında bir float olmalıdır. Varsayılan değer 0.5'tir. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | Şeffaf olarak işlenecek görüntünün renk değeri. Varsayılan değer tamamen şeffaf bir renktir. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Belirtilen resim için kontrast. 0.0 (en düşük kontrast) ile 1.0 (en yüksek kontrast) arasında bir ondalık sayı olmalıdır. Varsayılan değer 0.5'tir. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | Bu özellik, bir resmin gri tonlamalı modda görüntülenip görüntülenmeyeceğini gösterir. |
