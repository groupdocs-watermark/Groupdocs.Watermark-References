## SpreadsheetImageFillFormat class

Bir Excel belgesindeki resim doldurma biçim ayarlarını temsil eder.

SpreadsheetImageFillFormat türü aşağıdaki üyeleri ortaya çıkarır:

### Özellikler
| Özellik | Açıklama |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | Arka plan görüntüsü. Görüntü ayarlanmamışsa None döndürür. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | True olduğunda görüntü arka plan boyunca döşenir; aksi takdirde görüntü gerilir. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | Arka plan görüntüsünün şeffaflığı, 0.0 (opak) ile 1.0 (tamamen şeffaf) arasında bir değer olarak. |
