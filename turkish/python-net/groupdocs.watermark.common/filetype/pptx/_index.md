## PPTX field

PPTX uzantılı dosyalar, popüler Microsoft PowerPoint uygulamasıyla oluşturulan sunum dosyalarıdır. Önceki ikili PPT sunum dosya formatının aksine, PPTX formatı Microsoft PowerPoint açık XML sunum dosya formatına dayanır. Bu dosya formatı hakkında daha fazla bilgi edinin.
