## Watermark.ConsiderParentMargins property

Filigran boyutu ve koordinatlarının ebeveyn kenar boşlukları dikkate alınarak hesaplanıp hesaplanmadığını gösteren bir değeri alır veya ayarlar.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Değer true ise, filigran boyutu ve koordinatları üst öğe kenar boşlukları dikkate alınarak hesaplanır. Varsayılan olarak, değer false'tir, üst öğe kenar boşlukları göz ardı edilir.
