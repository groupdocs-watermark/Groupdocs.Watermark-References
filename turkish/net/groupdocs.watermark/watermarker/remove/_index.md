## Remove(PossibleWatermark) {#remove}

Belgeden filigranı kaldırır.

```csharp
public void Remove(PossibleWatermark possibleWatermark)
```

| Parametre | Type | Açıklama |
| --- | --- | --- |
| possibleWatermark | PossibleWatermark | Kaldırılacak filigran. |

### Açıklamalar

Filigranları kaldırma hakkında daha fazla bilgi edinin: [Bulunan filigranları kaldırma](https://docs.groupdocs.com/display/watermarknet/Removing+found+watermarks).

### Örnekler

Herhangi bir desteklenen türdeki belgelerden belirli metin veya görüntü içeren ilk olası filigranı bulun ve kaldırın.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria(@"D:\logo.png");
    Regex regex = new Regex(@"^Company\sName$", RegexOptions.IgnoreCase);
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria(regex);
    PossibleWatermarkCollection watermarks = watermarker.Search(textSearchCriteria.Or(imageSearchCriteria));
    if (watermarks.Count > 0)
    {
        watermarker.Remove(watermarks[0]);
    }

    watermarker.Save(@"D:\output.doc");
}
```
