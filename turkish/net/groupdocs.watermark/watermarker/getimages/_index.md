## GetImages(ImageSearchCriteria) {#getimages_1}

Belirtilen arama kriterlerine göre görüntüleri bulur.

```csharp
public WatermarkableImageCollection GetImages(ImageSearchCriteria searchCriteria)
```

| Parametre | Type | Açıklama |
| --- | --- | --- |
| searchCriteria | ImageSearchCriteria | Kullanılacak arama kriteri. |

### Return Value

Bulunan görüntülerin koleksiyonu.

### Açıklamalar

Arama, [`SearchableObjects`](../searchableobjects) içinde belirtilen nesnelerde gerçekleştirilir.

Filigran arama hakkında daha fazla bilgi edinin [Searching watermarks](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks).

### Örnekler

Herhangi bir desteklenen türdeki belgelerden referansa benzer tüm görüntüleri kaldırın.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    ImageThumbnailSearchCriteria criteria = new ImageThumbnailSearchCriteria("reference.png");
    WatermarkableImageCollection images = watermarker.GetImages(criteria);
    images.Clear();
    watermarker.Save(@"D:\output.doc");
}
```

## GetImages() {#getimages}

Belgedeki tüm görüntüleri bulur.

```csharp
public WatermarkableImageCollection GetImages()
```

### Return Value

Bulunan görüntülerin koleksiyonu.

### Açıklamalar

Arama, [`SearchableObjects`](../searchableobjects) içinde belirtilen nesnelerde gerçekleştirilir.

Filigran arama hakkında daha fazla bilgi edinin [Searching watermarks](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks).

### Örnekler

Herhangi bir desteklenen türdeki belgelerdeki tüm görüntülere filigran ekleyin.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    // Metin veya görüntü filigranını başlat.
    TextWatermark watermark = new TextWatermark("DRAFT", new Font("Arial", 19));

    // Belgedeki tüm görüntüleri bulun.
    WatermarkableImageCollection images = watermarker.GetImages();

    // Filigran ekle.
    foreach (WatermarkableImage watermarkableImage in images)
    {
        watermarkableImage.AddWatermark(watermark);
    }

    // Değişiklikleri kaydet.
    watermarker.Save(@"D:\output.doc");
}
```
