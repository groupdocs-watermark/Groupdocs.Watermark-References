| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | Коллекция гиперссылок, прикреплённых к этому [`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | Идентификатор этого DiagramShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | Изображение этого DiagramShape. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | Имя этого DiagramShape. |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | Родительская страница этого DiagramShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | Угол поворота этого DiagramShape в градусах. |

| [x](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/x/) | Горизонтальное смещение этого DiagramShape от левого края страницы в пунктах, то есть его координата x. |
| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | Вертикальное смещение этого DiagramShape от нижнего края страницы в пунктах. |
