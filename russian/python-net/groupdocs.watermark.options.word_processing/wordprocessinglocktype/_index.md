## WordProcessingLockType class

Тип WordProcessingLockType раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [ALLOW_ONLY_REVISIONS](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessinglocktype/allow_only_revisions/) | Пользователь может только добавлять метки исправлений в документ. |
| [ALLOW_ONLY_COMMENTS](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessinglocktype/allow_only_comments/) | Пользователь может только изменять комментарии в документе. |
| [ALLOW_ONLY_FORM_FIELDS](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessinglocktype/allow_only_form_fields/) | Пользователь может только вводить данные в поля формы в документе. |
| [READ_ONLY](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessinglocktype/read_only/) | Весь документ доступен только для чтения. |
| [READ_ONLY_WITH_EDITABLE_CONTENT](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessinglocktype/read_only_with_editable_content/) | Документ доступен только для чтения, но всё содержимое, кроме водяного знака, помечено как редактируемое. |
| [NO_LOCK](/watermark/python-net/groupdocs.watermark.options.word_processing/wordprocessinglocktype/no_lock/) | Отключить любую блокировку водяного знака и документа. |
