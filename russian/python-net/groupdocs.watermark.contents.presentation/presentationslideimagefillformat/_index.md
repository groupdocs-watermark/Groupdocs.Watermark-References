## PresentationSlideImageFillFormat class

Представляет настройки формата заливки изображением для слайда в документе PowerPoint.

Тип PresentationSlideImageFillFormat предоставляет следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslideimagefillformat/background_image/) | Фоновое изображение; возвращает None, если изображение не задано. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | Изображение повторяется по фону, если установлено значение True; иначе оно растягивается. (наследовано от [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | Прозрачность фонового изображения в виде значения от 0.0 (непрозрачный) до 1.0 (полностью прозрачный). (наследовано от [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
