## PresentationImageFillFormat class

Представляет настройки формата заливки изображением в PowerPoint‑документе.

Тип PresentationImageFillFormat содержит следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | Фоновое изображение. Возвращает None, если изображение не задано. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | Изображение будет повторяться по фону, если установлено значение True; иначе оно будет растянуто. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | Прозрачность фонового изображения в виде значения от 0.0 (непрозрачное) до 1.0 (полностью прозрачное). |
