## PresentationShapeSettings class

Представляет настройки, которые можно применить к водяному знаку формы в документе PowerPoint.

Тип PresentationShapeSettings раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/__init__/) | Инициализирует новый экземпляр PresentationShapeSettings. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [is_locked](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/is_locked/) | Свойство указывает, запрещено ли редактирование фигуры в PowerPoint. |
| [protect_with_unreadable_characters](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/protect_with_unreadable_characters/) | Значение, указывающее, смешаны ли символы текстового водяного знака с нечитаемыми символами. |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | Описательный (альтернативный) текст, который будет связан с фигурой. (унаследовано от [`OfficeShapeSettings`](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/)) |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | Имя фигуры. (унаследовано от [`OfficeShapeSettings`](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/)) |
