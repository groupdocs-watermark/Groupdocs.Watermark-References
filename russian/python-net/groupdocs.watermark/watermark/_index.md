## Watermark class

Представляет водяной знак, который будет добавлен в документ.

Узнать больше

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Тип Watermark раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | Свойство, указывающее, учитываются ли при расчёте размер и координаты водяного знака отступы родителя. Если установлено в True, расчёты учитывают отступы родителя; по умолчанию значение False и отступы родителя игнорируются. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | Желаемая высота этого [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |

| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | Угол поворота этого [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) в градусах. |
