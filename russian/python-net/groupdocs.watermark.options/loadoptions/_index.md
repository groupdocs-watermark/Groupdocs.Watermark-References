## LoadOptions class

Представляет параметры загрузки документа при загрузке документа.

Узнать больше:
- Loading documents: https://docs.groupdocs.com/display/watermarknet/Loading+documents
- Load from local disk: https://docs.groupdocs.com/display/watermarknet/Load+from+local+disk
- Load from stream: https://docs.groupdocs.com/display/watermarknet/Load+from+stream
- Load document of specific format: https://docs.groupdocs.com/display/watermarknet/Load+document+of+specific+format
- Load password-protected document: https://docs.groupdocs.com/display/watermarknet/Load+password-protected+document

Тип LoadOptions предоставляет следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options/loadoptions/__init__/) | Инициализирует новый экземпляр класса LoadOptions. |
| [__init__](/watermark/python-net/groupdocs.watermark.options/loadoptions/__init__/#password) | Инициализирует новый экземпляр класса [`LoadOptions`](/watermark/python-net/groupdocs.watermark.options/loadoptions/) с указанным паролем. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [file_type](/watermark/python-net/groupdocs.watermark.options/loadoptions/file_type/) | Тип файла, указывающий его формат (например, docx, pdf, xlsx и т.д.). |
| [format_family](/watermark/python-net/groupdocs.watermark.options/loadoptions/format_family/) | Семейство форматов документа, указывающее его тип (например, Image, Pdf, Spreadsheet и т.д.). |
| [password](/watermark/python-net/groupdocs.watermark.options/loadoptions/password/) | Пароль для открытия зашифрованного документа. |
