## DiagramPreviewOptions class

Предоставляет параметры для установки требований и делегатов потоков при генерации предварительного просмотра документа Diagram.

Тип DiagramPreviewOptions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/__init__/#create_page_stream) | Инициализирует новый экземпляр класса [`DiagramPreviewOptions`](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/), закрывая выходной поток. |
| [__init__](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/__init__/#create_page_stream-release_page_stream) | Инициализирует новый экземпляр [`DiagramPreviewOptions`](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/), возвращая выходной поток клиенту для дальнейшего использования. |
