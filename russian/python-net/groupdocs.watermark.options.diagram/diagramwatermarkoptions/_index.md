## DiagramWatermarkOptions class

Представляет базовый класс для параметров добавления водяного знака в документ Visio.

Тип DiagramWatermarkOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [is_locked](/watermark/python-net/groupdocs.watermark.options.diagram/diagramwatermarkoptions/is_locked/) | Свойство указывает, запрещено ли редактирование фигуры в Visio. |

### Поля
| Поле | Описание |
| :- | :- |
| [DEFAULT](/watermark/python-net/groupdocs.watermark.options/watermarkoptions/default/) | Получает значение по умолчанию для класса. (наследуется от [`WatermarkOptions`](/watermark/python-net/groupdocs.watermark.options/watermarkoptions/)) |
