## Margins class

Представляет настройки полей для каждой стороны объекта.

Тип Margins раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | Инициализирует новый экземпляр класса [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/). |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | Инициализирует новый экземпляр класса [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) с указанными типом, расположением и размером. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | Нижнее поле. Представляет горизонтальное смещение от нижней границы родителя. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | Левое поле, выраженное как горизонтальное смещение от левой границы родителя. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | Тип поля, который определяет, как интерпретируются поля; установка нового значения автоматически сбрасывает все поля к их значениям по умолчанию (ноль). |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | Правое поле как горизонтальное смещение от правой границы родителя. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | Верхнее поле. |
