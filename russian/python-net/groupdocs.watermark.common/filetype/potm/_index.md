## POTM field

Файлы с расширением POTM являются шаблонами Microsoft PowerPoint с поддержкой макросов. Файлы POTM создаются в PowerPoint 2007 или более поздних версиях и содержат настройки по умолчанию, которые можно использовать для создания последующих файлов презентаций. Узнайте больше об этом формате файлов здесь.
