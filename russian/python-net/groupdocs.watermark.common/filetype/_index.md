## FileType class

Представляет тип файла.

Предоставляет методы для получения списка всех типов файлов, поддерживаемых [`GroupDocs.Watermark`](/watermark/python-net/groupdocs.watermark/watermark/).

Тип FileType раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#other) | Определяет, является ли текущий [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) тем же, что и указанный объект [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/). |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#obj) | Определяет, является ли текущий FileType тем же, что и указанный объект. |
| [equals_file_type](/watermark/python-net/groupdocs.watermark.common/filetype/equals_file_type/) |  |
| [equals_object](/watermark/python-net/groupdocs.watermark.common/filetype/equals_object/) |  |
| [from_extension](/watermark/python-net/groupdocs.watermark.common/filetype/from_extension/#extension) | Сопоставляет расширение файла типу файла. |
| [get_hash_code](/watermark/python-net/groupdocs.watermark.common/filetype/get_hash_code/) | Возвращает хеш-код для текущего объекта [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/). |
| [get_supported_file_types](/watermark/python-net/groupdocs.watermark.common/filetype/get_supported_file_types/) | Получает поддерживаемые типы файлов. |
| [to_string](/watermark/python-net/groupdocs.watermark.common/filetype/to_string/) | Возвращает строку, представляющую текущий объект. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [extension](/watermark/python-net/groupdocs.watermark.common/filetype/extension/) | Суффикс имени файла (включая точку "."), например, ".doc". |
| [file_format_name](/watermark/python-net/groupdocs.watermark.common/filetype/file_format_name/) | Название типа файла, например, "Microsoft Word Document". |
| [format_family](/watermark/python-net/groupdocs.watermark.common/filetype/format_family/) | Семейство форматов. |

### Пример

```python
from groupdocs.watermark.common import FileType

def list_supported_formats():
    # Перечислите все типы файлов, которые библиотека может открывать
    supported_file_types = FileType.get_supported_file_types()
    for file_type in sorted(supported_file_types, key=lambda x: x.extension):
        print(file_type)

if __name__ == "__main__":
    list_supported_formats()
```
