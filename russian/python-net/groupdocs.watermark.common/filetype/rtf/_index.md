## RTF field

Введённый и задокументированный Microsoft, Rich Text Format (RTF) представляет метод кодирования форматированного текста и графики для использования в приложениях. Этот формат облегчает кроссплатформенный обмен документами с другими продуктами Microsoft, тем самым обеспечивая совместимость. Узнайте больше об этом формате файлов здесь.
