## SpreadsheetPreviewOptions class

Предоставляет параметры для установки требований и делегатов потоков при генерации предварительного просмотра документа spreadsheet.

Тип SpreadsheetPreviewOptions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetpreviewoptions/__init__/#create_page_stream) | Инициализирует новый экземпляр класса SpreadsheetPreviewOptions, закрывая поток вывода. |
| [__init__](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetpreviewoptions/__init__/#create_page_stream-release_page_stream) | Инициализирует новый экземпляр класса SpreadsheetPreviewOptions, возвращая поток вывода клиенту для дальнейшего использования. |
