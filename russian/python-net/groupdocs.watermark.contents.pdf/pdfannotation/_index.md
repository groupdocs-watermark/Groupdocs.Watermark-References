## PdfAnnotation class

Представляет аннотацию в PDF-документе.

Узнать больше:
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

Тип PdfAnnotation раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | Тип этого [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |

| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/page/) | Родительская страница этого [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | Угол поворота этого PdfAnnotation в градусах. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | Ширина этой PdfAnnotation в пунктах. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | Горизонтальное смещение этой PdfAnnotation от левого края страницы в пунктах. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/y/) | Вертикальное смещение этой [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) от нижнего края листа в пунктах. |

| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | Изображение этой PdfShape. Возвращает None, если объект не содержит изображения. (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Текст этой [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
