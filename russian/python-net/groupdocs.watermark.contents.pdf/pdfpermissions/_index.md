## PdfPermissions class

Тип PdfPermissions раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [PRINT_DOCUMENT](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/print_document/) | Печатать содержимое. |
| [MODIFY_CONTENT](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/modify_content/) | Изменять содержимое. |
| [EXTRACT_CONTENT](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/extract_content/) | Копировать или иным способом извлекать текст и графику из документа. |
| [MODIFY_TEXT_ANNOTATIONS](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/modify_text_annotations/) | Добавлять или изменять текстовые аннотации. |
| [FILL_FORM](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/fill_form/) | Заполнять существующие интерактивные поля формы. |
| [EXTRACT_CONTENT_WITH_DISABILITIES](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/extract_content_with_disabilities/) | Извлекать текст и графику. |
| [ASSEMBLE_DOCUMENT](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/assemble_document/) | Собирать содержимое. |
| [PRINTING_QUALITY](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfpermissions/printing_quality/) | Печатать содержимое в представление, из которого можно создать точную цифровую копию PDF‑документа. |
