## PdfXObject class

Представляет XObject в PDF‑документе.

Узнать больше

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

Тип PdfXObject раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | Высота этого PdfXObject в пунктах. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | Родительская страница этого PdfXObject. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | Угол поворота этого PdfXObject в градусах. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | Ширина этого [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) в пунктах. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | Горизонтальное смещение этого PdfXObject от левого края страницы в пунктах. Координата x этого PdfXObject. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | Вертикальное смещение этого PdfXObject от нижнего края страницы в пунктах (координата y). |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | Коллекция отформатированных текстовых фрагментов этой [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | Изображение этой PdfShape. Возвращает None, если объект не содержит изображения. (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Текст этой [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
