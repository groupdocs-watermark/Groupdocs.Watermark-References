## PdfArtifact class

Представляет артефакт в PDF‑содержимом.

Узнать больше:
- https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithartifacts

Тип PdfArtifact раскрывает следующие члены:

| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/height/) | Высота этого [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) в пунктах. |
| [opacity](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/opacity/) | Непрозрачность этого [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/page/) | Родительская страница этого [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |

| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/x/) | Горизонтальное смещение этого PdfArtifact от левого края страницы в пунктах. |
