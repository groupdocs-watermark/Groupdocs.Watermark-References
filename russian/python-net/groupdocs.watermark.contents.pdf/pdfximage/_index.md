## PdfXImage class

Представляет XImage в pdf‑контенте.

Тип PdfXImage раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/height/) | Высота объекта. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/rotate_angle/) | Угол поворота объекта в градусах. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/width/) | Ширина объекта. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/x/) | Координата x объекта. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/y/) | Координата y объекта. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | Коллекция отформатированных текстовых фрагментов этой [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | Изображение этой PdfShape. Возвращает None, если объект не содержит изображения. (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | Родительская страница этого PdfXObject. (унаследовано от [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Текст этой [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (унаследовано от [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
