## WordProcessingPageSetup class

Представляет свойства печатной страницы для секции документа Word.

Тип WordProcessingPageSetup раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/bottom_margin/) | Размер нижнего поля в пунктах. |
| [different_first_page_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/different_first_page_header_footer/) | Флаг, указывающий, используется ли отдельный верхний/нижний колонтитул для первой страницы. |
| [height](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/height/) | Высота печатной страницы в пунктах. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/left_margin/) | Размер левого поля в пунктах. |
| [odd_and_even_pages_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/odd_and_even_pages_header_footer/) | Свойство указывает, используются ли разные верхние/нижние колонтитулы для нечётных и чётных страниц. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/right_margin/) | Размер правого поля в пунктах. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/top_margin/) | Размер верхнего поля в пунктах. |
| [width](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/width/) | Ширина печатной страницы в пунктах. |
