## SpreadsheetImageFillFormat class

Представляет настройки формата заливки изображением в документе Excel.

Тип SpreadsheetImageFillFormat содержит следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | Фоновое изображение. Возвращает None, если изображение не задано. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | Изображение мозаично размещается по фону, когда True; в противном случае изображение растягивается. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | Прозрачность фонового изображения в виде значения от 0.0 (непрозрачное) до 1.0 (полностью прозрачное). |
