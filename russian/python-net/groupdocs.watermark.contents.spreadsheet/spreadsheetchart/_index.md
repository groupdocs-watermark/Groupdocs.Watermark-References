## SpreadsheetChart class

Представляет диаграмму в документе Excel.

Тип SpreadsheetChart раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | Описательный (альтернативный) текст, связанный с этим [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | Высота этого SpreadsheetChart в пунктах. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | Гиперссылка, связанная с этим SpreadsheetChart. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | Идентификатор этого SpreadsheetChart. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | Настройки формата заполнения изображения этого SpreadsheetChart. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | Имя этого SpreadsheetChart. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | Ширина этого SpreadsheetChart в пунктах. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | Родительский лист этого SpreadsheetChart. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | Горизонтальное смещение этого SpreadsheetChart от левой границы листа в пунктах. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | Вертикальное смещение этого SpreadsheetChart от верхней границы листа в пунктах. |
