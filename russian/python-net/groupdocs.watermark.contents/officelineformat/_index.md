## OfficeLineFormat class

Представляет формат линии фигуры.

Тип OfficeLineFormat раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.contents/officelineformat/__init__/) | Инициализирует новый экземпляр [`OfficeLineFormat`](/watermark/python-net/groupdocs.watermark.contents/officelineformat/) . |

### Свойства
| Свойство | Описание |
| :- | :- |
| [color](/watermark/python-net/groupdocs.watermark.contents/officelineformat/color/) | Цвет линии. |
| [dash_style](/watermark/python-net/groupdocs.watermark.contents/officelineformat/dash_style/) | Шаблон точек и тире для линии. |

| [line_style](/watermark/python-net/groupdocs.watermark.contents/officelineformat/line_style/) | Стиль линии. |

| [weight](/watermark/python-net/groupdocs.watermark.contents/officelineformat/weight/) | Толщина кисти, которая обводит путь формы, выраженная в пунктах (по умолчанию 0.75). |
