## OfficeImageEffects class

Представляет эффекты, которые можно применить к изображению водяного знака для офисного содержимого.

Тип OfficeImageEffects раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Настройки формата линии для границы изображения. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | Яркость изображения. Должна быть числом с плавающей точкой от 0.0 (самая темная) до 1.0 (самая яркая). Значение по умолчанию — 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | Значение цвета изображения, которое будет рассматриваться как прозрачное. Значение по умолчанию — полностью прозрачный цвет. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Контраст для указанного изображения. Должен быть числом с плавающей точкой от 0.0 (наименьший контраст) до 1.0 (наибольший контраст). Значение по умолчанию — 0.5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | Свойство указывает, будет ли изображение отображаться в режиме градаций серого. |
