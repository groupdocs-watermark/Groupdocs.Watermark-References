## OfficeShapeSettings class

Представляет настройки, которые можно применить к фигурному водяному знаку для офисного содержимого.

Тип OfficeShapeSettings раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | Описательный (альтернативный) текст, который будет связан с фигурой. |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | Имя фигуры. |
