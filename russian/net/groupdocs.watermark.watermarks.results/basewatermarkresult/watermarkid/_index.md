## BaseWatermarkResult.WatermarkId property

Уникальный идентификатор водяного знака для изменения водяного знака в документе с помощью методов Update или Delete. Это свойство будет установлено автоматически после вызова метода Add. Если это свойство было сохранено ранее, его можно установить вручную для манипуляции водяным знаком.

```csharp
public string WatermarkId { get; }
```
