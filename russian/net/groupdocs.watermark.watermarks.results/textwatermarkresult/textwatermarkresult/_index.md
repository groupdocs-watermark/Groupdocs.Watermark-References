## TextWatermarkResult constructor

Инициализирует объект TextWatermarkResult с идентификатором водяного знака, полученным после процесса поиска. Этот уникальный идентификатор используется для поиска дополнительных свойств этого водяного знака из слоя информации о водяных знаках документа.

```csharp
public TextWatermarkResult(string watermarkId)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| watermarkId | String | Уникальный идентификатор водяного знака, полученный методом подписи или поиска. |
