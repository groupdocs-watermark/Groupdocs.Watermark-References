## DiagramWatermarkOptions.IsLocked property

Получает или задает значение, указывающее, запрещено ли редактирование фигуры в Visio.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Если значение равно true, редактирование фигур будет запрещено.

### Примечания

По умолчанию значение равно false, фигуру можно редактировать в Visio.
