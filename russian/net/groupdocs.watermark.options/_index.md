Пространство имён предоставляет классы для указания дополнительных параметров при работе с документами и водяными знаками.

## Классы

| Класс | Описание |
| --- | --- |
| [CreatePageStream](./createpagestream) | Представляет метод, который возвращает поток для записи данных предварительного просмотра страницы. |
| [LoadOptions](./loadoptions) | Представляет параметры загрузки документа при загрузке документа. |
| [OoxmlLoadOptions](./ooxmlloadoptions) | Представляет параметры загрузки документа для OOXML‑документа. |
| [PreviewOptions](./previewoptions) | Предоставляет параметры для установки требований и делегатов потоков для генерации предварительного просмотра. |
| [ReleasePageStream](./releasepagestream) | Представляет метод, который освобождает поток, созданный делегатом [`CreatePageStream`](../groupdocs.watermark.options/createpagestream). |
| [SaveOptions](./saveoptions) | Представляет параметры сохранения документа при сохранении документа. |
| [WatermarkOptions](./watermarkoptions) | Представляет параметры добавления водяного знака при добавлении водяного знака в документ. |
## Интерфейсы
