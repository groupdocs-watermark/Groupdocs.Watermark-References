## DiagramWatermarkPlacementType enumeration

Указывает, на какие страницы следует добавить водяной знак.

```csharp
public enum DiagramWatermarkPlacementType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ForegroundPages | `0` | Водяной знак должен добавляться только на передние страницы. |
| BackgroundPages | `1` | Водяной знак должен быть добавлен только к фоновым страницам. |
| AllPages | `2` | Водяной знак должен быть добавлен ко всем страницам. |
| SeparateBackgrounds | `3` | Отдельные фоновые страницы с водяным знаком должны быть созданы и назначены всем страницам без фона. |
| Default | `0` | То же, что и ForegroundPages. |
