## Margins.MarginType property

Получает или задает тип поля. Установка нового значения этого свойства автоматически возвращает все поля к их значениям по умолчанию (ноль).

```csharp
public MarginType MarginType { get; set; }
```

### Property Value

Значение, определяющее, как следует интерпретировать отступы.

### Примечания

Значение по умолчанию — Absolute
