## TileOptions.RotateAroundOrigin property

Получает или задает значение, указывающее, следует ли вращать повторяющиеся водяные знаки вокруг центра документа.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true`, если повторяющиеся водяные знаки должны вращаться вокруг нижней левой точки документа; иначе `false`, в этом случае вращение будет относительно левого края документа. По умолчанию `false`.
