## Color Inequality operator

Определяет, отличаются ли две указанные структуры [`Color`](../../color).

```csharp
public static bool operator !=(Color left, Color right)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| left | Color | [`Color`](../../color), находящийся слева от оператора неравенства. |
| right | Color | Элемент [`Color`](../../color), который находится справа от оператора неравенства. |

### Возвращаемое значение

Истина, если две структуры [`Color`](../../color) различны; в противном случае — ложь.
