## Color Equality operator

Определяет, являются ли две указанные структуры [`Color`](../../color) эквивалентными.

```csharp
public static bool operator ==(Color left, Color right)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| left | Color | [`Color`](../../color), который находится слева от оператора равенства. |
| right | Color | [`Color`](../../color), который находится справа от оператора равенства. |

### Возвращаемое значение

Истина, если две структуры [`Color`](../../color) равны; иначе — ложь.
