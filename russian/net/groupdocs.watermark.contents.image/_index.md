Пространство имён предоставляет классы для добавления водяных знаков к изображениям разных форматов.

## Классы

| Класс | Описание |
| --- | --- |
| [GifImageContent](./gifimagecontent) | Представляет GIF‑изображение, на которое можно разместить водяной знак. |
| [ImageContent](./imagecontent) | Представляет изображение, на которое можно разместить водяной знак. |
| [ImageFrame](./imageframe) | Представляет кадр изображения, на который можно разместить водяной знак. |
| [ImageFrameCollection](./imageframecollection) | Представляет коллекцию кадров в многокадровом изображении. |
| [MultiframeImageContent](./multiframeimagecontent) | Представляет многокадровое изображение, на которое можно разместить водяной знак. |
| [SystemDrawingImageFrame](./systemdrawingimageframe) | Представляет кадр изображения, на который можно разместить водяной знак (реализация System.Drawing). |
| [SystemDrawingImageFrameCollection](./systemdrawingimageframecollection) | Представляет коллекцию кадров в многокадровом изображении. |
| [TiffImageContent](./tiffimagecontent) | Представляет TIFF‑изображение, на которое можно разместить водяной знак. |
| [WatermarkableImage](./watermarkableimage) | Представляет изображение внутри документа. |
| [WatermarkableImageCollection](./watermarkableimagecollection) | Представляет коллекцию изображений, найденных в документе. |
