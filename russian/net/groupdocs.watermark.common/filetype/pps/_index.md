## FileType.PPS field

PPS, PowerPoint Slide Show, файлы создаются с помощью Microsoft PowerPoint для показа слайдов. Чтение и создание файлов PPS поддерживается Microsoft PowerPoint 97‑2003. Узнайте больше об этом формате файлов [здесь](https://wiki.fileformat.com/presentation/pps/).
