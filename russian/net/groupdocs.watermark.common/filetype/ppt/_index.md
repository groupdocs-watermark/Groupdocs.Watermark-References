## FileType.PPT field

Файл с расширением PPT представляет собой файл PowerPoint, содержащий набор слайдов для отображения в виде слайд‑шоу. Он определяет двоичный формат файлов, используемый Microsoft PowerPoint 97‑2003. Узнайте больше об этом формате файлов [здесь](https://wiki.fileformat.com/presentation/ppt/).
