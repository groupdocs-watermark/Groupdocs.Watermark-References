## PresentationWatermarkBaseSlideOptions.IsLocked property

Получает или задает значение, указывающее, запрещено ли редактирование фигуры в PowerPoint.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Если значение равно `true`, редактирование фигур будет запрещено. По умолчанию значение `false`, фигуру можно редактировать в PowerPoint.
