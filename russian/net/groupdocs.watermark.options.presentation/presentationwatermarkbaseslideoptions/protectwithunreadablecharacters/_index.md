## PresentationWatermarkBaseSlideOptions.ProtectWithUnreadableCharacters property

Получает или задает значение, указывающее, смешаны ли символы текстового водяного знака с нечитаемыми символами.

```csharp
public bool ProtectWithUnreadableCharacters { get; set; }
```

### Property Value

Значение, указывающее, смешаны ли символы текстового водяного знака с нечитаемыми символами.

### Примечания

Эта защита применяется только тогда, когда значение свойства [`IsLocked`](../islocked) равно `true`.
