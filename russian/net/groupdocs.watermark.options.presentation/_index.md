Пространство имён предоставляет классы для указания дополнительных параметров при работе сarks и документами PowerPoint.

## Классы

| Класс | Описание |
| --- | --- |
| [PresentationImageEffects](./presentationimageeffects) | Представляет эффекты, которые могут быть применены к изображению водяного знака для документа PowerPoint. |
| [PresentationLoadOptions](./presentationloadoptions) | Представляет параметры загрузки документа для документа Presentation. |
| [PresentationPreviewOptions](./presentationpreviewoptions) | Предоставляет параметры для установки требований и делегатов потоков при генерации предварительного просмотра документа Presentation. |
| [PresentationSaveOptions](./presentationsaveoptions) | Представляет параметры сохранения документа при сохранении документа Presentation. |
| [PresentationTextEffects](./presentationtexteffects) | Представляет эффекты, которые могут быть применены к текстовому водяному знаку для содержимого PowerPoint. |
| [PresentationWatermarkBaseSlideOptions](./presentationwatermarkbaseslideoptions) | Базовый класс для параметров добавления водяного знака в документ Presentation. |
| [PresentationWatermarkLayoutSlideOptions](./presentationwatermarklayoutslideoptions) | Представляет параметры при добавлении водяного знака в слайд макета документа Presentation. |
| [PresentationWatermarkMasterHandoutSlideOptions](./presentationwatermarkmasterhandoutslideoptions) | Представляет параметры при добавлении водяного знака в слайд раздаточного листа мастера документа Presentation. |
| [PresentationWatermarkMasterNotesSlideOptions](./presentationwatermarkmasternotesslideoptions) | Представляет параметры при добавлении водяного знака в слайд заметок мастера документа Presentation. |
| [PresentationWatermarkMasterSlideOptions](./presentationwatermarkmasterslideoptions) | Представляет параметры при добавлении водяного знака в мастер‑слайд документа Presentation. |
| [PresentationWatermarkNoteSlideOptions](./presentationwatermarknoteslideoptions) | Представляет параметры при добавлении водяного знака в слайд заметки документа Presentation. |
| [PresentationWatermarkOptions](./presentationwatermarkoptions) | Базовый класс для параметров добавления водяного знака в документ Presentation. |
| [PresentationWatermarkSlideOptions](./presentationwatermarkslideoptions) | Представляет параметры при добавлении водяного знака в слайд документа Presentation. |
