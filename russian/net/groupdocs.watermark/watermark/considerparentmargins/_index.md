## Watermark.ConsiderParentMargins property

Получает или задает значение, указывающее, рассчитываются ли размер и координаты водяного знака с учётом отступов родителя.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Если значение истинно, размер и координаты водяного знака рассчитываются с учётом полей родителя. По умолчанию значение ложно, поля родителя игнорируются.
