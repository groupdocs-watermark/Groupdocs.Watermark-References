Пространство имён предоставляет различные классы исключений.

## Классы

| Класс | Описание |
| --- | --- |
| [DetachedImageException](./detachedimageexception) | Исключение, которое выбрасывается при работе с отсоединённым изображением. |
| [EncryptionIsNotSupportedException](./encryptionisnotsupportedexception) | Исключение, которое выбрасывается, когда шифрование содержимого не поддерживается. |
| [FontNotFoundException](./fontnotfoundexception) | Исключение, которое выбрасывается, когда запрашиваемый шрифт не найден. |
| [ImageEffectsForTextWatermarkException](./imageeffectsfortextwatermarkexception) | Исключение, которое выбрасывается, когда [`OfficeImageEffects`](../groupdocs.watermark.contents/officeimageeffects) передан для [`TextWatermark`](../groupdocs.watermark.watermarks/textwatermark). |
| [InvalidPasswordException](./invalidpasswordexception) | Исключение, которое выбрасывается, когда предоставленный пароль неверен. |
| [PreviewNotSupportedException](./previewnotsupportedexception) | Исключение, которое выбрасывается, когда невозможно сгенерировать изображение предварительного просмотра для содержимого. |
| [TextEffectsForImageWatermarkException](./texteffectsforimagewatermarkexception) | Исключение, которое выбрасывается, когда [`OfficeTextEffects`](../groupdocs.watermark.contents/officetexteffects) передан для [`ImageWatermark`](../groupdocs.watermark.watermarks/imagewatermark). |
| [UnexpectedDocumentStructureException](./unexpecteddocumentstructureexception) | Исключение, которое выбрасывается, когда содержимое не может быть разобрано из‑за неожиданной структуры. |
| [UnknownLoadOptionsTypeException](./unknownloadoptionstypeexception) | Исключение, которое выбрасывается, когда документ не может быть загружен с предоставленными [`LoadOptions`](../groupdocs.watermark.options/loadoptions). |
| [UnknownWatermarkOptionsTypeException](./unknownwatermarkoptionstypeexception) | Исключение, которое выбрасывается, когда водяной знак не может быть добавлен с предоставленными [`WatermarkOptions`](../groupdocs.watermark.options/watermarkoptions). |
| [UnsupportedFileTypeException](./unsupportedfiletypeexception) | Исключение, которое выбрасывается, когда файл не может быть загружен. |
| [WatermarkException](./watermarkexception) | Представляет базовое исключение в продукте **GroupDocs.Watermark**. |
