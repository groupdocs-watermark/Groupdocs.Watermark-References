## SpreadsheetWatermarkBaseOptions.IsLocked property

Получает или задает значение, указывающее, запрещено ли редактирование фигуры в Excel.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Если значение истинно, редактирование фигуры будет запрещено. По умолчанию значение ложно, фигуру можно редактировать в Excel.
