## SpreadsheetPreviewOptions.OnlyDataArea property

Получает или задает флаг, указывающий рендерить только область данных без заголовков, нижних колонтитулов и полей.

```csharp
public bool OnlyDataArea { get; set; }
```

### Property Value

Флаг для рендеринга только области данных без заголовков, нижних колонтитулов и полей.

### Примечания

Этот флаг приводит к рендерингу всего листа на одной странице. Значение по умолчанию — `false`.
