Пространство имён предоставляет классы для указания дополнительных параметров при работе с водяными знаками и документами Excel.

## Классы

| Класс | Описание |
| --- | --- |
| [SpreadsheetBackgroundWatermarkOptions](./spreadsheetbackgroundwatermarkoptions) | Представляет параметры при добавлении водяного знака в качестве фона листа таблицы Spreadsheet. |
| [SpreadsheetImageEffects](./spreadsheetimageeffects) | Представляет эффекты, которые можно применить к изображению водяного знака для документа Excel. |
| [SpreadsheetLoadOptions](./spreadsheetloadoptions) | Представляет параметры загрузки документа для документа Spreadsheet. |
| [SpreadsheetPreviewOptions](./spreadsheetpreviewoptions) | Предоставляет параметры для установки требований и делегатов потоков при генерации предварительного просмотра документа Spreadsheet. |
| [SpreadsheetSaveOptions](./spreadsheetsaveoptions) | Представляет параметры сохранения документа при сохранении документа Spreadsheet. |
| [SpreadsheetShapeSettings](./spreadsheetshapesettings) | Представляет настройки, которые могут быть применены к водяному знаку в виде фигуры для документа Excel. |
| [SpreadsheetTextEffects](./spreadsheettexteffects) | Представляет эффекты, которые могут быть применены к текстовому водяному знаку для документа Excel. |
| [SpreadsheetWatermarkBaseOptions](./spreadsheetwatermarkbaseoptions) | Базовый класс для параметров добавления водяного знака в документ Spreadsheet. |
| [SpreadsheetWatermarkHeaderFooterOptions](./spreadsheetwatermarkheaderfooteroptions) | Представляет параметры при добавлении водяного знака в верхний/нижний колонтитул документа Spreadsheet. |
| [SpreadsheetWatermarkModernWordArtOptions](./spreadsheetwatermarkmodernwordartoptions) | Представляет параметры при добавлении современного ворд-арт водяного знака в лист Spreadsheet. |
| [SpreadsheetWatermarkShapeOptions](./spreadsheetwatermarkshapeoptions) | Представляет параметры при добавлении фигурного водяного знака в лист Spreadsheet. |
