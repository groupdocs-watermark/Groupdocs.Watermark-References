## WordProcessingVerticalAlignment enumeration

Указывает вертикальное выравнивание плавающего объекта.

```csharp
public enum WordProcessingVerticalAlignment
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Inline | `-1` | Не документировано. Похоже, это возможное значение для плавающих абзацев и таблиц. |
| None | `0` | Объект явно позиционируется с использованием его y‑координаты. |
| Top | `1` | Указывает, что объект находится в верхней части базы вертикального выравнивания. |
| Center | `2` | Указывает, что объект центрирован относительно базы вертикального выравнивания. |
| Bottom | `3` | Указывает, что объект находится в нижней части базы вертикального выравнивания. |
| Inside | `4` | Указывает, что объект находится внутри базовой горизонтальной линии выравнивания. |
| Outside | `5` | Указывает, что объект находится за пределами базы вертикального выравнивания. |
