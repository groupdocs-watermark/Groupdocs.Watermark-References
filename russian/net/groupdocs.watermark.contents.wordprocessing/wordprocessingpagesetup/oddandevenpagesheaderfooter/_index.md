## WordProcessingPageSetup.OddAndEvenPagesHeaderFooter property

Получает или задает значение, указывающее, используются ли разные верхние/нижние колонтитулы для нечётных и чётных страниц. Примечание: изменение этого свойства влияет на все разделы в содержимом.

```csharp
public bool OddAndEvenPagesHeaderFooter { get; set; }
```

### Property Value

True, если для нечётных и чётных страниц используются разные верхние/нижние колонтитулы; в противном случае — false.
