## WordProcessingPageSetup.DifferentFirstPageHeaderFooter property

Получает или задает значение, указывающее, используется ли иной верхний/нижний колонтитул для первой страницы.

```csharp
public bool DifferentFirstPageHeaderFooter { get; set; }
```

### Property Value

True, если для первой страницы используется другой верхний/нижний колонтитул; в противном случае — false.
