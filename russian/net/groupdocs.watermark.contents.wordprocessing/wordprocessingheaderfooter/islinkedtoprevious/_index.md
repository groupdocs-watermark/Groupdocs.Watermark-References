## WordProcessingHeaderFooter.IsLinkedToPrevious property

Получает или задает значение, указывающее, связан ли этот верхний/нижний колонтитул с соответствующим колонтитулом в предыдущем разделе.

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

True, если этот верхний/нижний колонтитул связан с соответствующим колонтитулом в предыдущем разделе; в противном случае — false.

### Примечания

По умолчанию — true. Обратите внимание, что при связывании верхнего или нижнего колонтитула его содержимое очищается.
