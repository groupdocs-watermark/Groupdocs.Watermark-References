## WordProcessingWatermarkPagesOptions.PageNumbers property

Получает или задает номера страниц, на которые добавляется водяной знак.

```csharp
public int[] PageNumbers { get; set; }
```

### Property Value

Номера страниц, к которым добавляется водяной знак.

### Примечания

Все числа должны быть больше или равны 1. Это свойство используется только при добавлении водяного знака в документ. Если это значение `null` или пусто, водяной знак будет добавлен на все страницы.
