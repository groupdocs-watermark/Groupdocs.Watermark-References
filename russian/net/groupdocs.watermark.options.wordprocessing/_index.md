Пространство имён предоставляет классы для указания дополнительных параметров при работе с водяными знаками и документами Word.

## Классы

| Класс | Описание |
| --- | --- |
| [WordProcessingImageEffects](./wordprocessingimageeffects) | Представляет эффекты, которые можно применить к изображению водяного знака для документа Word. |
| [WordProcessingLoadOptions](./wordprocessingloadoptions) | Представляет параметры загрузки документа для документа Word. |
| [WordProcessingPreviewOptions](./wordprocessingpreviewoptions) | Предоставляет параметры для установки требований и делегатов потоков при генерации предварительного просмотра документа WordProcessing. |
| [WordProcessingSaveOptions](./wordprocessingsaveoptions) | Представляет параметры сохранения документа при сохранении документа Word. |
| [WordProcessingTextEffects](./wordprocessingtexteffects) | Представляет эффекты, которые можно применить к текстовому водяному знаку для документа Word. |
| [WordProcessingWatermarkBaseOptions](./wordprocessingwatermarkbaseoptions) | Базовый класс для параметров добавления водяного знака в документ Word. |
| [WordProcessingWatermarkHeaderFooterOptions](./wordprocessingwatermarkheaderfooteroptions) | Представляет параметры при добавлении водяного знака в заголовок/нижний колонтитул раздела Word. |
| [WordProcessingWatermarkPagesOptions](./wordprocessingwatermarkpagesoptions) | Представляет параметры при добавлении водяного знака на страницы документа Word. |
| [WordProcessingWatermarkSectionOptions](./wordprocessingwatermarksectionoptions) | Представляет параметры при добавлении фигурного водяного знака в раздел документа Word. |
## Интерфейсы
