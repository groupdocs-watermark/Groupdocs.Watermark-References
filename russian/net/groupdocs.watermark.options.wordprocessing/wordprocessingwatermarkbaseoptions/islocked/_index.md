## WordProcessingWatermarkBaseOptions.IsLocked property

Получает или задает значение, указывающее, запрещено ли редактирование формы в Word.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Если значение `true`, редактирование фигуры будет запрещено. По умолчанию значение `false`, фигуру можно редактировать в Word.
