Пространство имён предоставляет классы для указания дополнительных параметров при работе с водяными знаками и PDF‑документами.

## Классы

| Класс | Описание |
| --- | --- |
| [PdfAnnotationWatermarkOptions](./pdfannotationwatermarkoptions) | Представляет параметры добавления водяного знака при добавлении аннотационного водяного знака в PDF‑документ. |
| [PdfArtifactWatermarkOptions](./pdfartifactwatermarkoptions) | Представляет параметры добавления водяного знака при добавлении артефактного водяного знака в PDF‑документ. |
| [PdfLoadOptions](./pdfloadoptions) | Представляет параметры загрузки документа для PDF‑документа. |
| [PdfPreviewOptions](./pdfpreviewoptions) | Предоставляет параметры для установки требований и делегатов потоков при генерации предварительного просмотра PDF‑документа. |
| [PdfSaveOptions](./pdfsaveoptions) | Представляет параметры сохранения документа при сохранении PDF‑документа. |
| [PdfWatermarkOptions](./pdfwatermarkoptions) | Базовый класс для параметров добавления водяного знака в PDF‑документ. |
| [PdfXObjectWatermarkOptions](./pdfxobjectwatermarkoptions) | Представляет параметры добавления водяного знака при добавлении XObject‑водяного знака в PDF‑документ. |
