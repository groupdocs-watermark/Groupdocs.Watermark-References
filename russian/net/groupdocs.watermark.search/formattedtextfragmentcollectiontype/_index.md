## FormattedTextFragmentCollectionType enumeration

Указывает количество элементов, которое может содержать коллекция фрагментов форматированного текста.

```csharp
public enum FormattedTextFragmentCollectionType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| UnlimitedFragments | `0` | Разрешено использовать несколько стилей, коллекция может содержать неограниченное количество фрагментов. |
| SingleFragment | `1` | Весь текст может быть отформатирован одним стилем, коллекция может содержать только один фрагмент. |
| NoFormattedText | `2` | Родительский объект не поддерживает форматирование текста, коллекция всегда пуста. |
