Пространство имён предоставляет классы для работы с документами любого поддерживаемого типа.

## Классы

| Класс | Описание |
| --- | --- |
| [Content](./content) | Представляет содержимое, в котором может быть размещён водяной знак. |
| [ContentPart](./contentpart) | Представляет любую логическую часть содержимого (страницу, кадр, заголовок или всё содержимое), где может быть размещён водяной знак. |
| [OfficeImageEffects](./officeimageeffects) | Представляет эффекты, которые могут быть применены к изображению‑водяному знаку для офисного контента. |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | Представляет настройки формата заполнения изображения в любом поддерживаемом офисном контенте. |
| [OfficeLineFormat](./officelineformat) | Представляет формат линии фигуры. |
| [OfficeShapeSettings](./officeshapesettings) | Представляет настройки, которые могут быть применены к фигурному водяному знаку для офисного контента. |
| [OfficeTextEffects](./officetexteffects) | Представляет эффекты, которые могут быть применены к текстовому водяному знаку для офисного контента. |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [OfficeDashStyle](./officedashstyle) | Представляет стиль пунктирной линии. |
| [OfficeHeaderFooterType](./officeheaderfootertype) | Определяет тип верхнего или нижнего колонтитула. |
| [OfficeLineStyle](./officelinestyle) | Представляет составной стиль линии [`OfficeLineFormat`](../groupdocs.watermark.contents/officelineformat). |
