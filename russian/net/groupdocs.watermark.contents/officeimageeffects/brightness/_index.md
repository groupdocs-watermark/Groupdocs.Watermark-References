## OfficeImageEffects.Brightness property

Получает или задает яркость изображения. Значение этого свойства должно быть числом от 0.0 (самая темная) до 1.0 (самая яркая).

```csharp
public double Brightness { get; set; }
```

### Property Value

Значение по умолчанию — 0.5.
