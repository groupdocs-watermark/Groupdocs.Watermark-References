この名前空間は、ドキュメントと透かしを操作する際に追加オプションを指定するためのクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [CreatePageStream](./createpagestream) | ページプレビュー データを書き込むためのストリームを返すメソッドを表します。 |
| [LoadOptions](./loadoptions) | ドキュメントを読み込む際のドキュメント読み込みオプションを表します。 |
| [OoxmlLoadOptions](./ooxmlloadoptions) | OOXML ドキュメント用のドキュメント読み込みオプションを表します。 |
| [PreviewOptions](./previewoptions) | プレビュー生成のための要件設定とストリームデリゲートのオプションを提供します。 |
| [ReleasePageStream](./releasepagestream) | [`CreatePageStream`](../groupdocs.watermark.options/createpagestream) デリゲートによって作成されたストリームを解放するメソッドを表します。 |
| [SaveOptions](./saveoptions) | ドキュメントを保存する際の保存オプションを表します。 |
| [WatermarkOptions](./watermarkoptions) | ドキュメントに透かしを追加する際の追加オプションを表します。 |
