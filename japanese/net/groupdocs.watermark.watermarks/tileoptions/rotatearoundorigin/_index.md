## TileOptions.RotateAroundOrigin property

繰り返し透かしを文書の中心を基準に回転させるかどうかを示す値を取得または設定します。

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` は、繰り返しの透かしを文書の左下点を基準に回転させる場合です。そうでない場合は `false` となり、その場合の回転は文書の左端を基準とします。デフォルトは `false` です。
