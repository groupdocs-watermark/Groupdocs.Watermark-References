この名前空間は、さまざまな形式の画像に透かしを追加するためのクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [GifImageContent](./gifimagecontent) | 透かしを配置できる GIF 画像を表します。 |
| [ImageContent](./imagecontent) | 透かしを配置できる画像を表します。 |
| [ImageFrame](./imageframe) | 透かしを配置できる画像フレームを表します。 |
| [ImageFrameCollection](./imageframecollection) | マルチフレーム画像内のフレームコレクションを表します。 |
| [MultiframeImageContent](./multiframeimagecontent) | 透かしを配置できるマルチフレーム画像を表します。 |
| [SystemDrawingImageFrame](./systemdrawingimageframe) | 透かしを配置できる画像フレームを表します（System.Drawing 実装）。 |
| [SystemDrawingImageFrameCollection](./systemdrawingimageframecollection) | マルチフレーム画像内のフレームコレクションを表します。 |
| [TiffImageContent](./tiffimagecontent) | 透かしを配置できる TIFF 画像を表します。 |
| [WatermarkableImage](./watermarkableimage) | ドキュメント内の画像を表します。 |
| [WatermarkableImageCollection](./watermarkableimagecollection) | ドキュメント内で見つかった画像のコレクションを表します。 |
