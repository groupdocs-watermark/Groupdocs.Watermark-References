## DiagramWatermarkOptions.IsLocked property

Visio のシェイプ編集が禁止されているかどうかを示す値を取得または設定します。

```csharp
public bool IsLocked { get; set; }
```

### Property Value

値が true の場合、シェイプの編集は禁止されます。

### 備考

デフォルトでは、値は false で、Visio でシェイプを編集できます。
