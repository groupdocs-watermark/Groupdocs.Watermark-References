この名前空間は、サポートされている任意のタイプのドキュメントを操作するためのクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [Content](./content) | 透かしを配置できるコンテンツを表します。 |
| [ContentPart](./contentpart) | 透かしを配置できるコンテンツの任意の論理部分（ページ、フレーム、ヘッダー、または全体のコンテンツ）を表します。 |
| [OfficeImageEffects](./officeimageeffects) | オフィス コンテンツの画像透かしに適用できる効果を表します。 |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | サポートされているすべてのオフィス コンテンツにおける画像塗りつぶし形式設定を表します。 |
| [OfficeLineFormat](./officelineformat) | 図形の線形式を表します。 |
| [OfficeShapeSettings](./officeshapesettings) | オフィス コンテンツの図形透かしに適用できる設定を表します。 |
| [OfficeTextEffects](./officetexteffects) | オフィス コンテンツのテキスト透かしに適用できる効果を表します。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [OfficeDashStyle](./officedashstyle) | 破線スタイルを表します。 |
| [OfficeHeaderFooterType](./officeheaderfootertype) | ヘッダーまたはフッターのタイプを識別します。 |
| [OfficeLineStyle](./officelinestyle) | [`OfficeLineFormat`](../groupdocs.watermark.contents/officelineformat) の複合線スタイルを表します。 |
