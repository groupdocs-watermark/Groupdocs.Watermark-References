この名前空間は、透かしと Excel ドキュメントを操作する際に追加オプションを指定するためのクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [SpreadsheetBackgroundWatermarkOptions](./spreadsheetbackgroundwatermarkoptions) | スプレッドシートのワークシートに透かしを背景として追加する際のオプションを表します。 |
| [SpreadsheetImageEffects](./spreadsheetimageeffects) | Excel 文書の画像透かしに適用できる効果を表します。 |
| [SpreadsheetLoadOptions](./spreadsheetloadoptions) | スプレッドシート文書の読み込みオプションを表します。 |
| [SpreadsheetPreviewOptions](./spreadsheetpreviewoptions) | スプレッドシート文書のプレビュー生成の要件とストリームデリゲートを設定するオプションを提供します。 |
| [SpreadsheetSaveOptions](./spreadsheetsaveoptions) | Spreadsheet ドキュメントを保存する際のドキュメント保存オプションを表します。 |
| [SpreadsheetShapeSettings](./spreadsheetshapesettings) | Excel ドキュメントのシェイプ透かしに適用できる設定を表します。 |
| [SpreadsheetTextEffects](./spreadsheettexteffects) | Excel ドキュメントのテキスト透かしに適用できる効果を表します。 |
| [SpreadsheetWatermarkBaseOptions](./spreadsheetwatermarkbaseoptions) | Spreadsheet ドキュメントに透かしを追加するオプションの基底クラスです。 |
| [SpreadsheetWatermarkHeaderFooterOptions](./spreadsheetwatermarkheaderfooteroptions) | Spreadsheet のヘッダー/フッターに透かしを追加する際のオプションを表します。 |
| [SpreadsheetWatermarkModernWordArtOptions](./spreadsheetwatermarkmodernwordartoptions) | Spreadsheet ワークシートにモダンなワードアート透かしを追加する際のオプションを表します。 |
| [SpreadsheetWatermarkShapeOptions](./spreadsheetwatermarkshapeoptions) | Spreadsheet ワークシートにシェイプ透かしを追加する際のオプションを表します。 |
