## Watermark.ConsiderParentMargins property

透かしのサイズと座標が親の余白を考慮して計算されるかどうかを示す値を取得または設定します。

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

値が true の場合、ウォーターマークのサイズと座標は親の余白を考慮して計算されます。デフォルトでは、値は false で、親の余白は無視されます。
