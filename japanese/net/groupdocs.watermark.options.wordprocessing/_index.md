この名前空間は、透かしと Word ドキュメントを操作する際に追加オプションを指定するためのクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [WordProcessingImageEffects](./wordprocessingimageeffects) | Word 文書の画像透かしに適用できる効果を表します。 |
| [WordProcessingLoadOptions](./wordprocessingloadoptions) | Word 文書の読み込みオプションを表します。 |
| [WordProcessingPreviewOptions](./wordprocessingpreviewoptions) | WordProcessing ドキュメントのプレビュー生成のための要件とストリーム デリゲートを設定するオプションを提供します。 |
| [WordProcessingSaveOptions](./wordprocessingsaveoptions) | Word 文書を保存する際のドキュメント保存オプションを表します。 |
| [WordProcessingTextEffects](./wordprocessingtexteffects) | Word 文書のテキスト透かしに適用できる効果を表します。 |
| [WordProcessingWatermarkBaseOptions](./wordprocessingwatermarkbaseoptions) | Word 文書に透かしを追加するオプションの基底クラスです。 |
| [WordProcessingWatermarkHeaderFooterOptions](./wordprocessingwatermarkheaderfooteroptions) | Word セクションのヘッダー/フッターに透かしを追加する際のオプションを表します。 |
| [WordProcessingWatermarkPagesOptions](./wordprocessingwatermarkpagesoptions) | Word 文書のページに透かしを追加する際のオプションを表します。 |
| [WordProcessingWatermarkSectionOptions](./wordprocessingwatermarksectionoptions) | Word 文書のセクションにシェイプ透かしを追加する際のオプションを表します。 |
