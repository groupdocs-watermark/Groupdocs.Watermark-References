この名前空間は、さまざまな例外クラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [DetachedImageException](./detachedimageexception) | 切り離された画像を操作するときにスローされる例外です。 |
| [EncryptionIsNotSupportedException](./encryptionisnotsupportedexception) | コンテンツの暗号化がサポートされていない場合にスローされる例外です。 |
| [FontNotFoundException](./fontnotfoundexception) | 要求されたフォントが見つからない場合にスローされる例外です。 |
| [ImageEffectsForTextWatermarkException](./imageeffectsfortextwatermarkexception) | `[`OfficeImageEffects`](../groupdocs.watermark.contents/officeimageeffects) が [`TextWatermark`](../groupdocs.watermark.watermarks/textwatermark) に供給されたときにスローされる例外です。` |
| [InvalidPasswordException](./invalidpasswordexception) | 提供されたパスワードが正しくないときにスローされる例外です。 |

| [UnsupportedFileTypeException](./unsupportedfiletypeexception) | ファイルをロードできないときにスローされる例外です。 |
| [WatermarkException](./watermarkexception) | **GroupDocs.Watermark** 製品の基本例外を表します。 |
