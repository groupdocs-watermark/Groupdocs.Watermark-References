## PresentationShapeSettings.IsLocked property

PowerPoint でシェイプの編集が禁止されているかどうかを示す値を取得または設定します。

```csharp
public bool IsLocked { get; set; }
```

### Property Value

値が true の場合、シェイプの編集は禁止されます。デフォルトでは、値は false で、PowerPoint でシェイプを編集できます。
