## WordProcessingHeaderFooter.IsLinkedToPrevious property

このヘッダー/フッターが前のセクションの対応するヘッダー/フッターにリンクされているかどうかを示す値を取得または設定します。

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

このヘッダー/フッターが前のセクションの対応するヘッダー/フッターにリンクされている場合は True、そうでない場合は false。

### 備考

デフォルトは true です。ヘッダーまたはフッターをリンクすると、その内容がクリアされることに注意してください。
