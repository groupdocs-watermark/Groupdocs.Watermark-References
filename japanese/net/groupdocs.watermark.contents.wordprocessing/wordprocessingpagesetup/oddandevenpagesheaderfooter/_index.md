## WordProcessingPageSetup.OddAndEvenPagesHeaderFooter property

奇数ページと偶数ページで異なるヘッダー/フッターが使用されるかどうかを示す値を取得または設定します。注: このプロパティを変更すると、コンテンツ内のすべてのセクションに影響します。

```csharp
public bool OddAndEvenPagesHeaderFooter { get; set; }
```

### Property Value

奇数ページと偶数ページで異なるヘッダー/フッターが使用されている場合は True、そうでない場合は false。
