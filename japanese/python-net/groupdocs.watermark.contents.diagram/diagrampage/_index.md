## DiagramPage class

Visio ドキュメントのページを表します。

DiagramPage 型は次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | 指定された検索条件に従って画像を検索します。検索は[`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/)で指定されたオブジェクト内で実行されます。（[`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)から継承） |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) | （[`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)から継承） |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | 指定された検索条件に従って可能性のある透かしを検索します。検索は[`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/)に列挙されたオブジェクト上で実行されます。（[`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)から継承） |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) | （[`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)から継承） |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [background_page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/background_page/) | この DiagramPage の背景ページ。 |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/bottom_margin/) | 下余白のサイズ（ポイント単位）です。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/height/) | この DiagramPage の高さ（ポイント単位）。 |
| [is_background](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_background/) | このページは背景ページです。 |
| [is_visible](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_visible/) | ページが UI に表示されるかどうかを示す値。 |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/left_margin/) | 左余白のサイズ（ポイント単位）。 |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/name/) | この DiagramPage の名前。 |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/right_margin/) | 右余白のサイズ（ポイント単位）。 |
| [shapes](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/shapes/) | ページ上のすべてのシェイプのコレクション。 |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/top_margin/) | 上余白のサイズ（ポイント単位）。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/width/) | この DiagramPage の幅（ポイント単位）。 |
