## DiagramShape class

Visio ドキュメント内の描画シェイプを表します。

DiagramShape 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/formatted_text_fragments/) | このDiagramShapeの書式設定されたテキストフラグメントのコレクションです。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/height/) | このDiagramShapeの高さ（ポイント単位）。 |
| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | この[`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/)に添付されたハイパーリンクのコレクションです。 |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | このDiagramShapeの識別子です。 |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | このDiagramShapeの画像です。 |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | このDiagramShapeの名前です。 |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | このDiagramShapeの親ページです。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | このDiagramShapeの回転角度（度単位）です。 |
| [text](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/text/) | このDiagramShapeのテキストです。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | このDiagramShapeの幅（ポイント単位）です。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/x/) | このDiagramShapeのページ左端からの水平オフセット（ポイント単位）、すなわちx座標です。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | このDiagramShapeのページ下端からの垂直オフセット（ポイント単位）です。 |
