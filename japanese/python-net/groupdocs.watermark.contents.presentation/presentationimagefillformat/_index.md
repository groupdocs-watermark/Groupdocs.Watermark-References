## PresentationImageFillFormat class

PowerPoint ドキュメント内の画像塗りつぶし形式設定を表します。

PresentationImageFillFormat 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | 背景画像です。画像が設定されていない場合は None を返します。 |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | True に設定すると画像は背景全体にタイル状に配置されます。設定しない場合は伸縮されます。 |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | 背景画像の透明度を 0.0（不透明）から 1.0（完全に透明）までの値で表します。 |
