## PresentationShapeSettings class

PowerPoint ドキュメントのシェイプ透かしに適用できる設定を表します。

PresentationShapeSettings 型は次のメンバーを公開します:

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/__init__/) | 新しい PresentationShapeSettings インスタンスを初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [is_locked](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/is_locked/) | このプロパティは PowerPoint でシェイプの編集が禁止されているかどうかを示します。 |
| [protect_with_unreadable_characters](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationshapesettings/protect_with_unreadable_characters/) | テキスト透かし文字が読めない文字と混在しているかどうかを示す値です。 |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | シェイプに関連付けられる説明（代替）テキストです。（[`OfficeShapeSettings`](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/) から継承） |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | シェイプの名前です。(継承元は[`OfficeShapeSettings`](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/)) |
