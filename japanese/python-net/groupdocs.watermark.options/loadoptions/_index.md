## LoadOptions class

ドキュメントを読み込む際のロードオプションを表します。

詳しくは:
- Loading documents: https://docs.groupdocs.com/display/watermarknet/Loading+documents
- Load from local disk: https://docs.groupdocs.com/display/watermarknet/Load+from+local+disk
- Load from stream: https://docs.groupdocs.com/display/watermarknet/Load+from+stream
- Load document of specific format: https://docs.groupdocs.com/display/watermarknet/Load+document+of+specific+format
- Load password-protected document: https://docs.groupdocs.com/display/watermarknet/Load+password-protected+document

LoadOptions 型は次のメンバーを公開します:

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options/loadoptions/__init__/) | LoadOptions クラスの新しいインスタンスを初期化します。 |
| [__init__](/watermark/python-net/groupdocs.watermark.options/loadoptions/__init__/#password) | 指定されたパスワードで [`LoadOptions`](/watermark/python-net/groupdocs.watermark.options/loadoptions/) クラスの新しいインスタンスを初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [file_type](/watermark/python-net/groupdocs.watermark.options/loadoptions/file_type/) | ファイルの種類で、形式を示します（例: docx、pdf、xlsx など）。 |
| [format_family](/watermark/python-net/groupdocs.watermark.options/loadoptions/format_family/) | ドキュメントのフォーマットファミリーで、タイプを示します（例: Image、Pdf、Spreadsheet など）。 |
| [password](/watermark/python-net/groupdocs.watermark.options/loadoptions/password/) | 暗号化されたドキュメントを開くためのパスワードです。 |
