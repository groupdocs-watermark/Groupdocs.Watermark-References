## OfficeImageEffects class

オフィスコンテンツの画像透かしに適用できるエフェクトを表します。

OfficeImageEffects 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | 画像の境界線の書式設定です。 |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | 画像の明るさです。0.0（最も暗い）から1.0（最も明るい）までの浮動小数点数で指定する必要があります。デフォルト値は0.5です。 |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | 画像の透明として扱われる色の値です。デフォルト値は完全に透明な色です。 |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | 指定された画像のコントラストです。0.0（最小のコントラスト）から1.0（最大のコントラスト）までの浮動小数点数である必要があります。デフォルト値は0.5です。 |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | このプロパティは、画像がグレースケールモードで表示されるかどうかを示します。 |
