## OfficeLineFormat class

図形の線形式を表します。

The OfficeLineFormat 型は次のメンバーを公開します:

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.contents/officelineformat/__init__/) | 新しい[`OfficeLineFormat`](/watermark/python-net/groupdocs.watermark.contents/officelineformat/)インスタンスを初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [color](/watermark/python-net/groupdocs.watermark.contents/officelineformat/color/) | 線の色です。 |
| [dash_style](/watermark/python-net/groupdocs.watermark.contents/officelineformat/dash_style/) | 線の点線と破線のパターンです。 |
| [enabled](/watermark/python-net/groupdocs.watermark.contents/officelineformat/enabled/) | このプロパティは、シェイプがストロークされるかどうかを示します。 |
| [line_style](/watermark/python-net/groupdocs.watermark.contents/officelineformat/line_style/) | 線のスタイルです。 |
| [opacity](/watermark/python-net/groupdocs.watermark.contents/officelineformat/opacity/) | 線の不透明度です。値は0から1の間である必要があります。デフォルト値は1です。 |
| [weight](/watermark/python-net/groupdocs.watermark.contents/officelineformat/weight/) | シェイプのパスをストロークするブラシの太さで、ポイント単位で表されます（デフォルトは0.75）。 |
