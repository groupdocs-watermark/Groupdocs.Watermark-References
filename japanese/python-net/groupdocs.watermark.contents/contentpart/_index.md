## ContentPart class

透かしを配置できるコンテンツ（ページ、フレーム、ヘッダー、または全体のコンテンツ）の任意の論理的部分を表します。

ContentPart 型は以下のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/#search_criteria) | 指定された検索条件に従って画像を検索します。検索は[`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/) で指定されたオブジェクト内で実行されます。 |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | コンテンツ内のすべての画像を検索し、[`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/) で指定されたオブジェクト内を対象とします。 |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) |  |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/#search_criteria) | 指定された検索条件に基づいて可能性のある透かしを検索します。検索は[`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/) に列挙されたオブジェクト上で実行されます。 |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | コンテンツ内のすべての可能性のある透かしを検索します。 |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) |  |
