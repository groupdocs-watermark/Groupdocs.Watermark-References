## PdfShape class

XObjects、Artifacts、Annotations の基本クラスを提供します。

PdfShape 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | この [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) の書式設定されたテキストフラグメントのコレクション。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/height/) | オブジェクトの高さ。 |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | この PdfShape の画像。オブジェクトに画像がない場合は None を返します。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/rotate_angle/) | オブジェクトの回転角度（度単位）。 |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | この [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) のテキスト。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/width/) | オブジェクトの幅。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/x/) | オブジェクトの x 座標。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/y/) | オブジェクトの y 座標。 |
