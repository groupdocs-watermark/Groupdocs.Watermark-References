## PdfArtifact class

PDF コンテンツ内のアーティファクトを表します。

詳しくは:
- https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithartifacts

PdfArtifact 型は次のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [artifact_subtype](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_subtype/) | この [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) のサブタイプです。 |
| [artifact_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_type/) | この [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) の型です。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/height/) | この [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) の高さ（ポイント単位）です。 |
| [opacity](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/opacity/) | この [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) の不透明度です。 |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/page/) | この [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) の親ページです。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/rotate_angle/) | この PdfArtifact の回転角度（度）です。 |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/text/) | この [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) のテキストです。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/width/) | この [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) の幅（ポイント単位）です。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/x/) | この PdfArtifact のページ左端からの水平オフセット（ポイント単位）です。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/y/) | この PdfArtifact のページ下端からの垂直オフセット（ポイント単位）です。 |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | この [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) の書式設定されたテキストフラグメントのコレクションです。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | この PdfShape の画像です。オブジェクトに画像がない場合は None を返します。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
