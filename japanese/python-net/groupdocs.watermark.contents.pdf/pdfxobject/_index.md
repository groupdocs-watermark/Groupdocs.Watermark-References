## PdfXObject class

PDFドキュメント内のXObjectを表します。

詳細を見る

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

PdfXObject 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | この PdfXObject の高さ（ポイント単位）。 |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | この PdfXObject の親ページ。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | この PdfXObject の回転角度（度単位）。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | この [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) の幅（ポイント単位）。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | この PdfXObject のページ左端からの水平オフセット（ポイント単位）。この PdfXObject の x 座標。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | この PdfXObject のページ下端からの垂直オフセット（ポイント単位、y 座標）。 |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | この [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) の書式設定されたテキストフラグメントのコレクションです。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | この PdfShape の画像です。オブジェクトに画像がない場合は None を返します。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | この [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) のテキストです。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
