## PdfAnnotation class

PDF ドキュメント内の注釈を表します。

詳しくは:
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

PdfAnnotation 型は次のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | この [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) の型です。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/height/) | この PdfAnnotation の高さ（ポイント単位）。 |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/page/) | この [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) の親ページです。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | この PdfAnnotation の回転角度（度）。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | この PdfAnnotation の幅（ポイント単位）。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | この PdfAnnotation のページ左端からの水平オフセット（ポイント単位）。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/y/) | この [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) のワークシート下端からの垂直オフセット（ポイント単位）。 |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | この [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) の書式設定されたテキストフラグメントのコレクションです。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | この PdfShape の画像です。オブジェクトに画像がない場合は None を返します。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | この [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) のテキストです。（[`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) から継承） |
