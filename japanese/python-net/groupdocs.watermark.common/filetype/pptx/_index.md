## PPTX field

PPTX 拡張子のファイルは、一般的な Microsoft PowerPoint アプリケーションで作成されたプレゼンテーションファイルです。以前のバイナリ形式の PPT と異なり、PPTX 形式は Microsoft PowerPoint のオープン XML プレゼンテーションファイル形式に基づいています。このファイル形式の詳細については、こちらをご覧ください。
