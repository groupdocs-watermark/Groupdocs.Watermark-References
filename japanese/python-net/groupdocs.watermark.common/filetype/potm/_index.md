## POTM field

POTM 拡張子のファイルは、マクロに対応した Microsoft PowerPoint テンプレートファイルです。POTM ファイルは PowerPoint 2007 以降で作成され、今後のプレゼンテーションファイル作成に使用できる既定設定が含まれています。このファイル形式の詳細については、こちらをご覧ください。
