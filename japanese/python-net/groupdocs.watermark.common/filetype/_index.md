## FileType class

ファイルタイプを表します。

[`GroupDocs.Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) がサポートするすべてのファイルタイプのリストを取得するメソッドを提供します。

FileType 型は次のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#other) | 現在の[`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) が指定された[`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) オブジェクトと同じかどうかを判断します。 |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#obj) | 現在の FileType が指定されたオブジェクトと同じかどうかを判断します。 |
| [equals_file_type](/watermark/python-net/groupdocs.watermark.common/filetype/equals_file_type/) |  |
| [equals_object](/watermark/python-net/groupdocs.watermark.common/filetype/equals_object/) |  |
| [from_extension](/watermark/python-net/groupdocs.watermark.common/filetype/from_extension/#extension) | ファイル拡張子をファイルタイプにマッピングします。 |
| [get_hash_code](/watermark/python-net/groupdocs.watermark.common/filetype/get_hash_code/) | 現在の[`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) オブジェクトのハッシュコードを返します。 |
| [get_supported_file_types](/watermark/python-net/groupdocs.watermark.common/filetype/get_supported_file_types/) | サポートされているファイルタイプを取得します。 |
| [to_string](/watermark/python-net/groupdocs.watermark.common/filetype/to_string/) | 現在のオブジェクトを表す文字列を返します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [extension](/watermark/python-net/groupdocs.watermark.common/filetype/extension/) | ファイル名のサフィックス（ピリオド「.」を含む）例：".doc"。 |
| [file_format_name](/watermark/python-net/groupdocs.watermark.common/filetype/file_format_name/) | ファイルタイプ名、例："Microsoft Word Document"。 |
| [format_family](/watermark/python-net/groupdocs.watermark.common/filetype/format_family/) | フォーマットファミリー。 |

### 例

```python
from groupdocs.watermark.common import FileType

def list_supported_formats():
    # ライブラリが開くことのできるすべてのファイルタイプを列挙してください
    supported_file_types = FileType.get_supported_file_types()
    for file_type in sorted(supported_file_types, key=lambda x: x.extension):
        print(file_type)

if __name__ == "__main__":
    list_supported_formats()
```
