## DOCX field

DOCX は Microsoft Word 文書のよく知られた形式です。2007 年に Microsoft Office 2007 のリリースとともに導入され、この新しい文書形式の構造はプレーン バイナリから XML とバイナリ ファイルの組み合わせに変更されました。このファイル形式の詳細については、こちらをご覧ください。
