## WordProcessingPageSetup class

Word 文書のセクションの印刷ページプロパティを表します。

WordProcessingPageSetup 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/bottom_margin/) | 下余白のサイズ（ポイント単位）です。 |
| [different_first_page_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/different_first_page_header_footer/) | 最初のページで異なるヘッダー/フッターが使用されるかどうかを示すフラグです。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/height/) | 印刷ページの高さ（ポイント単位）です。 |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/left_margin/) | 左余白のサイズ（ポイント単位）。 |
| [odd_and_even_pages_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/odd_and_even_pages_header_footer/) | このプロパティは、奇数ページと偶数ページで異なるヘッダー/フッターが使用されるかどうかを示します。 |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/right_margin/) | 右余白のサイズ（ポイント単位）。 |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/top_margin/) | 上余白のサイズ（ポイント単位）。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/width/) | 印刷ページの幅（ポイント単位）。 |
