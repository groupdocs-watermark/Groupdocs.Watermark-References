## Watermark class

ドキュメントに追加される透かしを表します。

詳細を見る

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Watermark タイプは次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | 透かしのサイズと座標が親の余白を考慮して計算されるかどうかを示すプロパティです。True に設定すると計算は親の余白を考慮します。デフォルトでは False で、親の余白は無視されます。 |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) の希望高さ。 |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | この Watermark の水平配置。 |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | 透かしを背景に配置するかどうかを示すプロパティです。true の場合、透かしは下部に配置されます。false の場合、上部に配置されます（デフォルトは False）。 |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | この Watermark の余白設定。 |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) の不透明度。 |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | この Watermark のページ設定。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) の回転角度（度単位）。 |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | 追加された透かしに関する情報をドキュメントのメタデータに保存するかどうかを示すプロパティです。 |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) のスケール係数で、透かしのサイズが親サイズにどのように依存するかを定義します。 |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | 透かしのサイズタイプ。 |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | 繰り返し透かしを定義するオプション。 |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) の垂直配置。 |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) の希望幅。 |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) の x 座標。 |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | この [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) の y 座標。 |
