## Margins class

オブジェクトの各エッジの余白設定を表します。

Margins 型は以下のメンバーを公開します：

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) クラスの新しいインスタンスを初期化します。 |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) クラスの新しいインスタンスを、指定されたタイプ、位置、サイズで初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | 下部余白。親の下端からの水平オフセットを表します。 |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | 左余白。親の左端からの水平オフセットとして表されます。 |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | 余白タイプは、余白の解釈方法を決定します。新しい値を設定すると、すべての余白が自動的にデフォルト値（ゼロ）にリセットされます。 |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | 右余白。親の右端からの水平オフセットとして表されます。 |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | 上部余白。 |
