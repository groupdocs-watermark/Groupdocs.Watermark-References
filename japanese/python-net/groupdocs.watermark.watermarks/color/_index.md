### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [a](/watermark/python-net/groupdocs.watermark.watermarks/color/a/) | 色のアルファ成分です。有効な値は 0 から 255 です。 |
| [b](/watermark/python-net/groupdocs.watermark.watermarks/color/b/) | 色の青成分です。有効な値は 0 から 255 です。 |
| [g](/watermark/python-net/groupdocs.watermark.watermarks/color/g/) | 色の緑成分の値です。 |
| [is_empty](/watermark/python-net/groupdocs.watermark.watermarks/color/is_empty/) | この [`Color`](/watermark/python-net/groupdocs.watermark.watermarks/color/) 構造体が初期化されていないかどうかを示すプロパティです。 |
| [r](/watermark/python-net/groupdocs.watermark.watermarks/color/r/) | 色の赤成分です。有効な値は 0 から 255 です。 |

### 例

```python
from groupdocs.watermark.watermarks import Color, TextWatermark, Font
from groupdocs.watermark import Watermarker

with Watermarker("document.pdf") as watermarker:
    watermark = TextWatermark("CONFIDENTIAL", Font("Arial", 48))
    watermark.foreground_color = Color.red
    watermarker.add(watermark)
    watermarker.save("watermarked.pdf")
```
