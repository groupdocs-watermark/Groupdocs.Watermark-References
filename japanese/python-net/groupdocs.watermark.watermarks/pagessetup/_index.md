## PagesSetup class

ページの設定を表します。

PagesSetup 型は次のメンバーを公開します:

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/__init__/) | [`PagesSetup`](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/) クラスの新しいインスタンスを初期化します。 |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/__init__/#all_pages-first_page-last_page-odd_pages-even_pages-pages-page_number) | 指定されたパラメーターで新しい PagesSetup インスタンスを初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [all_pages](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/all_pages/) | すべてのページを含めるかどうかを示すフラグです。 |
| [even_pages](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/even_pages/) | 偶数ページを含めるかどうかを示す値。 |
| [first_page](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/first_page/) | first_page プロパティは、最初のページを含めるかどうかを示します。 |
| [last_page](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/last_page/) | last_page プロパティは、最後のページを含めるかどうかを示します。 |
| [odd_pages](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/odd_pages/) | 奇数ページを含めるかどうかを示す値。 |
| [page_number](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/page_number/) | 指定されたページのみを考慮した場合のページ番号。 |
| [pages](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/pages/) | 含める特定のページ番号のリスト。 |
| [specified](/watermark/python-net/groupdocs.watermark.watermarks/pagessetup/specified/) | 特定のページが指定されているかどうかを示す値。 |
