## SpreadsheetAttachment class

Excel ドキュメントに添付されたファイルを表します。

SpreadsheetAttachment 型は、次のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | 添付ファイルからコンテンツを読み込みます。（[`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/) から継承） |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | （[`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/) から継承） |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | 添付ファイルに保存されているドキュメントに関する情報を取得します。（[`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/) から継承） |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/alternative_text/) | 添付ファイルに関連付けられた説明（代替）テキストです。 |
| [content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/content/) | 添付ファイルのコンテンツ。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/height/) | ポイント単位の添付フレームの高さです。 |
| [is_link](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/is_link/) | このプロパティは、添付がファイルへのリンクのみを含むかどうかを示します。 |
| [preview_image_content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/preview_image_content/) | 添付ファイルのプレビュー画像（バイト配列）です。 |
| [source_full_name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/source_full_name/) | 添付ファイルのフルネームです。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/width/) | 添付フレームの幅（ポイント単位）です。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/x/) | ワークシート左端から添付フレームまでの水平オフセット（ポイント単位）です。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/y/) | 添付フレームの y 座標（ポイント単位）です。 |
