## SpreadsheetChart class

Excel ドキュメント内のチャートを表します。

SpreadsheetChart 型は次のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | この [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/) に関連付けられた説明（代替）テキスト。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | この SpreadsheetChart の高さ（ポイント単位）。 |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | この SpreadsheetChart に関連付けられたハイパーリンク。 |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | この SpreadsheetChart の識別子。 |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | この SpreadsheetChart の画像塗りつぶし形式設定。 |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | この SpreadsheetChart の名前。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | この SpreadsheetChart の幅（ポイント単位）。 |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | この SpreadsheetChart の親ワークシート。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | この SpreadsheetChart のワークシート左端からの水平オフセット（ポイント単位）。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | この SpreadsheetChart のワークシート上端からの垂直オフセット（ポイント単位）。 |
