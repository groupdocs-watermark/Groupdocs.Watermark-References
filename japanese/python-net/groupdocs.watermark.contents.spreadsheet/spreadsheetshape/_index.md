## SpreadsheetShape class

Excel ドキュメント内の描画シェイプを表します。

SpreadsheetShape 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/alternative_text/) | この [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) に関連付けられた説明（代替）テキストです。 |
| [auto_shape_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/auto_shape_type/) | 自動シェイプのタイプです。 |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/formatted_text_fragments/) | この SpreadsheetShape の書式設定されたテキストフラグメントのコレクションです。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/height/) | この SpreadsheetShape の高さ（ポイント単位）です。 |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/hyperlink/) | この [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) に関連付けられたハイパーリンクです。 |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/id/) | この SpreadsheetShape の識別子です。 |
| [image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image/) | この SpreadsheetShape の画像です。画像がない場合は None を返します。 |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image_fill_format/) | この SpreadsheetShape の画像塗りつぶし形式設定です。 |
| [is_word_art](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/is_word_art/) | このシェイプは WordArt オブジェクトです。 |
| [mso_drawing_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/mso_drawing_type/) | mso 描画タイプです。 |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/name/) | この SpreadsheetShape の名前。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/rotate_angle/) | この [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) の回転角度（度）。 |
| [text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/text/) | この [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) のテキスト。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/width/) | この SpreadsheetShape の幅（ポイント）。 |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/worksheet/) | この SpreadsheetShape の親ワークシート。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/x/) | この SpreadsheetShape のワークシート左端からの水平オフセット（ポイント）。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/y/) | この SpreadsheetShape のワークシート上端からの y 座標（ポイント）。 |
