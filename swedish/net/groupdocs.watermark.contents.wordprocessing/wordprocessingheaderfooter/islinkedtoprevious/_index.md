## WordProcessingHeaderFooter.IsLinkedToPrevious property

Hämtar eller anger ett värde som indikerar om detta header/footer är länkat till motsvarande header/footer i föregående sektion.

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

### Anmärkningar

Standard är sant. Observera att när du länkar en rubrik eller sidfot rensas dess innehåll.
