Namnrymden tillhandahåller klasser för att specificera ytterligare alternativ när du arbetar med dokument och vattenstämplar.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [CreatePageStream](./createpagestream) | Representerar en metod som returnerar en ström för att skriva förhandsgranskningsdata för en sida. |
| [LoadOptions](./loadoptions) | Representerar dokumentladdningsalternativ när ett dokument laddas. |
| [OoxmlLoadOptions](./ooxmlloadoptions) | Representerar dokumentladdningsalternativ för ett OOXML-dokument. |
| [PreviewOptions](./previewoptions) | Tillhandahåller alternativ för att ange krav och strömdelegeringar för förhandsgranskning. |
| [ReleasePageStream](./releasepagestream) | Representerar en metod som frigör strömmen som skapats av delegaten [`CreatePageStream`](../groupdocs.watermark.options/createpagestream). |
| [SaveOptions](./saveoptions) | Representerar alternativ för dokumentlagring när ett dokument sparas. |
| [WatermarkOptions](./watermarkoptions) | Representerar alternativ för att lägga till vattenstämpel i ett dokument. |
