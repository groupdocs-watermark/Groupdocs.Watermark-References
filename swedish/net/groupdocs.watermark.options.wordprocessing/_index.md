Namnrymden tillhandahåller klasser för att specificera ytterligare alternativ när du arbetar med vattenstämplar och Word-dokument

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [WordProcessingImageEffects](./wordprocessingimageeffects) | Representerar effekter som kan tillämpas på en bildvattenstämpel för ett Word-dokument. |
| [WordProcessingLoadOptions](./wordprocessingloadoptions) | Representerar alternativ för dokumentladdning för ett Word-dokument. |
| [WordProcessingPreviewOptions](./wordprocessingpreviewoptions) | Tillhandahåller alternativ för att ange krav och strömbaserade delegater för generering av förhandsgranskning av WordProcessing-dokument. |
| [WordProcessingSaveOptions](./wordprocessingsaveoptions) | Representerar alternativ för dokumentlagring när ett Word-dokument sparas. |
| [WordProcessingTextEffects](./wordprocessingtexteffects) | Representerar effekter som kan tillämpas på en textvattenstämpel för ett Word-dokument. |
| [WordProcessingWatermarkBaseOptions](./wordprocessingwatermarkbaseoptions) | Bas-klass för alternativ för att lägga till vattenstämpel i ett Word-dokument. |
| [WordProcessingWatermarkHeaderFooterOptions](./wordprocessingwatermarkheaderfooteroptions) | Representerar alternativ när vattenstämpeln läggs till i ett Word-avsnitts sidhuvud/sidfot. |
| [WordProcessingWatermarkPagesOptions](./wordprocessingwatermarkpagesoptions) | Representerar alternativ när vattenstämpel läggs till på Word-dokumentets sidor. |
| [WordProcessingWatermarkSectionOptions](./wordprocessingwatermarksectionoptions) | Representerar alternativ när en formvattenstämpel läggs till i ett Word-dokumentavsnitt. |
