## WordProcessingWatermarkBaseOptions.IsLocked property

Hämtar eller anger ett värde som indikerar om redigering av formen i Word är förbjuden.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Om värdet är `true` kommer redigering av former att förbjudas. Som standard är värdet `false`, så formen kan redigeras i Word.
