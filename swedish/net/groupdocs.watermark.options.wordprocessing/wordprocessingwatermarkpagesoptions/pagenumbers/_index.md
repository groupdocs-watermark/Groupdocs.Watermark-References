## WordProcessingWatermarkPagesOptions.PageNumbers property

Hämtar eller anger sidnumren för att lägga till vattenstämpeln.

```csharp
public int[] PageNumbers { get; set; }
```

### Property Value

Sidnumren för att lägga till vattenstämpeln.

### Anmärkningar

Alla tal måste vara större än eller lika med 1. Denna egenskap används endast när vattenstämpeln läggs till i ett dokument. Om detta värde är `null` eller tomt, läggs vattenstämpeln till på alla sidor.
