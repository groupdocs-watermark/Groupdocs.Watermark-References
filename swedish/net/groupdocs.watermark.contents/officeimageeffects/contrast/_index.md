## OfficeImageEffects.Contrast property

Hämtar eller anger kontrasten för den angivna bilden. Värdet för denna egenskap måste vara ett tal mellan 0.0 (minsta kontrast) och 1.0 (största kontrast).

```csharp
public double Contrast { get; set; }
```

### Property Value

Standardvärdet är 0.5.
