Namnrymden tillhandahåller klasser för att arbeta med dokument av alla stödjande typer.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Content](./content) | Representerar ett innehåll där ett vattenmärke kan placeras. |
| [ContentPart](./contentpart) | Representerar någon logisk del av ett innehåll (sida, ram, sidhuvud eller hela innehållet) där vattenmärke kan placeras. |
| [OfficeImageEffects](./officeimageeffects) | Representerar effekter som kan tillämpas på en bildvattenstämpel för ett kontorsinnehåll. |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | Representerar inställningarna för bildfyllningsformat i alla stödda kontorsinnehåll. |
| [OfficeLineFormat](./officelineformat) | Representerar ett format för en formlinje. |
| [OfficeShapeSettings](./officeshapesettings) | Representerar inställningar som kan tillämpas på en formvattenstämpel för ett kontorsinnehåll. |
| [OfficeTextEffects](./officetexteffects) | Representerar effekter som kan tillämpas på en textvattenstämpel för ett kontorsinnehåll. |
