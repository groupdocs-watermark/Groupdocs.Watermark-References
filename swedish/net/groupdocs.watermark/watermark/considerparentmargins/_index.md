## Watermark.ConsiderParentMargins property

Hämtar eller anger ett värde som indikerar om vattenmärkets storlek och koordinater beräknas med hänsyn till föräldramarginaler.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Om värdet är true beräknas vattenstämpelns storlek och koordinater med hänsyn till föräldramarginaler. Som standard är värdet false, föräldramarginaler ignoreras.
