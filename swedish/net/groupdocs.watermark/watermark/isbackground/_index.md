## Watermark.IsBackground property

Hämtar eller anger ett värde som indikerar om vattenmärket ska placeras i bakgrunden.

```csharp
public bool IsBackground { get; set; }
```

### Property Value

Om värdet är true placeras vattenstämpeln längst ner. Som standard är värdet false, placeras vattenstämpeln högst upp.
