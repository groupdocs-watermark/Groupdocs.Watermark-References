## PresentationShapeSettings.IsLocked property

Hämtar eller anger ett värde som indikerar om redigering av formen i PowerPoint är förbjuden.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Om värdet är true förbjuds redigering av formen. Som standard är värdet false, så formen kan redigeras i PowerPoint.
