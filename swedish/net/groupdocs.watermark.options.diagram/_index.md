Namnrymden tillhandahåller klasser för att specificera ytterligare alternativ när du arbetar med vattenstämplar i Visio-dokument.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [DiagramLoadOptions](./diagramloadoptions) | Representerar alternativ för dokumentladdning för ett Visio-dokument. |
| [DiagramPageWatermarkOptions](./diagrampagewatermarkoptions) | Representerar alternativ för att lägga till vattenstämpel när en formvattenstämpel läggs till på en specifik sida i ett Visio-dokument. |
| [DiagramPreviewOptions](./diagrampreviewoptions) | Tillhandahåller alternativ för att ange krav och strömbegäranden för generering av förhandsgranskning av Diagram-dokument. |
| [DiagramSaveOptions](./diagramsaveoptions) | Representerar alternativ för dokumentlagring när ett Visio-dokument sparas. |
| [DiagramShapeWatermarkOptions](./diagramshapewatermarkoptions) | Representerar alternativ för att lägga till vattenstämpel när en formvattenstämpel läggs till i ett Visio-dokument. |
| [DiagramWatermarkOptions](./diagramwatermarkoptions) | Bas-klass för alternativ för att lägga till vattenstämpel i ett Visio-dokument. |
