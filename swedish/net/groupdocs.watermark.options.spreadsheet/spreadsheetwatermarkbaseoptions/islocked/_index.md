## SpreadsheetWatermarkBaseOptions.IsLocked property

Hämtar eller anger ett värde som indikerar om redigering av formen i Excel är förbjuden.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Om värdet är true, kommer redigering av formen att förbjudas. Som standard är värdet false, så kan formen redigeras i Excel.
