Namnrymden tillhandahåller klasser för att specificera ytterligare alternativ när du arbetar med vattenstämplar och PDF-dokument.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [PdfAnnotationWatermarkOptions](./pdfannotationwatermarkoptions) | Representerar alternativ för att lägga till vattenstämpel när en annoteringsvattenstämpel läggs till i ett PDF‑dokument. |
| [PdfArtifactWatermarkOptions](./pdfartifactwatermarkoptions) | Representerar alternativ för att lägga till vattenstämpel när en artefaktvattenstämpel läggs till i ett PDF‑dokument. |
| [PdfLoadOptions](./pdfloadoptions) | Representerar alternativ för dokumentladdning för ett PDF‑dokument. |
| [PdfPreviewOptions](./pdfpreviewoptions) | Tillhandahåller alternativ för att ställa in krav och strömbaserade delegater för generering av förhandsgranskning av PDF‑dokument. |
| [PdfSaveOptions](./pdfsaveoptions) | Representerar alternativ för dokumentlagring när ett PDF‑dokument sparas. |
| [PdfWatermarkOptions](./pdfwatermarkoptions) | Basklass för alternativ för att lägga till vattenstämpel i ett PDF‑dokument. |
| [PdfXObjectWatermarkOptions](./pdfxobjectwatermarkoptions) | Representerar alternativ för att lägga till vattenstämpel när en XObject‑vattenstämpel läggs till i ett PDF‑dokument. |
