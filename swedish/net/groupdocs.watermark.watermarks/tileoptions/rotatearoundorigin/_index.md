## TileOptions.RotateAroundOrigin property

Hämtar eller anger ett värde som indikerar om de upprepade vattenstämplarna ska roteras kring dokumentets centrum.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` om de upprepade vattenmärkena ska roteras kring dokumentets nedre vänstra punkt; annars `false`, i så fall kommer rotationen att vara relativ till dokumentets vänstra kant. Standardvärdet är `false`.
