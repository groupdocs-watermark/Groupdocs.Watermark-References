## SpreadsheetImageFillFormat class

Typen SpreadsheetImageFillFormat visar följande medlemmar:

| Egenskap | Beskrivning |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | Bakgrundsbilden. Returnerar None om bilden inte är inställd. |
