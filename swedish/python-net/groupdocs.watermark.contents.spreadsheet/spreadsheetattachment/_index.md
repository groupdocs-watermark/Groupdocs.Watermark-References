## SpreadsheetAttachment class

Representerar en fil som är bifogad till ett Excel-dokument.

Typen SpreadsheetAttachment exponerar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | Laddar innehåll från den bifogade filen. (ärvd från [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | (ärvd från [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | Hämtar informationen om ett dokument som lagras i den bifogade filen. (ärvd från [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
