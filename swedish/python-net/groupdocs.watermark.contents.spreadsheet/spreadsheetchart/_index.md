## SpreadsheetChart class

Representerar ett diagram i ett Excel-dokument.

Typen SpreadsheetChart exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | Den beskrivande (alternativa) texten som är associerad med denna [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | Höjden på detta SpreadsheetChart i punkter. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | Hyperlänken som är associerad med detta SpreadsheetChart. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | Identifieraren för detta SpreadsheetChart. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | Inställningarna för bildfyllningsformatet för detta SpreadsheetChart. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | Namnet på detta SpreadsheetChart. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | Bredden på detta SpreadsheetChart i punkter. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | Det överordnade arbetsbladet för detta SpreadsheetChart. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | Den horisontella förskjutningen av detta SpreadsheetChart från arbetsbladets vänstra kant i punkter. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | Den vertikala förskjutningen av detta SpreadsheetChart från arbetsbladets övre kant i punkter. |
