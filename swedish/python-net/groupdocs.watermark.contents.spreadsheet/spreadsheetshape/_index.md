## SpreadsheetShape class

Representerar en ritningsform i ett Excel-dokument.

Typen SpreadsheetShape exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/alternative_text/) | Den beskrivande (alternativa) texten som är associerad med denna [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [auto_shape_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/auto_shape_type/) | Den automatiska formtypen. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/formatted_text_fragments/) | Samlingen av formaterade textfragment för denna SpreadsheetShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/height/) | Höjden på denna SpreadsheetShape i punkter. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/hyperlink/) | Hyperlänken som är associerad med denna [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/id/) | Identifieraren för denna SpreadsheetShape. |

| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/name/) | Namnet på denna SpreadsheetShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/rotate_angle/) | Rotationsvinkeln för detta [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) i grader. |
| [text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/text/) | Texten för detta [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/width/) | Bredden på detta SpreadsheetShape i punkter. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/worksheet/) | Det överordnade kalkylbladet för detta SpreadsheetShape. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/x/) | Den horisontella förskjutningen för detta SpreadsheetShape från kalkylbladets vänstra kant i punkter. |
