| Egenskap | Beskrivning |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | Den nedre marginalen. Representerar den horisontella förskjutningen från förälderns nedre kant. |

| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | Margintypen, som bestämmer hur marginaler tolkas; att ange ett nytt värde återställer automatiskt alla marginaler till sina standardvärden (noll). |

| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | Den övre marginalen. |
