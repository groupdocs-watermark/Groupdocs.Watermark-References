## __init__ {#left-right-top-bottom}

Initierar en ny Thickness-instans med specifika längder applicerade på varje sida av rektangeln.

```python
def __init__(self, left, right, top, bottom):
    ...
```

| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| left | `float` | Tjockleken för vänstra sidan av rektangeln. |
| right | `float` | Tjockleken för högra sidan av rektangeln. |
| top | `float` | Tjockleken för övre sidan av rektangeln. |
| bottom | `float` | Tjockleken för nedre sidan av rektangeln. |

## __init__ {#uniform_length}

Initierar en ny Thickness-instans med den angivna enhetliga längden på varje sida.

```python
def __init__(self, uniform_length):
    ...
```

| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| uniform_length | `float` | Den enhetliga längden som tillämpas på alla fyra sidor av den avgränsande rektangeln. |
