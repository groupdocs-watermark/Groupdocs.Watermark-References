## PresentationImageFillFormat class

Representerar inställningarna för bildfyllningsformat i ett PowerPoint-dokument.

PresentationImageFillFormat-typen visar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | Bakgrundsbilden. Returnerar None om bilden inte är inställd. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | Bilden upprepas över bakgrunden när den är satt till True; annars sträcks den. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | Transparensen för bakgrundsbilden som ett värde från 0.0 (opak) till 1.0 (fullt transparent). |
