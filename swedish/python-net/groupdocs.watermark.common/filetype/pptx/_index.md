## PPTX field

Filer med PPTX-förlängning är presentationsfiler skapade med den populära Microsoft PowerPoint-applikationen. Till skillnad från den tidigare versionen av presentationsfilformatet PPT som var binärt, är PPTX-formatet baserat på Microsoft PowerPoint Open XML presentationsfilformat. Läs mer om detta filformat här.
