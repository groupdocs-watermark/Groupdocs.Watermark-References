## FileType class

Representerar filtyp.

Tillhandahåller metoder för att erhålla en lista över alla filtyper som stöds av [`GroupDocs.Watermark`](/watermark/python-net/groupdocs.watermark/watermark/).

### Exempel

```python
from groupdocs.watermark.common import FileType

def list_supported_formats():
    # Enumerera alla filtyper som biblioteket kan öppna
    supported_file_types = FileType.get_supported_file_types()
    for file_type in sorted(supported_file_types, key=lambda x: x.extension):
        print(file_type)

if __name__ == "__main__":
    list_supported_formats()
```
