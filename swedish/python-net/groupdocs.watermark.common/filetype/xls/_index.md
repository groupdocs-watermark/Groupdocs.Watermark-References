## XLS field

Filer med XLS‑tillägget representerar Excel Binary File Format. Sådana filer kan skapas av Microsoft Excel samt andra liknande kalkylprogram som OpenOffice Calc eller Apple Numbers. Läs mer om detta filformat här.
