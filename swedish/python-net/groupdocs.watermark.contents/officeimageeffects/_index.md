## OfficeImageEffects class

Representerar effekter som kan tillämpas på en bildvattenstämpel för ett kontorsinnehåll.

Typen OfficeImageEffects exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Inställningarna för linjeformatet för bildens kant. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | Bildens ljusstyrka. Måste vara ett flyttal mellan 0.0 (mörkast) och 1.0 (ljusast). Standardvärdet är 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | Färgvärdet för bilden som kommer att behandlas som transparent. Standardvärdet är en helt transparent färg. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Kontrasten för den angivna bilden. Måste vara ett flyttal mellan 0,0 (minsta kontrast) och 1,0 (största kontrast). Standardvärdet är 0,5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | Egenskapen anger om en bild kommer att visas i gråskala. |
