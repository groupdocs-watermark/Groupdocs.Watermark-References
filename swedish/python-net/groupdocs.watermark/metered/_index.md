## Metered class

Hantera mätad (betala per användning) licensiering.

Metered-licenser faktureras baserat på faktisk förbrukning (vanligtvis sidor eller
dokument som bearbetas). Ställ in det offentliga/privata nyckelparet en gång vid
applikationsstart; omslaget rapporterar användning tillbaka till GroupDocs
licensservern i bakgrunden.

Metered-typen visar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [get_consumption_credit](/watermark/python-net/groupdocs.watermark/metered/get_consumption_credit/) | Returnerar antalet krediter som har förbrukats hittills. |
| [get_consumption_quantity](/watermark/python-net/groupdocs.watermark/metered/get_consumption_quantity/) | Returnerar mängden data som har bearbetats hittills. |
| [set_metered_key](/watermark/python-net/groupdocs.watermark/metered/set_metered_key/#public_key-private_key) | Aktivera meterad fakturering med det angivna offentliga/privata nyckelparet. |
