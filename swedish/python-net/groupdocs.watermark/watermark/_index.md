## Watermark class

Representerar ett vattenmärke som ska läggas till i ett dokument.

Läs mer

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Watermark-typen exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | Egenskapen som indikerar om vattenstämpelns storlek och koordinater beräknas med hänsyn till föräldramarginaler. Om den är satt till True, beaktas föräldramarginaler i beräkningarna; som standard är värdet False och föräldramarginaler ignoreras. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | Den önskade höjden för denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | Den horisontella justeringen av denna Watermark. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | Egenskapen som indikerar om vattenstämpeln ska placeras i bakgrunden. Om true placeras vattenstämpeln längst ner; annars placeras den högst upp (standard är False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | Marginalinställningarna för denna Watermark. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | Opaciteten för denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | Sidinställningarna för denna Watermark. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | Rotationsvinkeln för denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) i grader. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | Egenskapen indikerar om information om tillagda vattenstämplar ska sparas i dokumentets metadata. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | Skalfaktorn för denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/), som definierar hur vattenstämpelns storlek beror på förälderns storlek. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | Storlekstypen för vattenstämpeln. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | Alternativen för att definiera en upprepad vattenstämpel. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | Den vertikala justeringen av denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | Den önskade bredden för denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | x-koordinaten för denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | y-koordinaten för denna [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
