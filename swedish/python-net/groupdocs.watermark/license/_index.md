## License class

Hantera GroupDocs.Watermark-licensiering.

Licensierade byggen låser upp hela funktionsuppsättningen för omslaget vid
körningstid. Olicensierade byggen körs i evalueringsläge med samma API
yta men med begränsningar för utskriftsstorlek och vattenmärkt innehåll.
