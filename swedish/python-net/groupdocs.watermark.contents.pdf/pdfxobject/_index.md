## PdfXObject class

Representerar ett XObject i ett pdf-dokument.

Läs mer

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

PdfXObject-typen exponerar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | Höjden på denna PdfXObject i punkter. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | Den överordnade sidan för denna PdfXObject. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | Rotationsvinkeln för denna PdfXObject i grader. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | Bredden på denna [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) i punkter. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | Den horisontella förskjutningen av denna PdfXObject från sidans vänstra kant i punkter. X-koordinaten för denna PdfXObject. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | Det vertikala offsetet för detta PdfXObject från sidans nedre kant i punkter (y-koordinaten). |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | Samlingen av formaterade textfragment för detta [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (ärvd från [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | Bilden för detta PdfShape. Returnerar None om objektet inte har någon bild. (ärvd från [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Texten för detta [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (ärvd från [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
