## PdfAnnotation class

Representerar en annotation i ett pdf-dokument.

Läs mer:
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

PdfAnnotation-typen visar följande medlemmar:

| Egenskap | Beskrivning |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | Typen av denna [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/height/) | Höjden på denna PdfAnnotation i punkter. |

| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | Rotationsvinkeln för denna PdfAnnotation i grader. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | Bredden på denna PdfAnnotation i punkter. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | Det horisontella avståndet för denna PdfAnnotation från sidans vänstra kant i punkter. |

| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Texten för detta [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (ärvd från [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
