## DiagramShape class

Representerar en ritningsform i ett Visio-dokument.

DiagramShape-typen visar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/formatted_text_fragments/) | Samlingen av formaterade textfragment för detta DiagramShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/height/) | Höjden på detta DiagramShape i punkter. |
| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | Samlingen av hyperlänkar som är bifogade till detta [`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | Identifieraren för detta DiagramShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | Bilden för detta DiagramShape. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | Namnet på detta DiagramShape. |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | Den överordnade sidan för detta DiagramShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | Rotationsvinkeln för detta DiagramShape i grader. |
| [text](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/text/) | Texten för detta DiagramShape. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | Bredden på detta DiagramShape i punkter. |
| [x](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/x/) | Den horisontella förskjutningen av detta DiagramShape från sidans vänstra kant i punkter, d.v.s. dess x-koordinat. |
| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | Den vertikala förskjutningen av detta DiagramShape från sidans nedre kant i punkter. |
