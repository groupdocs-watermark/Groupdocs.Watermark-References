Der Namensraum stellt Klassen bereit, um zusätzliche Optionen beim Arbeiten mit Dokumenten und Wasserzeichen anzugeben.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CreatePageStream](./createpagestream) | Stellt eine Methode dar, die einen Stream zurückgibt, um Seitenvorschau-Daten zu schreiben. |
| [LoadOptions](./loadoptions) | Stellt Optionen zum Laden von Dokumenten dar, wenn ein Dokument geladen wird. |
| [OoxmlLoadOptions](./ooxmlloadoptions) | Stellt Optionen zum Laden von Dokumenten für ein OOXML-Dokument dar. |
| [PreviewOptions](./previewoptions) | Bietet Optionen zum Festlegen von Anforderungen und Stream-Delegaten für die Vorschauerstellung. |
| [ReleasePageStream](./releasepagestream) | Stellt eine Methode dar, die den vom [`CreatePageStream`](../groupdocs.watermark.options/createpagestream) Delegaten erstellten Stream freigibt. |
| [SaveOptions](./saveoptions) | Stellt Optionen zum Speichern von Dokumenten dar. |
| [WatermarkOptions](./watermarkoptions) | Stellt Optionen zum Hinzufügen von Wasserzeichen zu einem Dokument dar. |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [ILogger](./ilogger) | Definiert die Schnittstelle eines Loggers, der zum Protokollieren von Ereignissen und Fehlern während des Wasserzeichnens verwendet wird. |
