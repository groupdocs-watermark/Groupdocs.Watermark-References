## WordProcessingHeaderFooter.IsLinkedToPrevious property

Liest oder setzt einen Wert, der angibt, ob diese Kopf-/Fußzeile mit der entsprechenden Kopf-/Fußzeile im vorherigen Abschnitt verknüpft ist.

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

True, wenn diese Kopf‑/Fußzeile mit der entsprechenden Kopf‑/Fußzeile im vorherigen Abschnitt verknüpft ist; sonst false.

### Hinweise

Standard ist true. Hinweis: Wenn Sie eine Kopf‑ oder Fußzeile verknüpfen, wird deren Inhalt gelöscht.
