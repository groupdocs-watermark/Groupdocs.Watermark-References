## WordProcessingHorizontalAlignment enumeration

Gibt die horizontale Ausrichtung eines schwebenden Objekts an.

```csharp
public enum WordProcessingHorizontalAlignment
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Objekt ist explizit positioniert unter Verwendung seiner x-Koordinate. |
| Left | `1` | Gibt an, dass das Objekt linksbündig zur horizontalen Ausrichtungsbasis ist. |
| Center | `2` | Gibt an, dass das Objekt relativ zur horizontalen Ausrichtungsbasis zentriert ist. |
| Right | `3` | Gibt an, dass das Objekt rechtsbündig zur horizontalen Ausrichtungsbasis ist. |
| Inside | `4` | Gibt an, dass das Objekt innerhalb der horizontalen Ausrichtungsbasis liegt. |
| Outside | `5` | Gibt an, dass das Objekt außerhalb der horizontalen Ausrichtungsbasis liegt. |
