## WordProcessingPageSetup.OddAndEvenPagesHeaderFooter property

Liest oder setzt einen Wert, der angibt, ob unterschiedliche Kopf-/Fußzeilen für ungerade und gerade Seiten verwendet werden. Hinweis: Das Ändern dieser Eigenschaft wirkt sich auf alle Abschnitte im Inhalt aus.

```csharp
public bool OddAndEvenPagesHeaderFooter { get; set; }
```

### Property Value

True, wenn unterschiedliche Kopf‑/Fußzeilen für ungerade und gerade Seiten verwendet werden; andernfalls false.
