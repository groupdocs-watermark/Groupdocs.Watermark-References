## PdfPermissions enumeration

Stellt die Berechtigungen des Benutzers für ein PDF-Dokument dar.

```csharp
[Flags]
public enum PdfPermissions
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| PrintDocument | `4` | Drucke den Inhalt. |
| ModifyContent | `8` | Ändere den Inhalt. |
| ExtractContent | `10` | Kopiere oder extrahiere anderweitig Text und Grafiken aus dem Dokument. |
| ModifyTextAnnotations | `20` | Füge Textanmerkungen hinzu oder ändere sie. |
| FillForm | `100` | Fülle vorhandene interaktive Formularfelder aus. |
| ExtractContentWithDisabilities | `200` | Extrahiere Text und Grafiken. |
| AssembleDocument | `400` | Setze den Inhalt zusammen. |
| PrintingQuality | `800` | Drucke den Inhalt in eine Darstellung, aus der eine getreue digitale Kopie des PDF-Dokuments erzeugt werden kann. |
