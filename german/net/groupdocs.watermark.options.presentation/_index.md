Der Namensraum stellt Klassen bereit, um zusätzliche Optionen beim Arbeiten mit witharks und PowerPoint-Dokumenten anzugeben.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [PresentationImageEffects](./presentationimageeffects) | Stellt Effekte dar, die auf ein Bild‑Wasserzeichen für ein PowerPoint-Dokument angewendet werden können. |
| [PresentationLoadOptions](./presentationloadoptions) | Stellt Optionen zum Laden eines Dokuments für ein Präsentationsdokument dar. |
| [PresentationPreviewOptions](./presentationpreviewoptions) | Bietet Optionen, um Anforderungen festzulegen und Stream-Delegaten für die Vorschauerstellung eines Präsentationsdokuments zu definieren. |
| [PresentationSaveOptions](./presentationsaveoptions) | Stellt Optionen zum Speichern eines Dokuments dar, wenn ein Präsentationsdokument gespeichert wird. |
| [PresentationTextEffects](./presentationtexteffects) | Stellt Effekte dar, die auf ein Text‑Wasserzeichen für PowerPoint‑Inhalte angewendet werden können. |
| [PresentationWatermarkBaseSlideOptions](./presentationwatermarkbaseslideoptions) | Basisklasse für Optionen zum Hinzufügen von Wasserzeichen zu einem Präsentationsdokument. |
| [PresentationWatermarkLayoutSlideOptions](./presentationwatermarklayoutslideoptions) | Stellt Optionen dar, wenn ein Wasserzeichen zu einer Layout‑Folie eines Präsentationsdokuments hinzugefügt wird. |
| [PresentationWatermarkMasterHandoutSlideOptions](./presentationwatermarkmasterhandoutslideoptions) | Stellt Optionen dar, wenn ein Wasserzeichen zu einer Master‑Handout‑Folie eines Präsentationsdokuments hinzugefügt wird. |
| [PresentationWatermarkMasterNotesSlideOptions](./presentationwatermarkmasternotesslideoptions) | Stellt Optionen dar, wenn ein Wasserzeichen zu einer Master‑Notiz‑Folie eines Präsentationsdokuments hinzugefügt wird. |
| [PresentationWatermarkMasterSlideOptions](./presentationwatermarkmasterslideoptions) | Stellt Optionen dar, wenn ein Wasserzeichen zu einer Master‑Folie eines Präsentationsdokuments hinzugefügt wird. |
| [PresentationWatermarkNoteSlideOptions](./presentationwatermarknoteslideoptions) | Stellt Optionen dar, wenn ein Wasserzeichen zu einer Notiz‑Folie eines Präsentationsdokuments hinzugefügt wird. |
| [PresentationWatermarkOptions](./presentationwatermarkoptions) | Basisklasse für Optionen zum Hinzufügen von Wasserzeichen zu einem Präsentationsdokument. |
| [PresentationWatermarkSlideOptions](./presentationwatermarkslideoptions) | Stellt Optionen dar, wenn ein Wasserzeichen zu einer Folie eines Präsentationsdokuments hinzugefügt wird. |
