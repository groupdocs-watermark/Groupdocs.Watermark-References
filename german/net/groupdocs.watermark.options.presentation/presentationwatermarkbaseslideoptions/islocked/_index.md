## PresentationWatermarkBaseSlideOptions.IsLocked property

Liest oder setzt einen Wert, der angibt, ob das Bearbeiten der Form in PowerPoint verboten ist.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Wenn der Wert `true` ist, wird die Formbearbeitung verboten. Standardmäßig ist der Wert `false`; die Form kann in PowerPoint bearbeitet werden.
