## FileType.PPT field

Eine Datei mit der PPT-Erweiterung stellt eine PowerPoint‑Datei dar, die aus einer Sammlung von Folien für die Anzeige als Slide‑Show besteht. Sie gibt das von Microsoft PowerPoint 97‑2003 verwendete Binärdateiformat an. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/presentation/ppt/).
