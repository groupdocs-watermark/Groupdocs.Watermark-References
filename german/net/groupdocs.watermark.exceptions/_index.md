Der Namensraum stellt verschiedene Ausnahmeklassen bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DetachedImageException](./detachedimageexception) | Die Ausnahme, die ausgelöst wird, wenn ein abgetrenntes Bild bearbeitet wird. |
| [EncryptionIsNotSupportedException](./encryptionisnotsupportedexception) | Die Ausnahme, die ausgelöst wird, wenn Inhaltsverschlüsselung nicht unterstützt wird. |
| [FontNotFoundException](./fontnotfoundexception) | Die Ausnahme, die ausgelöst wird, wenn die angeforderte Schriftart nicht gefunden wird. |
| [ImageEffectsForTextWatermarkException](./imageeffectsfortextwatermarkexception) | Die Ausnahme, die ausgelöst wird, wenn [`OfficeImageEffects`](../groupdocs.watermark.contents/officeimageeffects) für [`TextWatermark`](../groupdocs.watermark.watermarks/textwatermark) bereitgestellt wird. |
| [InvalidPasswordException](./invalidpasswordexception) | Die Ausnahme, die ausgelöst wird, wenn das bereitgestellte Passwort falsch ist. |
| [PreviewNotSupportedException](./previewnotsupportedexception) | Die Ausnahme, die ausgelöst wird, wenn für den Inhalt kein Vorschaubild erzeugt werden kann. |
| [TextEffectsForImageWatermarkException](./texteffectsforimagewatermarkexception) | Die Ausnahme, die ausgelöst wird, wenn [`OfficeTextEffects`](../groupdocs.watermark.contents/officetexteffects) für [`ImageWatermark`](../groupdocs.watermark.watermarks/imagewatermark) bereitgestellt wird. |
| [UnexpectedDocumentStructureException](./unexpecteddocumentstructureexception) | Die Ausnahme, die ausgelöst wird, wenn ein Inhalt aufgrund unerwarteter Struktur nicht geparst werden kann. |
| [UnknownLoadOptionsTypeException](./unknownloadoptionstypeexception) | Die Ausnahme, die ausgelöst wird, wenn ein Dokument mit den bereitgestellten [`LoadOptions`](../groupdocs.watermark.options/loadoptions) nicht geladen werden kann. |
| [UnknownWatermarkOptionsTypeException](./unknownwatermarkoptionstypeexception) | Die Ausnahme, die ausgelöst wird, wenn ein Wasserzeichen mit den bereitgestellten [`WatermarkOptions`](../groupdocs.watermark.options/watermarkoptions) nicht hinzugefügt werden kann. |
| [UnsupportedFileTypeException](./unsupportedfiletypeexception) | Die Ausnahme, die ausgelöst wird, wenn eine Datei nicht geladen werden kann. |
| [WatermarkException](./watermarkexception) | Stellt die Basisausnahme im Produkt **GroupDocs.Watermark** dar. |
