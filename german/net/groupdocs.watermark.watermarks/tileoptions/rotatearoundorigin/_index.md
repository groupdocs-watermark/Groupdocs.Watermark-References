## TileOptions.RotateAroundOrigin property

Liest oder setzt einen Wert, der angibt, ob die wiederholten Wasserzeichen um die Mitte des Dokuments gedreht werden sollen.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true`, wenn wiederholte Wasserzeichen um den unteren linken Punkt des Dokuments rotiert werden sollen; andernfalls `false`. In diesem Fall erfolgt die Rotation relativ zur linken Kante des Dokuments. Der Standardwert ist `false`.
