## PresentationSearchableObjects enumeration

Gibt Flags an, die PowerPoint‑Inhaltsobjekte repräsentieren und in einer Wasserzeichensuche enthalten sein sollen.

```csharp
[Flags]
public enum PresentationSearchableObjects
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Gibt an, dass keine Suchobjekte vorhanden sind. |
| Shapes | `1` | Suche in Formen. |
| ChartsBackgrounds | `2` | Suche im Hintergrund von Diagrammen. |
| SlidesBackgrounds | `4` | Suche im Hintergrund von Folien. |
| Hyperlinks | `8` | Suche in Hyperlinks. |
| All | `F` | Suche in allen Inhaltsobjekten. |
