## DiagramWatermarkPlacementType enumeration

Gibt an, zu welchen Seiten ein Wasserzeichen hinzugefügt werden soll.

```csharp
public enum DiagramWatermarkPlacementType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| ForegroundPages | `0` | Ein Wasserzeichen sollte nur zu Vordergrundseiten hinzugefügt werden. |
| BackgroundPages | `1` | Ein Wasserzeichen sollte nur zu Hintergrundseiten hinzugefügt werden. |
| AllPages | `2` | Ein Wasserzeichen sollte zu allen Seiten hinzugefügt werden. |
| SeparateBackgrounds | `3` | Separate Hintergrundseiten mit einem Wasserzeichen sollten erstellt und allen Seiten ohne Hintergrund zugewiesen werden. |
| Default | `0` | Das gleiche wie ForegroundPages. |
