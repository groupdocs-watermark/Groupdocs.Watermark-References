## WordProcessingWatermarkPagesOptions.PageNumbers property

Liest oder setzt die Seitenzahlen, zu denen das Wasserzeichen hinzugefügt werden soll.

```csharp
public int[] PageNumbers { get; set; }
```

### Property Value

Die Seitenzahlen, zu denen das Wasserzeichen hinzugefügt werden soll.

### Hinweise

Alle Zahlen müssen größer oder gleich 1 sein. Diese Eigenschaft wird nur verwendet, wenn das Wasserzeichen zu einem Dokument hinzugefügt wird. Wenn dieser Wert `null` oder leer ist, wird das Wasserzeichen zu allen Seiten hinzugefügt.
