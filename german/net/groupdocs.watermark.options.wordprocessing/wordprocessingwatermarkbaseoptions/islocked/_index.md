## WordProcessingWatermarkBaseOptions.IsLocked property

Liest oder setzt einen Wert, der angibt, ob das Bearbeiten der Form in Word verboten ist.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Wenn der Wert `true` ist, wird die Bearbeitung der Form verboten. Standardmäßig ist der Wert `false`, die Form kann in Word bearbeitet werden.
