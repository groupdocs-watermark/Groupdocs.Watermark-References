Der Namensraum stellt Klassen bereit, um zusätzliche Optionen beim Arbeiten mit Wasserzeichen und Word-Dokumenten anzugeben.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [WordProcessingImageEffects](./wordprocessingimageeffects) | Stellt Effekte dar, die auf ein Bildwasserzeichen für ein Word‑Dokument angewendet werden können. |
| [WordProcessingLoadOptions](./wordprocessingloadoptions) | Stellt Optionen zum Laden eines Dokuments für ein Word‑Dokument dar. |
| [WordProcessingPreviewOptions](./wordprocessingpreviewoptions) | Bietet Optionen zum Festlegen von Anforderungen und Stream‑Delegaten für die Generierung einer Vorschau eines WordProcessing‑Dokuments. |
| [WordProcessingSaveOptions](./wordprocessingsaveoptions) | Stellt Optionen zum Speichern eines Dokuments dar, wenn ein Word‑Dokument gespeichert wird. |
| [WordProcessingTextEffects](./wordprocessingtexteffects) | Stellt Effekte dar, die auf ein Textwasserzeichen für ein Word‑Dokument angewendet werden können. |
| [WordProcessingWatermarkBaseOptions](./wordprocessingwatermarkbaseoptions) | Basisklasse für Optionen zum Hinzufügen von Wasserzeichen zu einem Word‑Dokument. |
| [WordProcessingWatermarkHeaderFooterOptions](./wordprocessingwatermarkheaderfooteroptions) | Stellt Optionen dar, wenn das Wasserzeichen zu einem Word‑Abschnitts‑Kopf‑ oder Fußzeile hinzugefügt wird. |
| [WordProcessingWatermarkPagesOptions](./wordprocessingwatermarkpagesoptions) | Stellt Optionen dar, wenn ein Wasserzeichen zu Word‑Dokumentseiten hinzugefügt wird. |
| [WordProcessingWatermarkSectionOptions](./wordprocessingwatermarksectionoptions) | Stellt Optionen dar, wenn ein Form‑Wasserzeichen zu einem Word‑Dokumentabschnitt hinzugefügt wird. |
