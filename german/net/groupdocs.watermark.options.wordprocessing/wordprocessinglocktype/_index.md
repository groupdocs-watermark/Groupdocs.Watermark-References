## WordProcessingLockType enumeration

Gibt den Sperrtyp des Wasserzeichens in einem Word‑Dokument an.

```csharp
public enum WordProcessingLockType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| AllowOnlyRevisions | `0` | Benutzer kann dem Dokument nur Revisionsmarken hinzufügen. |
| AllowOnlyComments | `1` | Benutzer kann im Dokument nur Kommentare ändern. |
| AllowOnlyFormFields | `2` | Benutzer kann im Dokument nur Daten in die Formularfelder eingeben. |
| ReadOnly | `3` | Das gesamte Dokument ist schreibgeschützt. |
| ReadOnlyWithEditableContent | `4` | Das Dokument ist schreibgeschützt, aber aller Inhalt außer dem Wasserzeichen ist als editierbar markiert. |
| NoLock | `-1` | Deaktivieren Sie jede Sperre für Wasserzeichen und Dokument. |
