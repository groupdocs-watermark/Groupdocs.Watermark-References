## FormattedTextFragmentCollectionType enumeration

Gibt die Anzahl der Elemente an, die eine Sammlung formatierter Textfragmente enthalten kann.

```csharp
public enum FormattedTextFragmentCollectionType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| UnlimitedFragments | `0` | Mehrere Stile sind erlaubt, die Sammlung kann eine unbegrenzte Anzahl von Fragmenten enthalten. |
| SingleFragment | `1` | Der gesamte Text kann mit einem einzigen Stil formatiert werden, die Sammlung kann nur ein Fragment enthalten. |
| NoFormattedText | `2` | Das übergeordnete Objekt unterstützt keine Textformatierung, die Sammlung ist immer leer. |
