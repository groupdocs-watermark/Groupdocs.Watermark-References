## BaseWatermarkResult.WatermarkId property

Eindeutiger Wasserzeichen-Identifikator zum Ändern des Wasserzeichens im Dokument über die Methoden Update oder Delete. Diese Eigenschaft wird automatisch gesetzt, nachdem die Add-Methode aufgerufen wurde. Wenn diese Eigenschaft zuvor gespeichert wurde, kann sie manuell gesetzt werden, um das Wasserzeichen zu manipulieren.

public string WatermarkId { get; }
