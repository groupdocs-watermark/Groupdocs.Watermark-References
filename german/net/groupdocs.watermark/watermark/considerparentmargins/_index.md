## Watermark.ConsiderParentMargins property

Liest oder setzt einen Wert, der angibt, ob die Größe und Koordinaten des Wasserzeichens unter Berücksichtigung der übergeordneten Ränder berechnet werden.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Wenn der Wert true ist, werden die Wasserzeichen‑Größe und -Koordinaten unter Berücksichtigung der übergeordneten Ränder berechnet. Standardmäßig ist der Wert false, übergeordnete Ränder werden ignoriert.
