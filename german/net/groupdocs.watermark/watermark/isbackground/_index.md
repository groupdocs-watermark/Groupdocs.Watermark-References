## Watermark.IsBackground property

Liest oder setzt einen Wert, der angibt, ob das Wasserzeichen im Hintergrund platziert werden soll.

```csharp
public bool IsBackground { get; set; }
```

### Property Value

Wenn der Wert true ist, wird das Wasserzeichen unten platziert. Standardmäßig ist der Wert false, wird das Wasserzeichen oben platziert.
