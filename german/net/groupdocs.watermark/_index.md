Der Namensraum stellt Klassen zur Arbeit mit Wasserzeichen in einem Dokument eines beliebigen unterstützten Typs bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [License](./license) | Stellt Methoden bereit, um die Komponente zu lizenzieren. |
| [Metered](./metered) | Stellt Methoden bereit, um die Komponente mit einer nutzungsbasierten Lizenz zu lizenzieren. |
| [Watermark](./watermark) | Stellt ein Wasserzeichen dar, das zu einem Dokument hinzugefügt werden soll. |
| [Watermarker](./watermarker) | Stellt eine Klasse für die Verwaltung von Wasserzeichen in einem Dokument dar. |
| [WatermarkerSettings](./watermarkersettings) | Definiert Einstellungen zur Anpassung des Verhaltens des Watermarkers. |
