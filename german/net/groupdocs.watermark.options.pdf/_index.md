Der Namensraum stellt Klassen bereit, um zusätzliche Optionen beim Arbeiten mit Wasserzeichen und PDF-Dokumenten anzugeben.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [PdfAnnotationWatermarkOptions](./pdfannotationwatermarkoptions) | Stellt Optionen zum Hinzufügen von Wasserzeichen dar, wenn ein Anmerkungs‑Wasserzeichen zu einem PDF‑Dokument hinzugefügt wird. |
| [PdfArtifactWatermarkOptions](./pdfartifactwatermarkoptions) | Stellt Optionen zum Hinzufügen von Wasserzeichen dar, wenn ein Artefakt‑Wasserzeichen zu einem PDF‑Dokument hinzugefügt wird. |
| [PdfLoadOptions](./pdfloadoptions) | Stellt Ladeoptionen für ein PDF‑Dokument dar. |

| [PdfSaveOptions](./pdfsaveoptions) | Stellt Speicheroptionen für ein PDF‑Dokument beim Speichern dar. |
| [PdfWatermarkOptions](./pdfwatermarkoptions) | Basisklasse für Optionen zum Hinzufügen von Wasserzeichen zu einem PDF‑Dokument. |
| [PdfXObjectWatermarkOptions](./pdfxobjectwatermarkoptions) | Stellt Optionen zum Hinzufügen von Wasserzeichen dar, wenn ein XObject‑Wasserzeichen zu einem PDF‑Dokument hinzugefügt wird. |
