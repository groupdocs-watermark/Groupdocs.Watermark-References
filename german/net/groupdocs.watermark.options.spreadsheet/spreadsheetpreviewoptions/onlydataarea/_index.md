## SpreadsheetPreviewOptions.OnlyDataArea property

Liest oder setzt das Flag für die Darstellung nur des Datenbereichs ohne Kopfzeilen, Fußzeilen und Ränder.

```csharp
public bool OnlyDataArea { get; set; }
```

### Property Value

Das Flag für die Darstellung nur des Datenbereichs ohne Kopfzeilen, Fußzeilen und Ränder.

### Hinweise

Dieses Flag führt dazu, dass das gesamte Arbeitsblatt auf einer Seite dargestellt wird. Der Standardwert ist `false`.
