Der Namensraum stellt Klassen bereit, um zusätzliche Optionen beim Arbeiten mit Wasserzeichen und Excel-Dokumenten anzugeben.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [SpreadsheetBackgroundWatermarkOptions](./spreadsheetbackgroundwatermarkoptions) | Stellt Optionen dar, wenn das Wasserzeichen als Hintergrund zu einem Spreadsheet-Arbeitsblatt hinzugefügt wird. |
| [SpreadsheetImageEffects](./spreadsheetimageeffects) | Stellt Effekte dar, die auf ein Bildwasserzeichen für ein Excel-Dokument angewendet werden können. |
| [SpreadsheetLoadOptions](./spreadsheetloadoptions) | Stellt Dokument-Ladeoptionen für ein Spreadsheet-Dokument dar. |
| [SpreadsheetPreviewOptions](./spreadsheetpreviewoptions) | Stellt Optionen bereit, um Anforderungen und Stream-Delegaten für die Vorschauerstellung eines Spreadsheet-Dokuments festzulegen. |
| [SpreadsheetSaveOptions](./spreadsheetsaveoptions) | Stellt Optionen zum Speichern eines Dokuments dar, wenn ein Spreadsheet-Dokument gespeichert wird. |
| [SpreadsheetShapeSettings](./spreadsheetshapesettings) | Stellt Einstellungen dar, die auf ein Form‑Wasserzeichen für ein Excel-Dokument angewendet werden können. |
| [SpreadsheetTextEffects](./spreadsheettexteffects) | Stellt Effekte dar, die auf ein Text‑Wasserzeichen für ein Excel-Dokument angewendet werden können. |
| [SpreadsheetWatermarkBaseOptions](./spreadsheetwatermarkbaseoptions) | Basisklasse für Optionen zum Hinzufügen von Wasserzeichen zu einem Spreadsheet-Dokument. |
| [SpreadsheetWatermarkHeaderFooterOptions](./spreadsheetwatermarkheaderfooteroptions) | Stellt Optionen dar, wenn das Wasserzeichen zu einer Spreadsheet‑Kopf‑/Fußzeile hinzugefügt wird. |
| [SpreadsheetWatermarkModernWordArtOptions](./spreadsheetwatermarkmodernwordartoptions) | Stellt Optionen dar, wenn ein modernes Word‑Art‑Wasserzeichen zu einem Spreadsheet‑Arbeitsblatt hinzugefügt wird. |
| [SpreadsheetWatermarkShapeOptions](./spreadsheetwatermarkshapeoptions) | Stellt Optionen dar, wenn ein Form‑Wasserzeichen zu einem Spreadsheet‑Arbeitsblatt hinzugefügt wird. |
