## DiagramWatermarkOptions.IsLocked property

Liefert oder setzt einen Wert, der angibt, ob das Bearbeiten der Form in Visio verboten ist.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Wenn der Wert true ist, wird die Formbearbeitung verboten.

### Hinweise

Standardmäßig ist der Wert false, die Form kann in Visio bearbeitet werden.
