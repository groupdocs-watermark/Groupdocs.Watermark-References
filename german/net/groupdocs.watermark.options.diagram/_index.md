Der Namensraum stellt Klassen bereit, um zusätzliche Optionen beim Arbeiten mit Wasserzeichen in Visio-Dokumenten anzugeben.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DiagramLoadOptions](./diagramloadoptions) | Stellt Dokument‑Ladeoptionen für ein Visio‑Dokument dar. |
| [DiagramPageWatermarkOptions](./diagrampagewatermarkoptions) | Stellt Optionen zum Hinzufügen von Wasserzeichen dar, wenn ein Form‑Wasserzeichen zu einer bestimmten Seite eines Visio‑Dokuments hinzugefügt wird. |
| [DiagramPreviewOptions](./diagrampreviewoptions) | Bietet Optionen zum Festlegen von Anforderungen und Stream‑Delegaten für die Vorschauerstellung eines Diagramm‑Dokuments. |
| [DiagramSaveOptions](./diagramsaveoptions) | Stellt Dokument‑Speicheroptionen beim Speichern eines Visio‑Dokuments dar. |
| [DiagramShapeWatermarkOptions](./diagramshapewatermarkoptions) | Stellt Optionen zum Hinzufügen von Wasserzeichen dar, wenn ein Form‑Wasserzeichen zu einem Visio‑Dokument hinzugefügt wird. |
| [DiagramWatermarkOptions](./diagramwatermarkoptions) | Basisklasse für Optionen zum Hinzufügen von Wasserzeichen zu einem Visio‑Dokument. |
