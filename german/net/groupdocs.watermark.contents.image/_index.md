Der Namensraum stellt Klassen zum Hinzufügen von Wasserzeichen zu Bildern verschiedener Formate bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [GifImageContent](./gifimagecontent) | Stellt ein GIF-Bild dar, in das ein Wasserzeichen eingefügt werden kann. |
| [ImageContent](./imagecontent) | Stellt ein Bild dar, in das ein Wasserzeichen eingefügt werden kann. |
| [ImageFrame](./imageframe) | Stellt einen Bildrahmen dar, in den ein Wasserzeichen eingefügt werden kann. |
| [ImageFrameCollection](./imageframecollection) | Stellt eine Sammlung von Rahmen in einem Mehrrahmenbild dar. |
| [MultiframeImageContent](./multiframeimagecontent) | Stellt ein Mehrrahmenbild dar, in das ein Wasserzeichen eingefügt werden kann. |
| [SystemDrawingImageFrame](./systemdrawingimageframe) | Stellt einen Bildrahmen dar, in den ein Wasserzeichen eingefügt werden kann (System.Drawing-Implementierung). |
| [SystemDrawingImageFrameCollection](./systemdrawingimageframecollection) | Stellt eine Sammlung von Rahmen in einem Mehrrahmenbild dar. |
| [TiffImageContent](./tiffimagecontent) | Stellt ein TIFF-Bild dar, in das ein Wasserzeichen eingefügt werden kann. |
| [WatermarkableImage](./watermarkableimage) | Stellt ein Bild in einem Dokument dar. |
| [WatermarkableImageCollection](./watermarkableimagecollection) | Stellt eine Sammlung von Bildern dar, die in einem Dokument gefunden werden. |
