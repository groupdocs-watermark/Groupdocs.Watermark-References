## SpreadsheetAttachment.IsLink property

Ermittelt einen Wert, der angibt, ob der Inhalt nur einen Link zur Datei enthält.

```csharp
public bool IsLink { get; }
```

### Property Value

Wahr, wenn die angehängte Datei über einen Link referenziert wird (der Inhalt enthält nicht den Anhangsdateiinhalt); andernfalls falsch.
