## OfficeImageEffects.Brightness property

Liest oder legt die Helligkeit des Bildes fest. Der Wert dieser Eigenschaft muss eine Zahl zwischen 0.0 (dunkelste) und 1.0 (hellste) sein.

```csharp
public double Brightness { get; set; }
```

### Property Value

Der Standardwert ist 0,5.
