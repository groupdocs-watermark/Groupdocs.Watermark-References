## OfficeImageEffects class

Stellt Effekte dar, die auf ein Bildwasserzeichen für einen Office-Inhalt angewendet werden können.

```csharp
public abstract class OfficeImageEffects
```

## Eigenschaften

| Name | Beschreibung |
| --- | --- |
| [BorderLineFormat](../../groupdocs.watermark.contents/officeimageeffects/borderlineformat) { get; set; } | Liest oder legt die Einstellungen des Linienformats für den Bildrand fest. |
| [Brightness](../../groupdocs.watermark.contents/officeimageeffects/brightness) { get; set; } | Liest oder legt die Helligkeit des Bildes fest. Der Wert dieser Eigenschaft muss eine Zahl zwischen 0.0 (dunkelste) und 1.0 (hellste) sein. |
| [ChromaKey](../../groupdocs.watermark.contents/officeimageeffects/chromakey) { get; set; } | Liest oder legt den Farbwert des Bildes fest, der als transparent behandelt wird. |
| [Contrast](../../groupdocs.watermark.contents/officeimageeffects/contrast) { get; set; } | Liest oder legt den Kontrast für das angegebene Bild fest. Der Wert dieser Eigenschaft muss eine Zahl zwischen 0.0 (geringster Kontrast) und 1.0 (höchster Kontrast) sein. |
| [GrayScale](../../groupdocs.watermark.contents/officeimageeffects/grayscale) { get; set; } | Liest oder legt einen Wert fest, der angibt, ob ein Bild im Graustufenmodus angezeigt wird. |
