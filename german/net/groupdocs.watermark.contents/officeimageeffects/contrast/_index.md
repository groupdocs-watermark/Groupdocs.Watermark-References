## OfficeImageEffects.Contrast property

Liest oder legt den Kontrast für das angegebene Bild fest. Der Wert dieser Eigenschaft muss eine Zahl zwischen 0.0 (geringster Kontrast) und 1.0 (höchster Kontrast) sein.

```csharp
public double Contrast { get; set; }
```

### Property Value

Der Standardwert ist 0,5.
