Der Namensraum stellt Klassen zur Arbeit mit Dokumenten beliebiger unterstützter Typen bereit.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Content](./content) | Stellt einen Inhalt dar, in dem ein Wasserzeichen platziert werden kann. |
| [ContentPart](./contentpart) | Stellt jeden logischen Teil eines Inhalts (Seite, Rahmen, Kopfzeile oder ein ganzer Inhalt) dar, in dem ein Wasserzeichen platziert werden kann. |
| [OfficeImageEffects](./officeimageeffects) | Stellt Effekte dar, die auf ein Bildwasserzeichen für einen Office-Inhalt angewendet werden können. |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | Stellt die Einstellungen des Bildfüllformats in beliebigem unterstütztem Office-Inhalt dar. |
| [OfficeLineFormat](./officelineformat) | Stellt ein Linienformat für Formen dar. |
| [OfficeShapeSettings](./officeshapesettings) | Stellt Einstellungen dar, die auf ein Formwasserzeichen für einen Office-Inhalt angewendet werden können. |
| [OfficeTextEffects](./officetexteffects) | Stellt Effekte dar, die auf ein Textwasserzeichen für einen Office-Inhalt angewendet werden können. |
## Aufzählung

| Aufzählung | Beschreibung |
| --- | --- |
| [OfficeDashStyle](./officedashstyle) | Stellt einen gestrichelten Linienstil dar. |
| [OfficeHeaderFooterType](./officeheaderfootertype) | Identifiziert den Typ von Kopf- oder Fußzeile. |
| [OfficeLineStyle](./officelinestyle) | Stellt den zusammengesetzten Linienstil eines [`OfficeLineFormat`](../groupdocs.watermark.contents/officelineformat) dar. |
