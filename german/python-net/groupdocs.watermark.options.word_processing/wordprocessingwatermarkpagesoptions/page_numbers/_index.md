## page_numbers property

Die Seitenzahlen, zu denen das Wasserzeichen hinzugefügt werden soll.

Alle Zahlen müssen größer oder gleich 1 sein.

Diese Eigenschaft wird nur verwendet, wenn das Wasserzeichen zu einem Dokument hinzugefügt wird.

Wenn dieser Wert None oder leer ist, wird das Wasserzeichen zu allen Seiten hinzugefügt.
