## only_data_area property

Das Flag zum Rendern des Datenbereichs ausschließlich ohne Kopfzeilen, Fußzeilen und Ränder.

Dieses Flag führt dazu, dass das gesamte Arbeitsblatt auf einer Seite gerendert wird. Der Standardwert ist False.
