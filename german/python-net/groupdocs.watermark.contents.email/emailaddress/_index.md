## EmailAddress class

Stellt eine Adresse einer E-Mail-Nachricht dar.

Der EmailAddress-Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [address](/watermark/python-net/groupdocs.watermark.contents.email/emailaddress/address/) | Die Zeichenketten-Darstellung der E-Mail-Adresse. |
| [display_name](/watermark/python-net/groupdocs.watermark.contents.email/emailaddress/display_name/) | Der Anzeigename, der mit der Adresse verknüpft ist. |
| [host](/watermark/python-net/groupdocs.watermark.contents.email/emailaddress/host/) | Der Host-Teil der Adresse. |
| [original_address_string](/watermark/python-net/groupdocs.watermark.contents.email/emailaddress/original_address_string/) | Die ursprüngliche Adresszeichenkette. |
| [user](/watermark/python-net/groupdocs.watermark.contents.email/emailaddress/user/) | Der Benutzername. |
