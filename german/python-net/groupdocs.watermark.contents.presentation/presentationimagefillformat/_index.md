## PresentationImageFillFormat class

Stellt die Einstellungen des Bildfüllformats in einem PowerPoint-Dokument dar.

Der Typ PresentationImageFillFormat stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | Das Hintergrundbild. Gibt None zurück, wenn kein Bild festgelegt ist. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | Das Bild wird über den Hintergrund gekachelt, wenn es auf True gesetzt ist; andernfalls wird es gestreckt. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | Die Transparenz des Hintergrundbildes als Wert von 0,0 (undurchsichtig) bis 1,0 (vollständig transparent). |
