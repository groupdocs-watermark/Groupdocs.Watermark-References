## PresentationSlideImageFillFormat class

Stellt die Einstellungen für das Bildfüllformat einer Folie in einem PowerPoint-Dokument dar.

Der PresentationSlideImageFillFormat-Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslideimagefillformat/background_image/) | Das Hintergrundbild; gibt None zurück, wenn kein Bild festgelegt ist. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | Das Bild wird über den Hintergrund gekachelt, wenn es auf True gesetzt ist; andernfalls wird es gestreckt. (geerbt von [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | Die Transparenz des Hintergrundbildes als Wert von 0,0 (undurchsichtig) bis 1,0 (vollständig transparent). (geerbt von [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
