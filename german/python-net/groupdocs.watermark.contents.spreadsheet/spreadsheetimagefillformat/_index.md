## SpreadsheetImageFillFormat class

Stellt die Einstellungen für das Bildfüllformat in einem Excel-Dokument dar.

Der Typ SpreadsheetImageFillFormat stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | Das Hintergrundbild. Gibt None zurück, wenn kein Bild festgelegt ist. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | Das Bild wird bei True über den Hintergrund gekachelt; andernfalls wird das Bild gestreckt. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | Die Transparenz des Hintergrundbildes als Wert von 0,0 (undurchsichtig) bis 1,0 (vollständig transparent). |
