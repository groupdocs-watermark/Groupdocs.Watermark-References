## SpreadsheetAttachment class

Stellt eine an ein Excel-Dokument angehängte Datei dar.

Der SpreadsheetAttachment-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | Lädt einen Inhalt aus der angehängten Datei. (geerbt von [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | (geerbt von [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | Ruft die Informationen zu einem im angehängten Dokument gespeicherten Dokument ab. (geerbt von [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/alternative_text/) | Der beschreibende (alternative) Text, der mit der angehängten Datei verknüpft ist. |
| [content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/content/) | Der Inhalt der angehängten Datei. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/height/) | Die Höhe des Anhangrahmens in Punkten. |
| [is_link](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/is_link/) | Die Eigenschaft gibt an, ob der Anhang nur einen Link zur Datei enthält. |
| [preview_image_content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/preview_image_content/) | Das Vorschaubild der angehängten Datei als Byte-Array. |
| [source_full_name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/source_full_name/) | Der vollständige Name der angehängten Datei. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/width/) | Die Breite des Anhangrahmens in Punkten. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/x/) | Der horizontale Abstand des Anhangrahmens vom linken Rand des Arbeitsblatts in Punkten. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/y/) | Die y-Koordinate des Anhangrahmens in Punkten. |
