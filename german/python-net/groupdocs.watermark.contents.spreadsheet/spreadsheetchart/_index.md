## SpreadsheetChart class

Stellt ein Diagramm in einem Excel-Dokument dar.

Der Typ SpreadsheetChart stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | Der beschreibende (alternativ) Text, der mit diesem [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/) verknüpft ist. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | Die Höhe dieses SpreadsheetChart in Punkten. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | Der Hyperlink, der mit diesem SpreadsheetChart verknüpft ist. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | Der Bezeichner dieses SpreadsheetChart. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | Die Bildfüllformat‑Einstellungen dieses SpreadsheetChart. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | Der Name dieses SpreadsheetChart. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | Die Breite dieses SpreadsheetChart in Punkten. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | Das übergeordnete Arbeitsblatt dieses SpreadsheetChart. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | Der horizontale Versatz dieses SpreadsheetChart vom linken Rand des Arbeitsblatts in Punkten. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | Der vertikale Versatz dieses SpreadsheetChart von der oberen Arbeitsblattkante in Punkten. |
