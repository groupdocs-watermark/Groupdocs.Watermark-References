## SpreadsheetPageSetup class

Stellt die Druckseiteneigenschaften für ein Arbeitsblatt dar.

Der Typ SpreadsheetPageSetup stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/bottom_margin/) | Die Größe des unteren Randes in Punkten. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/height/) | Die Höhe einer Druckseite in Punkten. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/left_margin/) | Die Größe des linken Randes in Punkten. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/right_margin/) | Die Größe des rechten Randes in Punkten. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/top_margin/) | Die Größe des oberen Randes in Punkten. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/width/) | Die Breite einer Druckseite in Punkten. |
