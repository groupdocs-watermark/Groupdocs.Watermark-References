## __init__ {#left-right-top-bottom}

Initialisiert eine neue Thickness-Instanz mit spezifischen Längen, die auf jede Seite des Rechtecks angewendet werden.

```python
def __init__(self, left, right, top, bottom):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| left | `float` | Die Dicke für die linke Seite des Rechtecks. |
| right | `float` | Die Dicke für die rechte Seite des Rechtecks. |
| top | `float` | Die Dicke für die obere Seite des Rechtecks. |
| bottom | `float` | Die Dicke für die untere Seite des Rechtecks. |

## __init__ {#uniform_length}

Initialisiert eine neue Thickness-Instanz mit der angegebenen einheitlichen Länge auf jeder Seite.

```python
def __init__(self, uniform_length):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| uniform_length | `float` | Die einheitliche Länge, die auf alle vier Seiten des umgebenden Rechtecks angewendet wird. |
