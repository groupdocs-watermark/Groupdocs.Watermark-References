## Margins class

Stellt Rand-Einstellungen für jede Kante eines Objekts dar.

Der Typ Margins stellt die folgenden Member bereit:

### Konstruktoren
| Konstruktor | Beschreibung |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | Initialisiert eine neue Instanz der [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) Klasse. |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | Initialisiert eine neue Instanz der [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) Klasse mit dem angegebenen Typ, Standort und Größe. |

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | Der untere Rand. Stellt den horizontalen Abstand von der unteren Kante des übergeordneten Elements dar. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | Der linke Rand, ausgedrückt als horizontaler Abstand von der linken Kante des übergeordneten Elements. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | Der Randtyp, der bestimmt, wie Ränder interpretiert werden; das Festlegen eines neuen Werts setzt alle Ränder automatisch auf ihre Standardwerte (null) zurück. |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | Der rechte Rand als horizontaler Abstand von der rechten Kante des übergeordneten Elements. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | Der obere Rand. |
