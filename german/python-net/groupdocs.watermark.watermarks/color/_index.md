### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [a](/watermark/python-net/groupdocs.watermark.watermarks/color/a/) | Die Alpha‑Komponente der Farbe. Gültige Werte liegen zwischen 0 und 255. |
| [b](/watermark/python-net/groupdocs.watermark.watermarks/color/b/) | Die Blau‑Komponente der Farbe, mit gültigen Werten von 0 bis 255. |
| [g](/watermark/python-net/groupdocs.watermark.watermarks/color/g/) | Der Grün‑Komponentenwert der Farbe. |
| [is_empty](/watermark/python-net/groupdocs.watermark.watermarks/color/is_empty/) | Die Eigenschaft gibt an, ob diese [`Color`](/watermark/python-net/groupdocs.watermark.watermarks/color/) Struktur nicht initialisiert ist. |
| [r](/watermark/python-net/groupdocs.watermark.watermarks/color/r/) | Die Rot‑Komponente der Farbe. Gültige Werte liegen zwischen 0 und 255. |

### Beispiel

```python
from groupdocs.watermark.watermarks import Color, TextWatermark, Font
from groupdocs.watermark import Watermarker

with Watermarker("document.pdf") as watermarker:
    watermark = TextWatermark("CONFIDENTIAL", Font("Arial", 48))
    watermark.foreground_color = Color.red
    watermarker.add(watermark)
    watermarker.save("watermarked.pdf")
```
