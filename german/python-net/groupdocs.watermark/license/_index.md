## License class

Verwaltet die Lizenzierung von GroupDocs.Watermark.

Lizenzierte Builds schalten den vollen Funktionsumfang des Wrappers frei bei
Laufzeit. Nicht lizenzierte Builds laufen im Evaluationsmodus mit derselben API
Oberfläche, jedoch mit Beschränkungen bei Ausgabegröße und wassergekennzeichnetem Inhalt.

Der Lizenztyp stellt die folgenden Mitglieder bereit:

| :- | :- |
