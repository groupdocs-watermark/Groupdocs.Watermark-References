## Metered class

Verwaltet nutzungsbasierte (Pay-per-Use) Lizenzierung.

Metered-Lizenzen werden nach tatsächlichem Verbrauch abgerechnet (typischerweise Seiten oder
verarbeitete Dokumente). Legen Sie das öffentliche/ private Schlüsselpaar einmalig fest bei
Anwendungsstart; der Wrapper meldet die Nutzung zurück an die GroupDocs
Lizenzserver im Hintergrund.

Der Metered-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [get_consumption_credit](/watermark/python-net/groupdocs.watermark/metered/get_consumption_credit/) | Gibt die bisher verbrauchten Credits zurück. |
| [get_consumption_quantity](/watermark/python-net/groupdocs.watermark/metered/get_consumption_quantity/) | Gibt die bisher verarbeiteten Datenmenge zurück. |
| [set_metered_key](/watermark/python-net/groupdocs.watermark/metered/set_metered_key/#public_key-private_key) | Aktivieren Sie die Metered-Abrechnung mit dem angegebenen öffentlichen/privaten Schlüsselpaar. |
