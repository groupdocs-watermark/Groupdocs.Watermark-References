## Watermark class

Stellt ein Wasserzeichen dar, das zu einem Dokument hinzugefügt wird.

Mehr erfahren

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Der Wasserzeichentyp stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | Die Eigenschaft gibt an, ob die Größe und Koordinaten des Wasserzeichens unter Berücksichtigung der übergeordneten Ränder berechnet werden. Wenn sie auf True gesetzt ist, berücksichtigen die Berechnungen die übergeordneten Ränder; standardmäßig ist der Wert False und übergeordnete Ränder werden ignoriert. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | Die gewünschte Höhe dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | Die horizontale Ausrichtung dieses Wasserzeichens. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | Die Eigenschaft gibt an, ob das Wasserzeichen im Hintergrund platziert werden soll. Wenn true, wird das Wasserzeichen unten platziert; andernfalls wird es oben platziert (Standard ist False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | Die Rand‑Einstellungen dieses Wasserzeichens. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | Die Deckkraft dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | Die Seiteneinrichtungs‑Einstellungen dieses Wasserzeichens. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | Der Rotationswinkel dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) in Grad. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | Die Eigenschaft gibt an, ob Informationen über hinzugefügte Wasserzeichen in den Dokumentmetadaten gespeichert werden sollen. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | Der Skalierungsfaktor dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/), der definiert, wie die Wasserzeichengröße von der Größe des übergeordneten Elements abhängt. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | Der Größentyp des Wasserzeichens. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | Die Optionen, um ein wiederholtes Wasserzeichen zu definieren. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | Die vertikale Ausrichtung dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | Die gewünschte Breite dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | Die x‑Koordinate dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | Die y‑Koordinate dieses [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
