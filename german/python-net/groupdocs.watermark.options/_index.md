Option-Klassen, die die Vorgänge der API konfigurieren.

| Klasse | Beschreibung |
| :- | :- |
| [`CreatePageStream`](/watermark/python-net/groupdocs.watermark.options/createpagestream/) | Stellt eine Methode dar, die einen Stream zurückgibt, um Seitenvorschau-Daten zu schreiben. |
| [`ILogger`](/watermark/python-net/groupdocs.watermark.options/ilogger/) | Definiert die Schnittstelle eines Loggers, der zum Protokollieren von Ereignissen und Fehlern während des Wasserzeichnens verwendet wird. |
| [`LoadOptions`](/watermark/python-net/groupdocs.watermark.options/loadoptions/) | Stellt Optionen zum Laden von Dokumenten dar, wenn ein Dokument geladen wird. |

| [`PreviewOptions`](/watermark/python-net/groupdocs.watermark.options/previewoptions/) | Bietet Optionen zum Festlegen von Anforderungen und Stream-Delegaten für die Vorschauerstellung. |
| [`ReleasePageStream`](/watermark/python-net/groupdocs.watermark.options/releasepagestream/) | Stellt eine Methode dar, die den vom [`CreatePageStream`](/watermark/python-net/groupdocs.watermark.options/createpagestream/) Delegaten erstellten Stream freigibt. |
| [`SaveOptions`](/watermark/python-net/groupdocs.watermark.options/saveoptions/) | Stellt Optionen zum Speichern von Dokumenten dar, wenn ein Dokument gespeichert wird. |
| [`WatermarkOptions`](/watermark/python-net/groupdocs.watermark.options/watermarkoptions/) | Stellt Optionen zum Hinzufügen von Wasserzeichen dar, wenn einem Dokument ein Wasserzeichen hinzugefügt wird. |
