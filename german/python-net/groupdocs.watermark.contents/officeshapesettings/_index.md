## OfficeShapeSettings class

Stellt Einstellungen dar, die auf ein Formwasserzeichen für Office-Inhalte angewendet werden können.

Der OfficeShapeSettings Typ stellt die folgenden Mitglieder bereit:

| Eigenschaft | Beschreibung |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | Der beschreibende (alternative) Text, der einer Form zugeordnet wird. |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | Der Name der Form. |
