## OfficeImageEffects class

Stellt Effekte dar, die auf ein Bildwasserzeichen für Office-Inhalte angewendet werden können.

Der Typ OfficeImageEffects stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Die Zeilenformat-Einstellungen für den Bildrand. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | Die Helligkeit des Bildes. Muss ein Float zwischen 0.0 (dunkelste) und 1.0 (hellste) sein. Der Standardwert ist 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | Der Farbwert des Bildes, das als transparent behandelt wird. Der Standardwert ist eine vollständig transparente Farbe. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Der Kontrast für das angegebene Bild. Muss ein Gleitkommawert zwischen 0,0 (geringster Kontrast) und 1,0 (höchster Kontrast) sein. Der Standardwert ist 0,5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | Die Eigenschaft gibt an, ob ein Bild im Graustufenmodus angezeigt wird. |
