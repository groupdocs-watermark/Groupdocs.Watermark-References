## ContentPart class

Stellt einen beliebigen logischen Teil eines Inhalts (Seite, Rahmen, Kopfzeile oder ein ganzer Inhalt) dar, in dem ein Wasserzeichen platziert werden kann.

Der ContentPart-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/#search_criteria) | Findet Bilder gemäß den angegebenen Suchkriterien. Die Suche wird in den in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/) angegebenen Objekten durchgeführt. |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Findet alle Bilder im Inhalt, indem in den in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/) angegebenen Objekten gesucht wird. |
