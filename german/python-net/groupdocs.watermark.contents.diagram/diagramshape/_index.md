## DiagramShape class

Stellt eine Zeichnungsform in einem Visio-Dokument dar.

Der Typ DiagramShape stellt die folgenden Mitglieder bereit:

| Eigenschaft | Beschreibung |

| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/height/) | Die Höhe dieses DiagramShape in Punkten. |
| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | Die Sammlung von Hyperlinks, die an diesem [`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/) angehängt sind. |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | Der Bezeichner dieses DiagramShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | Das Bild dieses DiagramShape. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | Der Name dieses DiagramShape. |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | Die übergeordnete Seite dieses DiagramShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | Der Drehwinkel dieses DiagramShape in Grad. |
| [text](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/text/) | Der Text dieses DiagramShape. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | Die Breite dieses DiagramShape in Punkten. |

| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | Der vertikale Versatz dieses DiagramShape vom unteren Seitenrand in Punkten. |
