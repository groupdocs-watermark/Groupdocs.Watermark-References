## DiagramHeaderFooterFont class

Stellt eine Schriftart dar, die in Visio-Kopf-/Fußzeilen verwendet wird.

Der DiagramHeaderFooterFont-Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [bold](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramheaderfooterfont/bold/) | Die Schrift ist fett. |
| [family_name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramheaderfooterfont/family_name/) | Der Name der Schriftfamilie. |
| [italic](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramheaderfooterfont/italic/) | Die Schrift ist kursiv. |
| [size](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramheaderfooterfont/size/) | Die Höhe der Schrift. |
| [strikeout](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramheaderfooterfont/strikeout/) | Die Schrift ist durchgestrichen. |
| [underline](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramheaderfooterfont/underline/) | Das Unterstreichungsflag der Schrift. |
