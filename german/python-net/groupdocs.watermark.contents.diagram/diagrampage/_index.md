## DiagramPage class

Stellt eine Visio-Dokumentseite dar.

Der DiagramPage-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Findet Bilder gemäß den angegebenen Suchkriterien. Die Suche wird in den in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/) angegebenen Objekten durchgeführt. (geerbt von [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) | (geerbt von [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | Findet mögliche Wasserzeichen gemäß den angegebenen Suchkriterien. Die Suche wird an den in [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/) aufgeführten Objekten durchgeführt. (geerbt von [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) | (geerbt von [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [background_page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/background_page/) | Die Hintergrundseite für diese DiagramPage. |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/bottom_margin/) | Die Größe des unteren Randes in Punkten. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/height/) | Die Höhe dieser DiagramPage in Punkten. |
| [is_background](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_background/) | Die Seite ist eine Hintergrundseite. |
| [is_visible](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_visible/) | Der Wert, der angibt, ob die Seite in der UI sichtbar ist. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/left_margin/) | Die Größe des linken Randes in Punkten. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/name/) | Der Name dieser DiagramPage. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/right_margin/) | Die Größe des rechten Randes in Punkten. |
| [shapes](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/shapes/) | Die Sammlung aller Formen der Seite. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/top_margin/) | Die Größe des oberen Randes in Punkten. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/width/) | Die Breite dieser DiagramPage in Punkten. |
