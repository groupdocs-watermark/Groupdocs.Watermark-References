## RTF field

Vom Microsoft eingeführt und dokumentiert, stellt das Rich Text Format (RTF) eine Methode zur Kodierung von formatiertem Text und Grafiken für die Verwendung in Anwendungen dar. Das Format erleichtert den plattformübergreifenden Dokumentenaustausch mit anderen Microsoft‑Produkten und dient damit der Interoperabilität. Erfahren Sie hier mehr über dieses Dateiformat.
