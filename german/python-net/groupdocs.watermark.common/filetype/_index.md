## FileType class

Stellt den Dateityp dar.

Stellt Methoden bereit, um eine Liste aller von [`GroupDocs.Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) unterstützten Dateitypen zu erhalten.

Der FileType‑Typ stellt die folgenden Mitglieder bereit:

| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#obj) | Bestimmt, ob der aktuelle FileType derselbe ist wie das angegebene Objekt. |

| [from_extension](/watermark/python-net/groupdocs.watermark.common/filetype/from_extension/#extension) | Ordnet die Dateierweiterung dem Dateityp zu. |

| [extension](/watermark/python-net/groupdocs.watermark.common/filetype/extension/) | Der Dateinamen‑Suffix (einschließlich des Punktes "."), z. B. ".doc". |
| [file_format_name](/watermark/python-net/groupdocs.watermark.common/filetype/file_format_name/) | Der Dateityp‑Name, z. B. "Microsoft Word Document". |
| [format_family](/watermark/python-net/groupdocs.watermark.common/filetype/format_family/) | Die Formatfamilie. |

### Beispiel

```python
from groupdocs.watermark.common import FileType

def list_supported_formats():
    # Alle Dateitypen auflisten, die die Bibliothek öffnen kann
    supported_file_types = FileType.get_supported_file_types()
    for file_type in sorted(supported_file_types, key=lambda x: x.extension):
        print(file_type)

if __name__ == "__main__":
    list_supported_formats()
```
