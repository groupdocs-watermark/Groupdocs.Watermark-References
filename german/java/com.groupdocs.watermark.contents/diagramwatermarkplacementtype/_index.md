Gibt an, zu welchen Seiten ein Wasserzeichen hinzugefügt werden soll.

## Felder

| Feld | Beschreibung |
| --- | --- |
|  | [ForegroundPages](#ForegroundPages) | Ein Wasserzeichen sollte nur zu Vordergrundseiten hinzugefügt werden. |
|
|  | [BackgroundPages](#BackgroundPages) | Ein Wasserzeichen sollte nur zu Hintergrundseiten hinzugefügt werden. |
|
|  | [AllPages](#AllPages) | Ein Wasserzeichen sollte zu allen Seiten hinzugefügt werden. |
|
|  | [SeparateBackgrounds](#SeparateBackgrounds) | Separate Hintergrundseiten mit einem Wasserzeichen sollten erstellt und allen Seiten ohne Hintergrund zugewiesen werden. |
|
|  | [Default](#Default) | Das gleiche wie `#ForegroundPages.ForegroundPages`. |
|
