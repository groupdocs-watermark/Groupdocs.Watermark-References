Gibt die Anzahl der Elemente an, die eine Sammlung formatierter Textfragmente enthalten kann.

## Felder

| Feld | Beschreibung |
| --- | --- |
|  | [UnlimitedFragments](#UnlimitedFragments) | Mehrere Stile sind erlaubt, die Sammlung kann eine unbegrenzte Anzahl von Fragmenten enthalten. |
|
|  | [SingleFragment](#SingleFragment) | Der gesamte Text kann mit einem einzigen Stil formatiert werden, die Sammlung kann nur ein Fragment enthalten. |
|
|  | [NoFormattedText](#NoFormattedText) | Das übergeordnete Objekt unterstützt keine Textformatierung, die Sammlung ist immer leer. |
|
