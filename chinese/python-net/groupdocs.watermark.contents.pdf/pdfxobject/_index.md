## PdfXObject class

表示 pdf 文档中的 XObject.

了解更多

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

该 PdfXObject 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | 该 PdfXObject 的高度（单位：点）。 |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | 该 PdfXObject 的父页面。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | 该 PdfXObject 的旋转角度（单位：度）。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | 该 [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) 的宽度（单位：点）。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | 该 PdfXObject 相对于页面左边界的水平偏移（单位：点）。该 PdfXObject 的 x 坐标。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | 该 PdfXObject 相对于页面底部边界的垂直偏移（单位：点）（y 坐标）。 |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | 此 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) 的格式化文本片段集合。（继承自 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)） |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | 此 PdfShape 的图像。如果对象没有图像，则返回 None。（继承自 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)） |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | 此 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) 的文本。（继承自 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)） |
