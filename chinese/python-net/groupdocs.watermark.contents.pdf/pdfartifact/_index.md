## PdfArtifact class

表示 PDF 内容中的工件。

了解更多：
- https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithartifacts

PdfArtifact 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [artifact_subtype](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_subtype/) | 此 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) 的子类型。 |
| [artifact_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_type/) | 此 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) 的类型。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/height/) | 此 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) 的高度（以点为单位）。 |
| [opacity](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/opacity/) | 此 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) 的不透明度。 |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/page/) | 此 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) 的父页面。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/rotate_angle/) | 此 PdfArtifact 的旋转角度（以度为单位）。 |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/text/) | 此 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) 的文本。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/width/) | 此 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) 的宽度（以点为单位）。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/x/) | 此 PdfArtifact 相对于页面左边界的水平偏移（以点为单位）。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/y/) | 此 PdfArtifact 相对于页面底部边界的垂直偏移（以点为单位）。 |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | 此 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/) 的格式化文本片段集合。（继承自 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)） |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | 此 PdfShape 的图像。如果对象没有图像，则返回 None。（继承自 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)） |
