## Metered class

管理计量（按使用付费）许可。

Metered 许可证根据实际消耗计费（通常是页面或
处理的文档）。在
应用程序启动时；包装器会将使用情况报告回 GroupDocs
许可证服务器后台。

Metered 类型公开以下成员：

### 方法
| 方法 | 描述 |
| :- | :- |
| [get_consumption_credit](/watermark/python-net/groupdocs.watermark/metered/get_consumption_credit/) | 返回迄今为止消耗的积分数量。 |
| [get_consumption_quantity](/watermark/python-net/groupdocs.watermark/metered/get_consumption_quantity/) | 返回迄今为止处理的数据量。 |
| [set_metered_key](/watermark/python-net/groupdocs.watermark/metered/set_metered_key/#public_key-private_key) | 使用给定的公/私钥对激活计量计费。 |
