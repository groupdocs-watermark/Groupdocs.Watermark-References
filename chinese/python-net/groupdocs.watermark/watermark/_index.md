## Watermark class

表示要添加到文档的水印。

了解更多

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Watermark 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | 属性指示是否在计算水印大小和坐标时考虑父级边距。如果设置为 True，计算会考虑父级边距；默认情况下值为 False，父级边距将被忽略。 |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的期望高度。 |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | 此 Watermark 的水平对齐方式。 |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | 属性指示是否应将水印放置在背景中。如果为 true，水印放置在底部；否则放置在顶部（默认值为 False）。 |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | 此 Watermark 的边距设置。 |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的不透明度。 |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | 此 Watermark 的页面设置。 |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的旋转角度（以度为单位）。 |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | 属性指示是否在文档元数据中保存已添加水印的信息。 |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的缩放因子，定义水印大小如何随父级大小而变化。 |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | 水印的尺寸类型。 |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | 定义重复水印的选项。 |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的垂直对齐方式。 |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的期望宽度。 |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的 x 坐标。 |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | 此 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) 的 y 坐标。 |
