## RTF field

Rich Text Format（RTF）由 Microsoft 引入并文档化，代表一种用于在应用程序中编码格式化文本和图形的方法。该格式促进了与其他 Microsoft 产品之间的跨平台文档交换，从而实现互操作性。了解更多关于此文件格式的信息。
