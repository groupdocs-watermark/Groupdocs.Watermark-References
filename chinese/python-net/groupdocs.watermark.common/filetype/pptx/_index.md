## PPTX field

PPTX 扩展名的文件是使用流行的 Microsoft PowerPoint 应用程序创建的演示文稿文件。不同于之前的二进制 PPT 演示文稿格式，PPTX 基于 Microsoft PowerPoint 开放 XML 演示文稿文件格式。了解有关此文件格式的更多信息，请点击此处。
