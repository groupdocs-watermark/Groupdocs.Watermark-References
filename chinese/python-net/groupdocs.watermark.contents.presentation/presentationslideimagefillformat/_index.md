## PresentationSlideImageFillFormat class

表示 PowerPoint 文档中幻灯片的图像填充格式设置。

PresentationSlideImageFillFormat 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslideimagefillformat/background_image/) | 背景图像；如果未设置图像，则返回 None。 |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | 当设置为 True 时，图像在背景上平铺；否则会被拉伸。（继承自 [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)） |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | 背景图像的透明度，取值范围为 0.0（不透明）至 1.0（完全透明）。（继承自 [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)） |
