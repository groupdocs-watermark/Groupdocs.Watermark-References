## PresentationImageFillFormat class

表示 PowerPoint 文档中的图像填充格式设置。

PresentationImageFillFormat 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | 背景图像。如果未设置图像，则返回 None。 |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | 当设置为 True 时，图像将在背景中平铺；否则会被拉伸。 |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | 背景图像的透明度，取值范围为 0.0（不透明）至 1.0（完全透明）。 |
