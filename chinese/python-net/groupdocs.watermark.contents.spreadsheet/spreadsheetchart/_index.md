## SpreadsheetChart class

表示 Excel 文档中的图表。

SpreadsheetChart 类型公开以下成员:

### 属性
| 属性 | 描述 |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | 与此 [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/) 关联的描述性（替代）文本。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | 此 SpreadsheetChart 的高度（单位：点）。 |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | 与此 SpreadsheetChart 关联的超链接。 |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | 此 SpreadsheetChart 的标识符。 |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | 此 SpreadsheetChart 的图像填充格式设置。 |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | 此 SpreadsheetChart 的名称。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | 此 SpreadsheetChart 的宽度（单位：点）。 |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | 此 SpreadsheetChart 的父工作表。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | 此 SpreadsheetChart 相对于工作表左边界的水平偏移（单位：点）。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | 此 SpreadsheetChart 相对于工作表顶部边界的垂直偏移（单位：点）。 |
