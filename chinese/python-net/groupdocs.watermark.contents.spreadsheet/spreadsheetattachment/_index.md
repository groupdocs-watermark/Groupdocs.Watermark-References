## SpreadsheetAttachment class

SpreadsheetAttachment 类型公开以下成员：

### 方法
| 方法 | 描述 |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | 从附加文件加载内容。（继承自 [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)） |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | （继承自 [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)） |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | 检索存储在附加文件中的文档信息。（继承自 [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)） |

| 属性 | 描述 |
| :- | :- |

| [content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/content/) | 附件文件内容。 |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/height/) | 附件框架的高度（以磅为单位）。 |
| [is_link](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/is_link/) | 该属性指示附件是否仅包含指向文件的链接。 |
| [preview_image_content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/preview_image_content/) | 附件文件的预览图像，以字节数组形式。 |
| [source_full_name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/source_full_name/) | 附件文件的完整名称。 |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/width/) | 附件框架的宽度（单位：点）。 |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/x/) | 附件框架相对于工作表左边界的水平偏移量（单位：点）。 |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/y/) | 附件框架的 y 坐标（单位：点）。 |
