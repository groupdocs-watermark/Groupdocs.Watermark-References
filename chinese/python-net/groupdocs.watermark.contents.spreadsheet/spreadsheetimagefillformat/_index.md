## SpreadsheetImageFillFormat class

表示 Excel 文档中图像填充格式的设置。

SpreadsheetImageFillFormat 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | 背景图像。如果未设置图像，则返回 None。 |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | 当为 True 时，图像在背景上平铺；否则图像将被拉伸。 |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | 背景图像的透明度，取值范围为 0.0（不透明）至 1.0（完全透明）。 |
