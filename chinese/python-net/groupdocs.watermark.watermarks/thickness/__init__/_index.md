## __init__ {#left-right-top-bottom}

使用特定长度初始化一个新的 Thickness 实例，应用于矩形的每一侧。

```python
def __init__(self, left, right, top, bottom):
    ...
```

| 参数 | 类型 | 描述 |
| :- | :- | :- |
| left | `float` | 矩形左侧的厚度。 |
| right | `float` | 矩形右侧的厚度。 |
| top | `float` | 矩形顶部的厚度。 |
| bottom | `float` | 矩形底部的厚度。 |

## __init__ {#uniform_length}

使用指定的统一长度初始化一个新的 Thickness 实例，适用于每一侧。

```python
def __init__(self, uniform_length):
    ...
```

| 参数 | 类型 | 描述 |
| :- | :- | :- |
| uniform_length | `float` | 应用于边界矩形四个侧面的统一长度。 |
