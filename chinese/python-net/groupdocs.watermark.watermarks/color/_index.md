### 属性
| 属性 | 描述 |
| :- | :- |
| [a](/watermark/python-net/groupdocs.watermark.watermarks/color/a/) | 颜色的 alpha 分量。有效值范围为 0 到 255。 |
| [b](/watermark/python-net/groupdocs.watermark.watermarks/color/b/) | 颜色的蓝色分量，有效值范围为 0 到 255。 |
| [g](/watermark/python-net/groupdocs.watermark.watermarks/color/g/) | 颜色的绿色分量值。 |
| [is_empty](/watermark/python-net/groupdocs.watermark.watermarks/color/is_empty/) | 此属性指示此 [`Color`](/watermark/python-net/groupdocs.watermark.watermarks/color/) 结构是否未初始化。 |
| [r](/watermark/python-net/groupdocs.watermark.watermarks/color/r/) | 颜色的红色分量。有效值范围为 0 到 255。 |

### 示例

```python
from groupdocs.watermark.watermarks import Color, TextWatermark, Font
from groupdocs.watermark import Watermarker

with Watermarker("document.pdf") as watermarker:
    watermark = TextWatermark("CONFIDENTIAL", Font("Arial", 48))
    watermark.foreground_color = Color.red
    watermarker.add(watermark)
    watermarker.save("watermarked.pdf")
```
