Margins 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | 底部边距。表示相对于父级底部边框的水平偏移。 |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | 左侧边距，表示相对于父级左边框的水平偏移。 |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | 边距类型，决定边距的解释方式；设置新值会自动将所有边距重置为默认值（零）。 |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | 右侧边距，作为相对于父级右边框的水平偏移。 |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | 顶部边距。 |
