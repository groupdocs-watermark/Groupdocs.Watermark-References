## OfficeImageEffects class

表示可应用于办公内容图像水印的效果。

该 OfficeImageEffects 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | 图像边框的线条格式设置。 |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | 图片的亮度。必须是 0.0（最暗）到 1.0（最亮）之间的浮点数。默认值为 0.5。 |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | 图像将被视为透明的颜色值。默认值是完全透明的颜色。 |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | 指定图片的对比度。必须是介于 0.0（最低对比度）和 1.0（最高对比度）之间的浮点数。默认值为 0.5。 |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | 该属性指示图片是否以灰度模式显示。 |
