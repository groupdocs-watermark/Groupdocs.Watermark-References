## Watermark.ConsiderParentMargins property

获取或设置一个值，指示是否在计算水印大小和坐标时考虑父级边距。

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

如果值为 true，则在计算水印大小和坐标时会考虑父级边距。默认情况下，值为 false，父级边距将被忽略。
