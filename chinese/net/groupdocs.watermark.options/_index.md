此命名空间提供用于在处理文档和水印时指定附加选项的类。

## 类

| 类 | 描述 |
| --- | --- |
| [CreatePageStream](./createpagestream) | 表示返回用于写入页面预览数据的流的方法。 |
| [LoadOptions](./loadoptions) | 表示加载文档时的文档加载选项。 |
| [OoxmlLoadOptions](./ooxmlloadoptions) | 表示 OOXML 文档的文档加载选项。 |
| [PreviewOptions](./previewoptions) | 提供用于预览生成的需求设置和流委托的选项。 |
| [ReleasePageStream](./releasepagestream) | 表示一个释放由[`CreatePageStream`](../groupdocs.watermark.options/createpagestream)委托创建的流的方法。 |
| [SaveOptions](./saveoptions) | 表示文档保存时的选项。 |
| [WatermarkOptions](./watermarkoptions) | 表示向文档添加水印时的选项。 |
