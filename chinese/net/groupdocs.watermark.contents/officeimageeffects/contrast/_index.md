## OfficeImageEffects.Contrast property

获取或设置指定图片的对比度。此属性的值必须是介于 0.0（最低对比度）到 1.0（最高对比度）之间的数字。

```csharp
public double Contrast { get; set; }
```

### Property Value

默认值为 0.5。
