此命名空间提供用于处理任何受支持类型文档的类。

## 类

| 类 | 描述 |
| --- | --- |
| [Content](./content) | 表示可以放置水印的内容。 |
| [ContentPart](./contentpart) | 表示内容的任何逻辑部分（页面、框架、页眉或整个内容），可以放置水印。 |
| [OfficeImageEffects](./officeimageeffects) | 表示可应用于办公内容的图像水印的效果。 |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | 表示任何受支持的办公内容中的图像填充格式设置。 |
| [OfficeLineFormat](./officelineformat) | 表示形状线条格式。 |
| [OfficeShapeSettings](./officeshapesettings) | 表示可应用于办公内容的形状水印的设置。 |
| [OfficeTextEffects](./officetexteffects) | 表示可应用于办公内容的文字水印的效果。 |
## 枚举

| 枚举 | 描述 |
| --- | --- |
| [OfficeDashStyle](./officedashstyle) | 表示虚线样式。 |
| [OfficeHeaderFooterType](./officeheaderfootertype) | 标识页眉或页脚的类型。 |
| [OfficeLineStyle](./officelinestyle) | 表示 [`OfficeLineFormat`](../groupdocs.watermark.contents/officelineformat) 的复合线样式。 |
