此命名空间提供用于在处理水印和 PDF 文档时指定附加选项的类。

## 类

| 类 | 描述 |
| --- | --- |
| [PdfAnnotationWatermarkOptions](./pdfannotationwatermarkoptions) | 表示在向 PDF 文档添加注释水印时的水印添加选项。 |
| [PdfArtifactWatermarkOptions](./pdfartifactwatermarkoptions) | 表示在向 PDF 文档添加工件水印时的水印添加选项。 |
| [PdfLoadOptions](./pdfloadoptions) | 表示 PDF 文档的文档加载选项。 |
| [PdfPreviewOptions](./pdfpreviewoptions) | 提供用于设置 PDF 文档预览生成的要求和流委托的选项。 |
| [PdfSaveOptions](./pdfsaveoptions) | 表示保存 PDF 文档时的文档保存选项。 |
| [PdfWatermarkOptions](./pdfwatermarkoptions) | PDF 文档水印添加选项的基类。 |
| [PdfXObjectWatermarkOptions](./pdfxobjectwatermarkoptions) | 表示在向 PDF 文档添加 XObject 水印时的水印添加选项。 |
