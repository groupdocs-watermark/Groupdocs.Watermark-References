此命名空间提供用于在处理水印和 Word 文档时指定附加选项的类。

## 类

| 类 | 描述 |
| --- | --- |
| [WordProcessingImageEffects](./wordprocessingimageeffects) | 表示可应用于 Word 文档中图像水印的效果。 |
| [WordProcessingLoadOptions](./wordprocessingloadoptions) | 表示 Word 文档的文档加载选项。 |
| [WordProcessingPreviewOptions](./wordprocessingpreviewoptions) | 提供用于设置要求和流委托的选项，以生成 WordProcessing 文档的预览。 |
| [WordProcessingSaveOptions](./wordprocessingsaveoptions) | 表示保存 Word 文档时的文档保存选项。 |
| [WordProcessingTextEffects](./wordprocessingtexteffects) | 表示可应用于 Word 文档中文本水印的效果。 |
| [WordProcessingWatermarkBaseOptions](./wordprocessingwatermarkbaseoptions) | 用于向 Word 文档添加水印选项的基类。 |
| [WordProcessingWatermarkHeaderFooterOptions](./wordprocessingwatermarkheaderfooteroptions) | 表示向 Word 部分页眉/页脚添加水印时的选项。 |
| [WordProcessingWatermarkPagesOptions](./wordprocessingwatermarkpagesoptions) | 表示向 Word 文档页面添加水印时的选项。 |
| [WordProcessingWatermarkSectionOptions](./wordprocessingwatermarksectionoptions) | 表示向 Word 文档节添加形状水印时的选项。 |
