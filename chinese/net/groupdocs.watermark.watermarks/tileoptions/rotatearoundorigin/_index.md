## TileOptions.RotateAroundOrigin property

获取或设置一个值，指示是否应将重复的水印围绕文档中心旋转。

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` 如果重复水印应围绕文档左下角旋转；否则为 `false`，在这种情况下旋转将相对于文档左边缘。默认值为 `false`。
