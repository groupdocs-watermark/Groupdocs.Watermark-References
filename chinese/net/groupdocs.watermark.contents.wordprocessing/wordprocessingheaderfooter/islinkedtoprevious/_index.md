## WordProcessingHeaderFooter.IsLinkedToPrevious property

获取或设置一个值，指示此页眉/页脚是否链接到前一节中对应的页眉/页脚。

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

如果此页眉/页脚链接到前一节中的相应页眉/页脚，则为 True；否则为 false。

### 备注

默认值为 true。注意，当您链接页眉或页脚时，其内容会被清除。
