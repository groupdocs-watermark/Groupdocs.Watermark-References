## XLS field

Les fichiers avec l'extension XLS représentent le format de fichier binaire Excel. Ces fichiers peuvent être créés par Microsoft Excel ainsi que par d'autres programmes de feuille de calcul similaires tels qu'OpenOffice Calc ou Apple Numbers. En savoir plus sur ce format de fichier ici.
