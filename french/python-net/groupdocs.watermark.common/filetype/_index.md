## FileType class

Représente le type de fichier.

Fournit des méthodes pour obtenir une liste de tous les types de fichiers pris en charge par [`GroupDocs.Watermark`](/watermark/python-net/groupdocs.watermark/watermark/).

Le type FileType expose les membres suivants :

| :- | :- |

| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#obj) | Détermine si le FileType actuel est le même que l'objet spécifié. |

### Exemple

```python
from groupdocs.watermark.common import FileType

def list_supported_formats():
    # Énumérez chaque type de fichier que la bibliothèque peut ouvrir
    supported_file_types = FileType.get_supported_file_types()
    for file_type in sorted(supported_file_types, key=lambda x: x.extension):
        print(file_type)

if __name__ == "__main__":
    list_supported_formats()
```
