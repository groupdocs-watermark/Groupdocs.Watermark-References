## searchable_objects property

Les objets qui doivent être inclus dans une recherche de filigrane.

Cette propriété spécifie également les objets de contenu qui sont utilisés dans la recherche d'images. Pour plus d'informations, voir les méthodes [`Watermarker.search`](/watermark/python-net/groupdocs.watermark/watermarker/search/) et [`Watermarker.get_images`](/watermark/python-net/groupdocs.watermark/watermarker/get_images/).

En savoir plus sur la recherche de filigranes : https://docs.groupdocs.com/display/watermarknet/Searching+watermarks
