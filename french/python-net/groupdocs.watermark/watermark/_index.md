## Watermark class

Représente un filigrane à ajouter à un document.

En savoir plus

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Le type Watermark expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | La propriété indiquant si la taille et les coordonnées du filigrane sont calculées en tenant compte des marges du parent. Si elle est définie sur True, les calculs tiennent compte des marges du parent ; par défaut, la valeur est False et les marges du parent sont ignorées. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | La hauteur souhaitée de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | L'alignement horizontal de ce Watermark. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | La propriété indiquant si le filigrane doit être placé en arrière-plan. Si true, le filigrane est placé en bas ; sinon, il est placé en haut (par défaut, False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | Les paramètres de marge de ce Watermark. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | L'opacité de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | Les paramètres de configuration des pages de ce Watermark. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | L'angle de rotation de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) en degrés. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | La propriété indique s'il faut enregistrer les informations sur les filigranes ajoutés dans les métadonnées du document. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | Le facteur d'échelle de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/), définissant comment la taille du filigrane dépend de la taille du parent. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | Le type de dimension du filigrane. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | Les options pour définir un filigrane répété. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | L'alignement vertical de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | La largeur souhaitée de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | La coordonnée x de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | La coordonnée y de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
