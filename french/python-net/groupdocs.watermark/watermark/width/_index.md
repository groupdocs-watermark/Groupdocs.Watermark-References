## width property

La largeur souhaitée de ce [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/).

Définir cette propriété modifiera également la valeur de la propriété [`Watermark.sizing_type`](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) à `SizingType.absolute`.
