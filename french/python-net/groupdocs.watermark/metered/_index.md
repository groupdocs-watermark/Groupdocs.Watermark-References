## Metered class

Gère la licence à la consommation (pay-per-use).

Les licences mesurées facturent la consommation réelle (généralement les pages ou
documents traités). Définissez la paire de clés publique/privée une fois au
démarrage de l'application ; le wrapper renvoie l'utilisation au serveur GroupDocs
de licences en arrière-plan.

Le type Metered expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [get_consumption_credit](/watermark/python-net/groupdocs.watermark/metered/get_consumption_credit/) | Renvoie le nombre de crédits consommés jusqu'à présent. |
| [get_consumption_quantity](/watermark/python-net/groupdocs.watermark/metered/get_consumption_quantity/) | Renvoie la quantité de données traitées jusqu'à présent. |
| [set_metered_key](/watermark/python-net/groupdocs.watermark/metered/set_metered_key/#public_key-private_key) | Activez la facturation mesurée avec la paire de clés publique/privée fournie. |
