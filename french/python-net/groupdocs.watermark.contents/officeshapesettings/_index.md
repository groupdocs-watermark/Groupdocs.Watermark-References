## OfficeShapeSettings class

Représente les paramètres qui peuvent être appliqués à un filigrane de forme pour un contenu Office.

Le type OfficeShapeSettings expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | Le texte descriptif (alternatif) qui sera associé à une forme. |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | Le nom de la forme. |
