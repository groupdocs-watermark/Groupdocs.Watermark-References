## OfficeImageEffects class

Représente les effets qui peuvent être appliqués à un filigrane d'image pour un contenu Office.

Le type OfficeImageEffects expose les membres suivants:

### Propriétés
| Propriété | Description |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Les paramètres de format de ligne pour la bordure de l'image. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | La luminosité de l'image. Doit être un nombre à virgule flottante compris entre 0,0 (le plus sombre) et 1,0 (le plus lumineux). La valeur par défaut est 0,5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | La valeur de couleur de l'image qui sera traitée comme transparente. La valeur par défaut est une couleur totalement transparente. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Le contraste pour l'image spécifiée. Doit être un nombre flottant compris entre 0.0 (le contraste le plus faible) et 1.0 (le contraste le plus élevé). La valeur par défaut est 0.5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | La propriété indique si une image sera affichée en mode niveaux de gris. |
