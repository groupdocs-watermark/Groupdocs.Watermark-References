## PresentationImageFillFormat class

Représente les paramètres de format de remplissage d'image dans un document PowerPoint.

Le type PresentationImageFillFormat expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | L'image d'arrière-plan. Retourne None si l'image n'est pas définie. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | L'image est répétée en mosaïque sur l'arrière-plan lorsqu'elle est définie sur True ; sinon elle est étirée. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | La transparence de l'image d'arrière-plan sous forme d'une valeur comprise entre 0.0 (opaque) et 1.0 (totalement transparent). |
