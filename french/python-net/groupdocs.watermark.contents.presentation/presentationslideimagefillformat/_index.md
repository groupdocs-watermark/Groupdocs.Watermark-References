## PresentationSlideImageFillFormat class

Représente les paramètres du format de remplissage d'image pour une diapositive dans un document PowerPoint.

Le type PresentationSlideImageFillFormat expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslideimagefillformat/background_image/) | L'image d'arrière-plan ; renvoie None si l'image n'est pas définie. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | L'image est répétée en mosaïque sur l'arrière-plan lorsqu'elle est définie sur True ; sinon elle est étirée. (hérité de [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | La transparence de l'image d'arrière-plan sous forme d'une valeur de 0.0 (opaque) à 1.0 (entièrement transparent). (hérité de [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
