## watermark_id property

L'identifiant unique du filigrane, utilisé pour modifier le filigrane via les méthodes Update ou Delete.

L'identifiant est défini automatiquement après l'appel de la méthode Add. Si l'identifiant a été enregistré précédemment, il peut être défini manuellement pour manipuler le filigrane.
