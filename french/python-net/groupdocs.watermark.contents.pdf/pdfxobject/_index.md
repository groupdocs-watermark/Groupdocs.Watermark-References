## PdfXObject class

Représente un XObject dans un document pdf.

En savoir plus

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

Le type PdfXObject expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | La hauteur de ce PdfXObject en points. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | La page parente de ce PdfXObject. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | L'angle de rotation de ce PdfXObject en degrés. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | La largeur de ce [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) en points. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | Le décalage horizontal de ce PdfXObject depuis la bordure gauche de la page en points. La coordonnée x de ce PdfXObject. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | Le décalage vertical de ce PdfXObject depuis la bordure inférieure de la page en points (la coordonnée y). |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La collection des fragments de texte formatés de ce [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (hérité de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | L'image de ce PdfShape. Retourne None si l'objet n'a pas d'image. (hérité de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Le texte de ce [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (hérité de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
