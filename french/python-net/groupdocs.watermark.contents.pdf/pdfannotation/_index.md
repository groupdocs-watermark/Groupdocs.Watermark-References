## PdfAnnotation class

Représente une annotation dans un document pdf.

En savoir plus :
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

Le type PdfAnnotation expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | Le type de ce [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/height/) | La hauteur de ce PdfAnnotation en points. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/page/) | La page parente de ce [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | L'angle de rotation de ce PdfAnnotation en degrés. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | La largeur de ce PdfAnnotation en points. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | Le décalage horizontal de ce PdfAnnotation par rapport à la bordure gauche de la page en points. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/y/) | Le décalage vertical de ce [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) par rapport à la bordure inférieure de la feuille de calcul en points. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La collection des fragments de texte formatés de ce [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). | [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | L'image de ce PdfShape. Retourne None si l'objet n'a pas d'image. (hérité de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Le texte de ce [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (hérité de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
