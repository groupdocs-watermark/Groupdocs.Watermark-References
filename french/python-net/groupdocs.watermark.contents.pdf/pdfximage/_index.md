## PdfXImage class

Représente un XImage dans un contenu pdf.

Le type PdfXImage expose les membres suivants :

| Propriété | Description |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/height/) | La hauteur de l'objet. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/rotate_angle/) | L'angle de rotation de l'objet en degrés. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/width/) | La largeur de l'objet. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/x/) | La coordonnée x de l'objet. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfximage/y/) | La coordonnée y de l'objet. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La collection des fragments de texte formatés de ce [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). | [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | L'image de ce PdfShape. Retourne None si l'objet n'a pas d'image. (hérité de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | La page parente de ce PdfXObject. (hérité de [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Le texte de ce [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (hérité de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
