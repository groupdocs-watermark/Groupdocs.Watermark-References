## SpreadsheetImageFillFormat class

Représente les paramètres de format de remplissage d'image dans un document Excel.

Le type SpreadsheetImageFillFormat expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | L'image d'arrière-plan. Retourne None si l'image n'est pas définie. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | L'image est répétée en mosaïque sur l'arrière-plan lorsque True ; sinon l'image est étirée. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | La transparence de l'image d'arrière-plan sous forme d'une valeur comprise entre 0.0 (opaque) et 1.0 (totalement transparent). |
