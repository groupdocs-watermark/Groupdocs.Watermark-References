## SpreadsheetShape class

Représente une forme de dessin dans un document Excel.

Le type SpreadsheetShape expose les membres suivants:

### Propriétés
| Propriété | Description |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/alternative_text/) | Le texte descriptif (alternatif) associé à ce [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [auto_shape_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/auto_shape_type/) | Le type de forme automatique. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/formatted_text_fragments/) | La collection de fragments de texte formatés de ce SpreadsheetShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/height/) | La hauteur de ce SpreadsheetShape en points. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/hyperlink/) | Le lien hypertexte associé à ce [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/id/) | L'identifiant de ce SpreadsheetShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image/) | L'image de ce SpreadsheetShape. Retourne None si la forme n'a pas d'image. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image_fill_format/) | Les paramètres du format de remplissage d'image de ce SpreadsheetShape. |
| [is_word_art](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/is_word_art/) | La forme est un objet WordArt. |
| [mso_drawing_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/mso_drawing_type/) | Le type de dessin mso. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/name/) | Le nom de ce SpreadsheetShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/rotate_angle/) | L'angle de rotation de ce [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) en degrés. |
| [text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/text/) | Le texte de ce [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/width/) | La largeur de ce SpreadsheetShape en points. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/worksheet/) | La feuille de calcul parente de ce SpreadsheetShape. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/x/) | Le décalage horizontal de ce SpreadsheetShape par rapport à la bordure gauche de la feuille de calcul en points. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/y/) | La coordonnée y de ce SpreadsheetShape par rapport à la bordure supérieure de la feuille de calcul en points. |
