## SpreadsheetChart class

Représente un graphique dans un document Excel.

Le type SpreadsheetChart expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | Le texte descriptif (alternatif) associé à ce [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | La hauteur de ce SpreadsheetChart en points. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | Le lien hypertexte associé à ce SpreadsheetChart. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | L'identifiant de ce SpreadsheetChart. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | Les paramètres du format de remplissage d'image de ce SpreadsheetChart. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | Le nom de ce SpreadsheetChart. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | La largeur de ce SpreadsheetChart en points. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | La feuille de calcul parent de ce SpreadsheetChart. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | Le décalage horizontal de ce SpreadsheetChart par rapport à la bordure gauche de la feuille de calcul en points. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | Le décalage vertical de ce SpreadsheetChart par rapport à la bordure supérieure de la feuille de calcul en points. |
