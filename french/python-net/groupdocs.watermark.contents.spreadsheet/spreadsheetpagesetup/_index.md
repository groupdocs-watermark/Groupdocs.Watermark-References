## SpreadsheetPageSetup class

Représente les propriétés d'impression de page pour une feuille de calcul.

Le type SpreadsheetPageSetup expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/bottom_margin/) | La taille de la marge inférieure en points. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/height/) | La hauteur d'une page d'impression en points. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/left_margin/) | La taille de la marge gauche en points. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/right_margin/) | La taille de la marge droite en points. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/top_margin/) | La taille de la marge supérieure en points. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetpagesetup/width/) | La largeur d'une page d'impression en points. |
