## SpreadsheetAttachment class

Représente un fichier joint à un document Excel.

Le type SpreadsheetAttachment expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | Charge un contenu depuis le fichier joint. (hérité de [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | (hérité de [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | Récupère les informations sur un document stocké dans le fichier joint. (hérité de [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |

| Propriété | Description |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/alternative_text/) | Le texte descriptif (alternatif) associé au fichier joint. |
| [content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/content/) | Le contenu du fichier joint. |

| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/width/) | La largeur du cadre de la pièce jointe en points. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/x/) | Le décalage horizontal du cadre de la pièce jointe par rapport à la bordure gauche de la feuille de calcul en points. |
