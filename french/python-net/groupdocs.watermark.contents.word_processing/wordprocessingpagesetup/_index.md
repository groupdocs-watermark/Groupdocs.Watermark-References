## WordProcessingPageSetup class

Représente les propriétés d'impression de page pour une section d'un document Word.

Le type WordProcessingPageSetup expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/bottom_margin/) | La taille de la marge inférieure en points. |
| [different_first_page_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/different_first_page_header_footer/) | Le drapeau indiquant si un en-tête/pied de page différent est utilisé pour la première page. |
| [height](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/height/) | La hauteur d'une page d'impression en points. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/left_margin/) | La taille de la marge gauche en points. |
| [odd_and_even_pages_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/odd_and_even_pages_header_footer/) | La propriété indique si des en-têtes/pieds de page différents sont utilisés pour les pages impaires et paires. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/right_margin/) | La taille de la marge droite en points. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/top_margin/) | La taille de la marge supérieure en points. |
| [width](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/width/) | La largeur d'une page d'impression en points. |
