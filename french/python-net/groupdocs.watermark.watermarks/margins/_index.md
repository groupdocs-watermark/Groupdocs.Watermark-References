## Margins class

Représente les paramètres de marge pour chaque bord d'un objet.

Le type Margins expose les membres suivants:

### Constructeurs
| Constructeur | Description |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | Initialise une nouvelle instance de la classe [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/). |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | Initialise une nouvelle instance de la classe [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) avec le type, l'emplacement et la taille spécifiés. |

### Propriétés
| Propriété | Description |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | La marge inférieure. Représente le décalage horizontal par rapport à la bordure inférieure du parent. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | La marge gauche, exprimée comme le décalage horizontal par rapport à la bordure gauche du parent. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | Le type de marge, qui détermine comment les marges sont interprétées ; définir une nouvelle valeur réinitialise automatiquement toutes les marges à leurs valeurs par défaut (zéro). |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | La marge droite comme décalage horizontal par rapport à la bordure droite du parent. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | La marge supérieure. |
