### Propriétés
| Propriété | Description |
| :- | :- |
| [a](/watermark/python-net/groupdocs.watermark.watermarks/color/a/) | Le composant alpha de la couleur. Les valeurs valides sont de 0 à 255. |
| [b](/watermark/python-net/groupdocs.watermark.watermarks/color/b/) | Le composant bleu de la couleur, avec des valeurs valides de 0 à 255. |
| [g](/watermark/python-net/groupdocs.watermark.watermarks/color/g/) | La valeur du composant vert de la couleur. |
| [is_empty](/watermark/python-net/groupdocs.watermark.watermarks/color/is_empty/) | La propriété indique si cette structure [`Color`](/watermark/python-net/groupdocs.watermark.watermarks/color/) n'est pas initialisée. |
| [r](/watermark/python-net/groupdocs.watermark.watermarks/color/r/) | Le composant rouge de la couleur. Les valeurs valides sont de 0 à 255. |

### Exemple

```python
from groupdocs.watermark.watermarks import Color, TextWatermark, Font
from groupdocs.watermark import Watermarker

with Watermarker("document.pdf") as watermarker:
    watermark = TextWatermark("CONFIDENTIAL", Font("Arial", 48))
    watermark.foreground_color = Color.red
    watermarker.add(watermark)
    watermarker.save("watermarked.pdf")
```
