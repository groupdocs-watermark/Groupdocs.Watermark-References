## PresentationPreviewOptions class

Représente les options permettant de définir les exigences et les délégués de flux pour la génération d'aperçu d'un document Presentation.

Le type PresentationPreviewOptions expose les membres suivants:

| Constructeur | Description |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options.presentation/presentationpreviewoptions/__init__/#create_page_stream) | Initialise une nouvelle instance de la classe PresentationPreviewOptions entraînant la fermeture du flux de sortie. |
| [__init__](/watermark/python-net/groupdocs.watermark.options.presentation/presentationpreviewoptions/__init__/#create_page_stream-release_page_stream) | Initialise une nouvelle instance de [`PresentationPreviewOptions`](/watermark/python-net/groupdocs.watermark.options.presentation/presentationpreviewoptions/) entraînant le retour du flux de sortie au client pour une utilisation ultérieure. |
