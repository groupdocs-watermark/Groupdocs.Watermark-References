## DiagramPage class

Représente une page de document Visio.

Le type DiagramPage expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Recherche des images selon les critères de recherche spécifiés. La recherche est effectuée dans les objets spécifiés dans [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (hérité de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) | (hérité de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | Recherche les filigranes possibles selon les critères de recherche spécifiés. La recherche est effectuée sur les objets répertoriés dans [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (hérité de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) | (hérité de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |

### Propriétés
| Propriété | Description |
| :- | :- |
| [background_page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/background_page/) | La page d'arrière-plan pour ce DiagramPage. |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/bottom_margin/) | La taille de la marge inférieure en points. |

| [is_background](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_background/) | La page est une page d'arrière-plan. |
| [is_visible](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_visible/) | La valeur indiquant si la page est visible dans l'interface utilisateur. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/left_margin/) | La taille de la marge gauche en points. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/name/) | Le nom de ce DiagramPage. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/right_margin/) | La taille de la marge droite en points. |
| [shapes](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/shapes/) | La collection de toutes les formes de la page. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/top_margin/) | La taille de la marge supérieure en points. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/width/) | La largeur de ce DiagramPage en points. |
