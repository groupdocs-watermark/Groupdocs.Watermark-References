## DiagramShape class

Représente une forme de dessin dans un document Visio.

Le type DiagramShape expose les membres suivants:

| Propriété | Description |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/formatted_text_fragments/) | La collection des fragments de texte formatés de ce DiagramShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/height/) | La hauteur de ce DiagramShape en points. |
| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | La collection des hyperliens attachés à ce [`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | L'identifiant de ce DiagramShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | L'image de ce DiagramShape. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | Le nom de ce DiagramShape. |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | La page parente de ce DiagramShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | L'angle de rotation de ce DiagramShape en degrés. |
| [text](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/text/) | Le texte de ce DiagramShape. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | La largeur de ce DiagramShape en points. |
| [x](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/x/) | Le décalage horizontal de ce DiagramShape depuis la bordure gauche de la page en points, c.-à-d., sa coordonnée x. |
| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | Le décalage vertical de ce DiagramShape depuis la bordure inférieure de la page en points. |
