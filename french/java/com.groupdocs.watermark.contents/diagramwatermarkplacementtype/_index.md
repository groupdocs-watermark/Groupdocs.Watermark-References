## Champs

| Champ | Description |
| --- | --- |
|  | [ForegroundPages](#ForegroundPages) | Un filigrane doit être ajouté uniquement aux pages de premier plan. |
|
|  | [BackgroundPages](#BackgroundPages) | Un filigrane doit être ajouté uniquement aux pages d'arrière-plan. |
|
|  | [AllPages](#AllPages) | Un filigrane doit être ajouté à toutes les pages. |
|
|  | [SeparateBackgrounds](#SeparateBackgrounds) | Des pages d'arrière-plan séparées avec un filigrane doivent être créées et assignées à toutes les pages sans arrière-plan. |
