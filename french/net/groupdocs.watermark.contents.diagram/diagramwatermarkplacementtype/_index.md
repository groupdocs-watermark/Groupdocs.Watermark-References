## DiagramWatermarkPlacementType enumeration

Spécifie sur quelles pages un filigrane doit être ajouté.

```csharp
public enum DiagramWatermarkPlacementType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| ForegroundPages | `0` | Un filigrane doit être ajouté uniquement aux pages de premier plan. |
| BackgroundPages | `1` | Un filigrane doit être ajouté uniquement aux pages d'arrière-plan. |
| AllPages | `2` | Un filigrane doit être ajouté à toutes les pages. |
| SeparateBackgrounds | `3` | Des pages d'arrière-plan séparées avec un filigrane doivent être créées et affectées à toutes les pages sans arrière-plan. |
| Default | `0` | Le même que ForegroundPages. |
