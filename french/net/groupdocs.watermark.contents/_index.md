L'espace de noms fournit des classes pour travailler avec des documents de tout type pris en charge.

## Classes

| Classe | Description |
| --- | --- |
| [Content](./content) | Représente un contenu où un filigrane peut être placé. |
| [ContentPart](./contentpart) | Représente toute partie logique d'un contenu (page, cadre, en-tête ou l'ensemble du contenu) où le filigrane peut être placé. |
| [OfficeImageEffects](./officeimageeffects) | Représente les effets qui peuvent être appliqués à un filigrane d'image pour un contenu Office. |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | Représente les paramètres du format de remplissage d'image dans tout contenu Office pris en charge. |
| [OfficeLineFormat](./officelineformat) | Représente un format de ligne de forme. |
| [OfficeShapeSettings](./officeshapesettings) | Représente les paramètres qui peuvent être appliqués à un filigrane de forme pour un contenu Office. |
| [OfficeTextEffects](./officetexteffects) | Représente les effets qui peuvent être appliqués à un filigrane de texte pour un contenu Office. |
