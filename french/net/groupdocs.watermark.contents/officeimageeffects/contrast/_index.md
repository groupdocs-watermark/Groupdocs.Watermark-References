## OfficeImageEffects.Contrast property

Obtient ou définit le contraste de l'image spécifiée. La valeur de cette propriété doit être un nombre compris entre 0.0 (le contraste le plus faible) et 1.0 (le contraste le plus élevé).

```csharp
public double Contrast { get; set; }
```

### Property Value

La valeur par défaut est 0,5.
