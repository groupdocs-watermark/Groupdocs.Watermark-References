## OfficeImageEffects.Brightness property

Obtient ou définit la luminosité de l'image. La valeur de cette propriété doit être un nombre compris entre 0.0 (la plus sombre) et 1.0 (la plus lumineuse).

```csharp
public double Brightness { get; set; }
```

### Property Value

La valeur par défaut est 0,5.
