## Margins.MarginType property

Obtient ou définit le type de marge. La définition d'une nouvelle valeur pour cette propriété réinitialise automatiquement toutes les marges à leurs valeurs par défaut (zéro).

```csharp
public MarginType MarginType { get; set; }
```

### Property Value

La valeur spécifiant comment les marges doivent être interprétées.

### Remarques

La valeur par défaut est Absolute
