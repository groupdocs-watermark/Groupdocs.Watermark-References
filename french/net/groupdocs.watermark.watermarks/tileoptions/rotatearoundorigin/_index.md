## TileOptions.RotateAroundOrigin property

Obtient ou définit une valeur indiquant si les filigranes répétés doivent être pivotés autour du centre du document.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` si les filigranes répétés doivent être tournés autour du point inférieur gauche du document ; sinon, `false`, auquel cas la rotation sera relative au bord gauche du document. La valeur par défaut est `false`.
