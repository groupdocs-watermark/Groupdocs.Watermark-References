## DiagramWatermarkOptions.IsLocked property

Obtient ou définit une valeur indiquant si la modification de la forme dans Visio est interdite.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Si la valeur est vraie, la modification de la forme sera interdite.

### Remarques

Par défaut, la valeur est false, la forme peut être modifiée dans Visio.
