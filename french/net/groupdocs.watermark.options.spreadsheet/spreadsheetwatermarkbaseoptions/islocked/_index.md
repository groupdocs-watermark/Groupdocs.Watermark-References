## SpreadsheetWatermarkBaseOptions.IsLocked property

Obtient ou définit une valeur indiquant si la modification de la forme dans Excel est interdite.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Si la valeur est vraie, la modification de la forme sera interdite. Par défaut, la valeur est fausse, la forme peut être modifiée dans Excel.
