## SpreadsheetPreviewOptions.OnlyDataArea property

Obtient ou définit le drapeau pour rendre uniquement la zone de données sans en-têtes, pieds de page, marges.

```csharp
public bool OnlyDataArea { get; set; }
```

### Property Value

Le drapeau pour rendre uniquement la zone de données sans en-têtes, pieds de page, marges.

### Remarques

Ce drapeau entraîne le rendu de toute la feuille de calcul sur une page. La valeur par défaut est `false`.
