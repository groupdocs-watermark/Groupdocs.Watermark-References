## PresentationImageFillFormat.TileAsTexture property

Obtient ou définit une valeur indiquant si l'image est répétée en mosaïque sur l'arrière-plan.

```csharp
public override bool TileAsTexture { get; set; }
```

### Property Value

Vrai si l'image est répétée sur l'arrière-plan ; sinon, faux (l'image est étirée). La valeur par défaut est false.
