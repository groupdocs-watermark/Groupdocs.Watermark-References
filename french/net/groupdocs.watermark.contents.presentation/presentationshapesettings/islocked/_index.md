## PresentationShapeSettings.IsLocked property

Obtient ou définit une valeur indiquant si la modification de la forme dans PowerPoint est interdite.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Si la valeur est `true`, la modification de la forme sera interdite. Par défaut, la valeur est `false`, la forme peut être modifiée dans PowerPoint.
