## WordProcessingHeaderFooter.IsLinkedToPrevious property

Obtient ou définit une valeur indiquant si cet en-tête/pied de page est lié à l'en-tête/pied de page correspondant dans la section précédente.

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

Vrai si cet en-tête/pied de page est lié à l'en-tête/pied de page correspondant dans la section précédente ; sinon, faux.

### Remarques

La valeur par défaut est vraie. Remarque : lorsque vous liez un en-tête ou un pied de page, son contenu est effacé.
