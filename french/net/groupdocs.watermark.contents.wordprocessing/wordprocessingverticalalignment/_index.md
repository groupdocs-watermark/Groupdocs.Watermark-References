## WordProcessingVerticalAlignment enumeration

Spécifie l'alignement vertical d'un objet flottant.

```csharp
public enum WordProcessingVerticalAlignment
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Inline | `-1` | Non documenté. Il semble s'agir d'une valeur possible pour les paragraphes et tableaux flottants. |
| None | `0` | L'objet est positionné explicitement à l'aide de sa coordonnée y. |
| Top | `1` | Spécifie que l'objet se trouve en haut de la base d'alignement vertical. |
| Center | `2` | Spécifie que l'objet est centré par rapport à la base d'alignement vertical. |
| Bottom | `3` | Spécifie que l'objet se trouve en bas de la base d'alignement vertical. |
| Inside | `4` | Spécifie que l'objet est à l'intérieur de la base d'alignement horizontal. |
| Outside | `5` | Spécifie que l'objet est à l'extérieur de la base d'alignement vertical. |
