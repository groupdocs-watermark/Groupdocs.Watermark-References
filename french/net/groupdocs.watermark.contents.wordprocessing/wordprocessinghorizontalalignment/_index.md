## WordProcessingHorizontalAlignment enumeration

Spécifie l'alignement horizontal d'un objet flottant.

```csharp
public enum WordProcessingHorizontalAlignment
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | L'objet est positionné explicitement à l'aide de sa coordonnée x. |
| Left | `1` | Spécifie que l'objet est aligné à gauche par rapport à la base d'alignement horizontal. |
| Center | `2` | Spécifie que l'objet est centré par rapport à la base d'alignement horizontal. |
| Right | `3` | Spécifie que l'objet est aligné à droite par rapport à la base d'alignement horizontal. |
| Inside | `4` | Spécifie que l'objet est à l'intérieur de la base d'alignement horizontal. |
| Outside | `5` | Spécifie que l'objet est à l'extérieur de la base d'alignement horizontal. |
