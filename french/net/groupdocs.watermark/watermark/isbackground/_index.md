## Watermark.IsBackground property

Obtient ou définit une valeur indiquant si le filigrane doit être placé en arrière-plan.

```csharp
public bool IsBackground { get; set; }
```

### Property Value

Si la valeur est vraie, le filigrane sera placé en bas. Par défaut, la valeur est fausse, le filigrane sera placé en haut.
