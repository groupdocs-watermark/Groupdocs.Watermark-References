## Watermark.ConsiderParentMargins property

Obtient ou définit une valeur indiquant si la taille et les coordonnées du filigrane sont calculées en tenant compte des marges du parent.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Si la valeur est vraie, la taille du filigrane et les coordonnées sont calculées en tenant compte des marges du parent. Par défaut, la valeur est fausse, les marges du parent sont ignorées.
