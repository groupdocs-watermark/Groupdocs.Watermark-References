L'espace de noms fournit des classes pour spécifier des options supplémentaires lors de la manipulation de documents et de filigranes.

## Classes

| Classe | Description |
| --- | --- |
| [CreatePageStream](./createpagestream) | Représente une méthode qui renvoie un flux pour écrire les données d'aperçu de page. |
| [LoadOptions](./loadoptions) | Représente les options de chargement du document lors du chargement d'un document. |
| [OoxmlLoadOptions](./ooxmlloadoptions) | Représente les options de chargement du document pour un document OOXML. |
| [PreviewOptions](./previewoptions) | Fournit des options pour définir les exigences et les délégués de flux pour la génération d'aperçu. |
| [ReleasePageStream](./releasepagestream) | Représente une méthode qui libère le flux créé par le délégué [`CreatePageStream`](../groupdocs.watermark.options/createpagestream). |
| [SaveOptions](./saveoptions) | Représente les options d'enregistrement du document lors de l'enregistrement d'un document. |
| [WatermarkOptions](./watermarkoptions) | Représente les options d'ajout de filigrane lors de l'ajout d'un filigrane à un document. |
