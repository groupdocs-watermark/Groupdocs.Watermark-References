## PresentationSearchableObjects enumeration

Spécifie les indicateurs représentant les objets de contenu PowerPoint qui doivent être inclus dans une recherche de filigrane.

```csharp
[Flags]
public enum PresentationSearchableObjects
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Spécifie aucun objet de recherche. |
| Shapes | `1` | Rechercher dans les formes. |
| ChartsBackgrounds | `2` | Rechercher dans les arrière-plans des graphiques. |
| SlidesBackgrounds | `4` | Rechercher dans les arrière-plans des diapositives. |
| Hyperlinks | `8` | Rechercher dans les hyperliens. |
| All | `F` | Rechercher dans tous les objets de contenu. |
