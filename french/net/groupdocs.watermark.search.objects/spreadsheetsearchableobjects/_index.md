## SpreadsheetSearchableObjects enumeration

Spécifie les indicateurs représentant les objets de contenu Excel qui doivent être inclus dans une recherche de filigrane.

```csharp
[Flags]
public enum SpreadsheetSearchableObjects
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Spécifie aucun objet de recherche. |
| Shapes | `1` | Rechercher dans les formes. |
| ChartsBackgrounds | `2` | Rechercher dans les arrière-plans des graphiques. |
| HeadersFooters | `4` | Rechercher dans les en-têtes et pieds de page. |
| WorksheetBackgrounds | `8` | Rechercher dans les arrière-plans des feuilles de calcul. |
| Cells | `10` | Rechercher dans les cellules. |
| Hyperlinks | `20` | Rechercher dans les hyperliens. |
| AttachedImages | `40` | Rechercher dans les images jointes. |
| All | `7F` | Rechercher dans tous les objets de contenu. |
