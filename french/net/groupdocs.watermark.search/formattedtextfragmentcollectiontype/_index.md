## FormattedTextFragmentCollectionType enumeration

Spécifie le nombre d'éléments qu'une collection de fragments de texte formaté peut contenir.

```csharp
public enum FormattedTextFragmentCollectionType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| UnlimitedFragments | `0` | Plusieurs styles sont autorisés, la collection peut contenir un nombre illimité de fragments. |
| SingleFragment | `1` | Le texte complet peut être formaté avec un seul style, la collection ne peut contenir qu'un seul fragment. |
| NoFormattedText | `2` | L'objet parent ne prend pas en charge le formatage du texte, la collection est toujours vide. |
