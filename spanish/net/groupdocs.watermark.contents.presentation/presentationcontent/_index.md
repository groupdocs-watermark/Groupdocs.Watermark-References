### Ejemplos

Carga y guarda documentos PowerPoint de cualquier tipo compatible.

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
using (Watermarker watermarker = new Watermarker(@"D:\input.ppt", loadOptions))
{
    // Utiliza el método Add para agregar una marca de agua a una diapositiva en particular o a todas las diapositivas.

    // Guarda los cambios.
    watermarker.Save(@"D:\output.ppt");
}
```
