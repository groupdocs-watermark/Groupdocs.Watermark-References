## PresentationShapeSettings.IsLocked property

Obtiene o establece un valor que indica si la edición de la forma en PowerPoint está prohibida.

```csharp
public bool IsLocked { get; set; }
```

### Property Value

Si el valor es `true`, la edición de formas estará prohibida. Por defecto, el valor es `false`, la forma puede editarse en PowerPoint.
