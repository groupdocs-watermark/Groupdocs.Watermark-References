## PdfContent.PageMarginType property

Obtiene o establece los márgenes de página pdf que se usarán al agregar la marca de agua.

```csharp
public PdfPageMarginType PageMarginType { get; set; }
```

### Property Value

Márgenes de página PDF que se usarán al agregar la marca de agua.

### Observaciones

Esta propiedad funciona solo cuando [`ConsiderParentMargins`](../../../groupdocs.watermark/watermark/considerparentmargins) está establecida en true. Si [`ConsiderParentMargins`](../../../groupdocs.watermark/watermark/considerparentmargins) es false, cuando se usa el CropBox del PDF como área de marca de agua.

El valor predeterminado es TrimBox.
