## WordProcessingWatermarkPagesOptions.PageNumbers property

Obtiene o establece los números de página para añadir la marca de agua.

```csharp
public int[] PageNumbers { get; set; }
```

### Property Value

Los números de página para agregar la marca de agua.

### Observaciones

Todos los números deben ser mayores o iguales a 1. Esta propiedad solo se usa al agregar la marca de agua a un documento. Si este valor es `null` o está vacío, la marca de agua se agrega a todas las páginas.
