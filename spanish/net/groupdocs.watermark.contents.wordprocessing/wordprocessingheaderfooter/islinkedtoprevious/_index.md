## WordProcessingHeaderFooter.IsLinkedToPrevious property

Obtiene o establece un valor que indica si este encabezado/pie de página está vinculado al encabezado/pie de página correspondiente en la sección anterior.

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

True si este encabezado/pie de página está vinculado al encabezado/pie de página correspondiente en la sección anterior; false de lo contrario.

### Observaciones

El valor predeterminado es true. Nota: cuando vinculas un encabezado o pie de página, su contenido se borra.
