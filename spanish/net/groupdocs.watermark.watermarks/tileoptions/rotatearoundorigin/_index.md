## TileOptions.RotateAroundOrigin property

Obtiene o establece un valor que indica si las marcas de agua repetidas deben rotarse alrededor del centro del documento.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` si las marcas de agua repetidas deben rotarse alrededor del punto inferior izquierdo del documento; de lo contrario, `false`, en cuyo caso la rotación será relativa al borde izquierdo del documento. El valor predeterminado es `false`.
