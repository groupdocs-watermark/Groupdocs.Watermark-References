## FileType.DOCX field

DOCX es un formato bien conocido para documentos de Microsoft Word. Introducido a partir de 2007 con el lanzamiento de Microsoft Office 2007, la estructura de este nuevo formato de documento cambió de binario simple a una combinación de archivos XML y binarios.
