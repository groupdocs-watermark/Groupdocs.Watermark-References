## Remove(PossibleWatermark) {#remove}

Elimina la marca de agua del documento.

```csharp
public void Remove(PossibleWatermark possibleWatermark)
```

| Parámetro | Type | Descripción |
| --- | --- | --- |
| possibleWatermark | PossibleWatermark | La marca de agua a eliminar. |

### Observaciones

Obtén más información sobre la eliminación de marcas de agua: [Eliminación de marcas de agua encontradas](https://docs.groupdocs.com/display/watermarknet/Removing+found+watermarks).

### Ejemplos

Buscar y eliminar la primera marca de agua posible que contenga texto o imagen específicos de un documento de cualquier tipo compatible.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria(@"D:\logo.png");
    Regex regex = new Regex(@"^Company\sName$", RegexOptions.IgnoreCase);
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria(regex);
    PossibleWatermarkCollection watermarks = watermarker.Search(textSearchCriteria.Or(imageSearchCriteria));
    if (watermarks.Count > 0)
    {
        watermarker.Remove(watermarks[0]);
    }

    watermarker.Save(@"D:\output.doc");
}
```

| Parámetro | Type | Descripción |

### Ejemplos

Encuentre y elimine todas las marcas de agua posibles que contengan texto o imagen particulares de un documento de cualquier tipo compatible.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria(@"D:\logo.png");
    Regex regex = new Regex(@"^Company\sName$", RegexOptions.IgnoreCase);
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria(regex);
    PossibleWatermarkCollection watermarks = watermarker.Search(textSearchCriteria.Or(imageSearchCriteria));
    watermarker.Remove(watermarks);

}
```
