## Search(SearchCriteria) {#search_1}

Busca marcas de agua posibles según los criterios de búsqueda especificados.

```csharp
public PossibleWatermarkCollection Search(SearchCriteria searchCriteria)
```

| Parámetro | Type | Descripción |
| --- | --- | --- |
| searchCriteria | SearchCriteria | Los criterios de búsqueda a usar. |

### Valor de retorno

La colección de marcas de agua posibles.

### Observaciones

La búsqueda se realiza en los objetos especificados en [`SearchableObjects`](../searchableobjects).

Obtenga más información sobre la búsqueda de marcas de agua [Búsqueda de marcas de agua](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks).

### Ejemplos

Encuentre y elimine todas las marcas de agua posibles que contengan texto o imagen particulares de un documento de cualquier tipo compatible.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\input.doc"))
{
    ImageSearchCriteria imageSearchCriteria = new ImageDctHashSearchCriteria(@"D:\logo.png");
    Regex regex = new Regex(@"^Company\sName$", RegexOptions.IgnoreCase);
    TextSearchCriteria textSearchCriteria = new TextSearchCriteria(regex);
    PossibleWatermarkCollection watermarks = watermarker.Search(textSearchCriteria.Or(imageSearchCriteria));
    watermarks.Clear();
    watermarker.Save(@"D:\output.doc");
}
```
