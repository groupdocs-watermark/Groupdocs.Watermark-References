## Watermark.ConsiderParentMargins property

Obtiene o establece un valor que indica si el tamaño y las coordenadas de la marca de agua se calculan considerando los márgenes del padre.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Si el valor es verdadero, el tamaño y las coordenadas de la marca de agua se calculan considerando los márgenes del padre. Por defecto, el valor es falso, los márgenes del padre se ignoran.
