## PdfPreviewOptions class

Proporciona opciones para establecer requisitos y delegados de flujo para la generación de vista previa de un documento PDF.

El tipo PdfPreviewOptions expone los siguientes miembros:

### Constructores
| Constructor | Descripción |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options.pdf/pdfpreviewoptions/__init__/#create_page_stream) | Inicializa una nueva instancia de la clase [`PdfPreviewOptions`](/watermark/python-net/groupdocs.watermark.options.pdf/pdfpreviewoptions/) que provoca que el flujo de salida se cierre. |
| [__init__](/watermark/python-net/groupdocs.watermark.options.pdf/pdfpreviewoptions/__init__/#create_page_stream-release_page_stream) | Inicializa una nueva instancia de PdfPreviewOptions que devuelve el flujo de salida al cliente para su uso posterior. |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [resolution](/watermark/python-net/groupdocs.watermark.options.pdf/pdfpreviewoptions/resolution/) | La resolución para las imágenes generadas, en puntos por pulgada. |

| [page_numbers](/watermark/python-net/groupdocs.watermark.options/previewoptions/page_numbers/) | El arreglo de números de página para generar vistas previas. (heredado de [`PreviewOptions`](/watermark/python-net/groupdocs.watermark.options/previewoptions/)) |

| [release_page_stream](/watermark/python-net/groupdocs.watermark.options/previewoptions/release_page_stream/) | El delegado de finalización de la vista previa de la página. (heredado de [`PreviewOptions`](/watermark/python-net/groupdocs.watermark.options/previewoptions/)) |
