## PdfXObject class

Representa un XObject en un documento PDF.

Más información

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

El tipo PdfXObject expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | La altura de este PdfXObject en puntos. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | La página principal de este PdfXObject. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | El ángulo de rotación de este PdfXObject en grados. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | El ancho de este [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) en puntos. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | El desplazamiento horizontal de este PdfXObject desde el borde izquierdo de la página en puntos. La coordenada x de este PdfXObject. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | El desplazamiento vertical de este PdfXObject desde el borde inferior de la página en puntos (la coordenada y). |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La colección de fragmentos de texto formateado de este [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (heredado de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | La imagen de este PdfShape. Devuelve None si el objeto no tiene imagen. (heredado de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | El texto de este [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (heredado de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
