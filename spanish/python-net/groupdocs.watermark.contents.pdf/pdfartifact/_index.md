## PdfArtifact class

Representa un artefacto en un contenido pdf.

Aprende más:
- https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithartifacts

El tipo PdfArtifact expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [artifact_subtype](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_subtype/) | El subtipo de este [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [artifact_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_type/) | El tipo de este [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/height/) | La altura de este [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) en puntos. |
| [opacity](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/opacity/) | La opacidad de este [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/page/) | La página principal de este [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/rotate_angle/) | El ángulo de rotación de este PdfArtifact en grados. |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/text/) | El texto de este [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/width/) | El ancho de este [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) en puntos. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/x/) | El desplazamiento horizontal de este PdfArtifact desde el borde izquierdo de la página en puntos. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/y/) | El desplazamiento vertical de este PdfArtifact desde el borde inferior de la página en puntos. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La colección de fragmentos de texto formateado de este [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). | [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | La imagen de este PdfShape. Devuelve None si el objeto no tiene imagen. (heredado de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
