## PdfAnnotation class

Representa una anotación en un documento pdf.

Aprende más:
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

El tipo PdfAnnotation expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | El tipo de este [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/height/) | La altura de este PdfAnnotation en puntos. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/page/) | La página padre de este [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | El ángulo de rotación de este PdfAnnotation en grados. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | El ancho de este PdfAnnotation en puntos. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | El desplazamiento horizontal de este PdfAnnotation desde el borde izquierdo de la página en puntos. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/y/) | El desplazamiento vertical de este [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) desde el borde inferior de la hoja de cálculo en puntos. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | La colección de fragmentos de texto formateado de este [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (heredado de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | La imagen de este PdfShape. Devuelve None si el objeto no tiene imagen. (heredado de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | El texto de este [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (heredado de [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
