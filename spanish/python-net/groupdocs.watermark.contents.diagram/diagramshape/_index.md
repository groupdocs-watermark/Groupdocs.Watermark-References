## DiagramShape class

Representa una forma de dibujo en un documento Visio.

El tipo DiagramShape expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/formatted_text_fragments/) | La colección de fragmentos de texto formateado de este DiagramShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/height/) | La altura de este DiagramShape en puntos. |
| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | La colección de hipervínculos adjuntos a este [`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | El identificador de este DiagramShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | La imagen de este DiagramShape. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | El nombre de este DiagramShape. |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | La página padre de este DiagramShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | El ángulo de rotación de este DiagramShape en grados. |
| [text](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/text/) | El texto de este DiagramShape. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | El ancho de este DiagramShape en puntos. |
| [x](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/x/) | El desplazamiento horizontal de este DiagramShape desde el borde izquierdo de la página en puntos, es decir, su coordenada x. |
| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | El desplazamiento vertical de este DiagramShape desde el borde inferior de la página en puntos. |
