## DiagramPage class

Representa una página de documento Visio.

El tipo DiagramPage expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Encuentra imágenes según los criterios de búsqueda especificados. La búsqueda se realiza en los objetos especificados en [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) | (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | Encuentra posibles marcas de agua según los criterios de búsqueda especificados. La búsqueda se realiza en los objetos enumerados en [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) | (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [background_page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/background_page/) | La página de fondo para este DiagramPage. |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/bottom_margin/) | El tamaño del margen inferior en puntos. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/height/) | La altura de este DiagramPage en puntos. |
| [is_background](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_background/) | La página es una página de fondo. |
| [is_visible](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/is_visible/) | El valor que indica si la página es visible en la interfaz de usuario. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/left_margin/) | El tamaño del margen izquierdo en puntos. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/name/) | El nombre de este DiagramPage. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/right_margin/) | El tamaño del margen derecho en puntos. |
| [shapes](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/shapes/) | La colección de todas las formas de la página. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/top_margin/) | El tamaño del margen superior en puntos. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagrampage/width/) | El ancho de este DiagramPage en puntos. |
