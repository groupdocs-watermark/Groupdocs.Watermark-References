## SpreadsheetImageFillFormat class

Representa la configuración del formato de relleno de imagen en un documento de Excel.

El tipo SpreadsheetImageFillFormat expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | La imagen de fondo. Devuelve None si la imagen no está establecida. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | La imagen se repite en el fondo cuando es True; de lo contrario, la imagen se estira. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | La transparencia de la imagen de fondo como un valor de 0.0 (opaco) a 1.0 (totalmente transparente). |
