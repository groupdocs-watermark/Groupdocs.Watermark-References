## SpreadsheetAttachment class

Representa un archivo adjunto a un documento de Excel.

El tipo SpreadsheetAttachment expone los siguientes miembros:

| Método | Descripción |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | Carga un contenido del archivo adjunto. (heredado de [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
