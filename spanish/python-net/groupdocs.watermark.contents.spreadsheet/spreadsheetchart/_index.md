## SpreadsheetChart class

Representa un gráfico en un documento de Excel.

El tipo SpreadsheetChart expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | El texto descriptivo (alternativo) asociado a este [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | La altura de este SpreadsheetChart en puntos. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | El hipervínculo asociado a este SpreadsheetChart. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | El identificador de este SpreadsheetChart. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | La configuración del formato de relleno de imagen de este SpreadsheetChart. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | El nombre de este SpreadsheetChart. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | El ancho de este SpreadsheetChart en puntos. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | La hoja de cálculo principal de este SpreadsheetChart. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | El desplazamiento horizontal de este SpreadsheetChart desde el borde izquierdo de la hoja de cálculo en puntos. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | El desplazamiento vertical de este SpreadsheetChart desde el borde superior de la hoja de cálculo en puntos. |
