## SpreadsheetShape class

Representa una forma de dibujo en un documento de Excel.

El tipo SpreadsheetShape expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/alternative_text/) | El texto descriptivo (alternativo) asociado a este [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [auto_shape_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/auto_shape_type/) | El tipo de forma automática. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/formatted_text_fragments/) | La colección de fragmentos de texto formateado de este SpreadsheetShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/height/) | La altura de este SpreadsheetShape en puntos. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/hyperlink/) | El hipervínculo asociado a este [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/id/) | El identificador de este SpreadsheetShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image/) | La imagen de este SpreadsheetShape. Devuelve None si la forma no tiene imagen. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image_fill_format/) | La configuración del formato de relleno de imagen de este SpreadsheetShape. |
| [is_word_art](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/is_word_art/) | La forma es un objeto WordArt. |
| [mso_drawing_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/mso_drawing_type/) | El tipo de dibujo mso. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/name/) | El nombre de este SpreadsheetShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/rotate_angle/) | El ángulo de rotación de este [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) en grados. |
| [text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/text/) | El texto de este [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/width/) | El ancho de este SpreadsheetShape en puntos. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/worksheet/) | La hoja de cálculo padre de este SpreadsheetShape. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/x/) | El desplazamiento horizontal de este SpreadsheetShape desde el borde izquierdo de la hoja de cálculo en puntos. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/y/) | La coordenada y de este SpreadsheetShape desde el borde superior de la hoja de cálculo en puntos. |
