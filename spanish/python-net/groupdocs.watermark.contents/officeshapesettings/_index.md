## OfficeShapeSettings class

Representa la configuración que se puede aplicar a una marca de agua de forma para un contenido de oficina.

El tipo OfficeShapeSettings expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/alternative_text/) | El texto descriptivo (alternativo) que se asociará a una forma. |
| [name](/watermark/python-net/groupdocs.watermark.contents/officeshapesettings/name/) | El nombre de la forma. |
