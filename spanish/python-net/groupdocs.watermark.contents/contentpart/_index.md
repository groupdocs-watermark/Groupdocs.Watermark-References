## ContentPart class

Representa cualquier parte lógica de un contenido (página, marco, encabezado o todo el contenido) donde se puede colocar una marca de agua.

El tipo ContentPart expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/#search_criteria) | Encuentra imágenes según los criterios de búsqueda especificados. La búsqueda se lleva a cabo en los objetos especificados en [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Encuentra todas las imágenes en el contenido, buscando dentro de los objetos especificados en [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) |  |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/#search_criteria) | Encuentra posibles marcas de agua según los criterios de búsqueda especificados. La búsqueda se realiza en los objetos enumerados en [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | Encuentra todas las posibles marcas de agua en el contenido. |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) |  |
