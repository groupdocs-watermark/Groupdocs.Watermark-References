## OfficeTextEffects class

Representa los efectos que se pueden aplicar a una marca de agua de texto para un contenido de oficina.

El tipo OfficeTextEffects expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [line_format](/watermark/python-net/groupdocs.watermark.contents/officetexteffects/line_format/) | La configuración del formato de línea, representada por una instancia de [`OfficeLineFormat`](/watermark/python-net/groupdocs.watermark.contents/officelineformat/). |
