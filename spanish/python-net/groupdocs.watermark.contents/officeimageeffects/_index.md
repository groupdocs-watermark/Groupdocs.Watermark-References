## OfficeImageEffects class

Representa los efectos que se pueden aplicar a una marca de agua de imagen para un contenido de oficina.

El tipo OfficeImageEffects expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | La configuración del formato de línea para el borde de la imagen. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | El brillo de la imagen. Debe ser un número de punto flotante entre 0.0 (más tenue) y 1.0 (más brillante). El valor predeterminado es 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | El valor de color de la imagen que se tratará como transparente. El valor predeterminado es un color totalmente transparente. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | El contraste para la imagen especificada. Debe ser un número flotante entre 0.0 (menor contraste) y 1.0 (mayor contraste). El valor predeterminado es 0.5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | La propiedad indica si una imagen se mostrará en modo escala de grises. |
