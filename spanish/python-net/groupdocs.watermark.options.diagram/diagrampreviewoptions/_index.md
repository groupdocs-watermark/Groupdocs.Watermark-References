## DiagramPreviewOptions class

Proporciona opciones para establecer requisitos y delegados de flujo para la generación de vista previa de un documento Diagram.

El tipo DiagramPreviewOptions expone los siguientes miembros:

### Constructores
| Constructor | Descripción |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/__init__/#create_page_stream) | Inicializa una nueva instancia de la clase [`DiagramPreviewOptions`](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/) que provoca que el flujo de salida se cierre. |
| [__init__](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/__init__/#create_page_stream-release_page_stream) | Inicializa una nueva instancia de [`DiagramPreviewOptions`](/watermark/python-net/groupdocs.watermark.options.diagram/diagrampreviewoptions/) que hace que el flujo de salida se devuelva al cliente para su uso posterior. |
