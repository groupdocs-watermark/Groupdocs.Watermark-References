## PresentationSlide class

Representa una diapositiva de un documento de PowerPoint.

El tipo PresentationSlide expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Encuentra imágenes según los criterios de búsqueda especificados. La búsqueda se realiza en los objetos especificados en [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) | (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | Encuentra posibles marcas de agua según los criterios de búsqueda especificados. La búsqueda se realiza en los objetos enumerados en [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/). (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |
| [search_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/search_search_criteria/) | (heredado de [`ContentPart`](/watermark/python-net/groupdocs.watermark.contents/contentpart/)) |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [layout_slide](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslide/layout_slide/) | La diapositiva de diseño para este PresentationSlide. |
| [master_slide](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslide/master_slide/) | La diapositiva maestra para este PresentationSlide. |
| [notes_slide](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslide/notes_slide/) | La diapositiva de notas para este PresentationSlide. |
| [charts](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/charts/) | La colección de todos los gráficos en la presentación. (heredado de [`PresentationBaseSlide`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/)) |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/image_fill_format/) | La configuración del formato de relleno de imagen de la presentación. | [shapes](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/shapes/) | La colección de todas las formas de la presentación. (heredado de [`PresentationBaseSlide`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationbaseslide/)) |
