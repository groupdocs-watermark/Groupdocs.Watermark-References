## PresentationImageFillFormat class

Representa la configuración de formato de relleno de imagen en un documento PowerPoint.

El tipo PresentationImageFillFormat expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | La imagen de fondo. Devuelve None si la imagen no está establecida. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | La imagen se repite en mosaico en el fondo cuando se establece en True; de lo contrario se estira. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | La transparencia de la imagen de fondo como un valor de 0.0 (opaco) a 1.0 (totalmente transparente). |
