## Margins class

Representa la configuración de márgenes para cada borde de un objeto.

El tipo Margins expone los siguientes miembros:

### Constructores
| Constructor | Descripción |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | Inicializa una nueva instancia de la clase [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/). |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | Inicializa una nueva instancia de la clase [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) con el tipo, la ubicación y el tamaño especificados. |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | El margen inferior. Representa el desplazamiento horizontal desde el borde inferior del elemento padre. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | El margen izquierdo, expresado como el desplazamiento horizontal desde el borde izquierdo del elemento padre. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | El tipo de margen, que determina cómo se interpretan los márgenes; establecer un nuevo valor restablece automáticamente todos los márgenes a sus valores predeterminados (cero). |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | El margen derecho como desplazamiento horizontal desde el borde derecho del elemento padre. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | El margen superior. |
