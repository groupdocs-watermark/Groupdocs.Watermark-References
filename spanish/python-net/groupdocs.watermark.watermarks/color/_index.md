### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [a](/watermark/python-net/groupdocs.watermark.watermarks/color/a/) | El componente alfa del color. Los valores válidos son de 0 a 255. |
| [b](/watermark/python-net/groupdocs.watermark.watermarks/color/b/) | El componente azul del color, con valores válidos de 0 a 255. |
| [g](/watermark/python-net/groupdocs.watermark.watermarks/color/g/) | El valor del componente verde del color. |
| [is_empty](/watermark/python-net/groupdocs.watermark.watermarks/color/is_empty/) | La propiedad indica si esta estructura [`Color`](/watermark/python-net/groupdocs.watermark.watermarks/color/) no está inicializada. |
| [r](/watermark/python-net/groupdocs.watermark.watermarks/color/r/) | El componente rojo del color. Los valores válidos son de 0 a 255. |

### Ejemplo

```python
from groupdocs.watermark.watermarks import Color, TextWatermark, Font
from groupdocs.watermark import Watermarker

with Watermarker("document.pdf") as watermarker:
    watermark = TextWatermark("CONFIDENTIAL", Font("Arial", 48))
    watermark.foreground_color = Color.red
    watermarker.add(watermark)
    watermarker.save("watermarked.pdf")
```
