## WordProcessingPageSetup class

Representa las propiedades de impresión de página para una sección de un documento Word.

El tipo WordProcessingPageSetup expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [bottom_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/bottom_margin/) | El tamaño del margen inferior en puntos. |
| [different_first_page_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/different_first_page_header_footer/) | La bandera que indica si se usa un encabezado/pie de página diferente en la primera página. |
| [height](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/height/) | La altura de una página de impresión en puntos. |
| [left_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/left_margin/) | El tamaño del margen izquierdo en puntos. |
| [odd_and_even_pages_header_footer](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/odd_and_even_pages_header_footer/) | La propiedad indica si se utilizan encabezados/pies de página diferentes para páginas impares y pares. |
| [right_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/right_margin/) | El tamaño del margen derecho en puntos. |
| [top_margin](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/top_margin/) | El tamaño del margen superior en puntos. |
| [width](/watermark/python-net/groupdocs.watermark.contents.word_processing/wordprocessingpagesetup/width/) | El ancho de una página de impresión en puntos. |
