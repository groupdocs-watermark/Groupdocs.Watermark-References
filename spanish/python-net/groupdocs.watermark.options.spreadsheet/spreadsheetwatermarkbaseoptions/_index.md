## SpreadsheetWatermarkBaseOptions class

Representa la clase base para las opciones de agregar marcas de agua a un documento Spreadsheet.

El tipo SpreadsheetWatermarkBaseOptions expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetwatermarkbaseoptions/alternative_text/) | El texto descriptivo (alternativo) que se asociará a una forma. |
| [is_locked](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetwatermarkbaseoptions/is_locked/) | La propiedad indica si la edición de la forma en Excel está prohibida. |
| [name](/watermark/python-net/groupdocs.watermark.options.spreadsheet/spreadsheetwatermarkbaseoptions/name/) | El nombre de la forma. |

### Campos
| Campo | Descripción |
| :- | :- |
