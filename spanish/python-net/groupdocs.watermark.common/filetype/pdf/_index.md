## PDF field

Portable Document Format (PDF) es un tipo de documento creado por Adobe a principios de los años 90. El propósito de este formato de archivo era introducir un estándar para la representación de documentos y otro material de referencia en un formato independiente del software de aplicación, hardware y del sistema operativo.
