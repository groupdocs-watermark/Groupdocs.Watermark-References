## FileType class

Representa el tipo de archivo.

Proporciona métodos para obtener una lista de todos los tipos de archivo compatibles con [`GroupDocs.Watermark`](/watermark/python-net/groupdocs.watermark/watermark/).

El tipo FileType expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#other) | Determina si el [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) actual es el mismo que el objeto [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) especificado. |
| [equals](/watermark/python-net/groupdocs.watermark.common/filetype/equals/#obj) | Determina si el FileType actual es el mismo que el objeto especificado. |
| [equals_file_type](/watermark/python-net/groupdocs.watermark.common/filetype/equals_file_type/) |  |
| [equals_object](/watermark/python-net/groupdocs.watermark.common/filetype/equals_object/) |  |
| [from_extension](/watermark/python-net/groupdocs.watermark.common/filetype/from_extension/#extension) | Asocia la extensión del archivo con el tipo de archivo. |
| [get_hash_code](/watermark/python-net/groupdocs.watermark.common/filetype/get_hash_code/) | Devuelve un código hash para el objeto [`FileType`](/watermark/python-net/groupdocs.watermark.common/filetype/) actual. |
| [get_supported_file_types](/watermark/python-net/groupdocs.watermark.common/filetype/get_supported_file_types/) | Recupera los tipos de archivo compatibles. |
| [to_string](/watermark/python-net/groupdocs.watermark.common/filetype/to_string/) | Devuelve una cadena que representa el objeto actual. |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [extension](/watermark/python-net/groupdocs.watermark.common/filetype/extension/) | El sufijo del nombre de archivo (incluyendo el punto ".") p. ej., ".doc". |
| [file_format_name](/watermark/python-net/groupdocs.watermark.common/filetype/file_format_name/) | El nombre del tipo de archivo, p. ej., "Microsoft Word Document". |
| [format_family](/watermark/python-net/groupdocs.watermark.common/filetype/format_family/) | La familia de formato. |

### Ejemplo

```python
from groupdocs.watermark.common import FileType

def list_supported_formats():
    # Enumere cada tipo de archivo que la biblioteca puede abrir
    supported_file_types = FileType.get_supported_file_types()
    for file_type in sorted(supported_file_types, key=lambda x: x.extension):
        print(file_type)

if __name__ == "__main__":
    list_supported_formats()
```
