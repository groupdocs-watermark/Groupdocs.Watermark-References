## POTM field

Los archivos con extensión POTM son archivos de plantilla de Microsoft PowerPoint con soporte para macros. Los archivos POTM se crean con PowerPoint 2007 o superior y contienen configuraciones predeterminadas que pueden usarse para crear más archivos de presentación. Obtén más información sobre este formato de archivo aquí.
