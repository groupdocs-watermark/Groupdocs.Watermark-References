## RTF field

Introducido y documentado por Microsoft, el Formato de Texto Enriquecido (RTF) representa un método de codificación de texto formateado y gráficos para su uso en aplicaciones. El formato facilita el intercambio de documentos entre plataformas con otros productos de Microsoft, cumpliendo así con el objetivo de interoperabilidad. Obtén más información sobre este formato de archivo aquí.
