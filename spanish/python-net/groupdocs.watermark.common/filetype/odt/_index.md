## ODT field

Los archivos ODT son un tipo de documentos creados con aplicaciones de procesamiento de texto basadas en el formato de archivo OpenDocument Text. Se crean con procesadores de texto como el gratuito OpenOffice Writer y pueden contener contenido como texto, imágenes, objetos y estilos. Obtén más información sobre este formato de archivo aquí.
