## watermark_id property

El identificador único de la marca de agua, utilizado para modificar la marca de agua mediante los métodos Update o Delete.

El identificador se establece automáticamente después de llamar al método Add. Si el identificador se guardó previamente, puede establecerse manualmente para manipular la marca de agua.
