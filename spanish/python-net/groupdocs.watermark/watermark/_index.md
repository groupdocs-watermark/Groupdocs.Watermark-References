## Watermark class

Representa una marca de agua que se añadirá a un documento.

Más información

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

El tipo Watermark expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | La propiedad que indica si el tamaño y las coordenadas de la marca de agua se calculan considerando los márgenes del elemento padre. Si se establece en True, los cálculos consideran los márgenes del padre; por defecto el valor es False y los márgenes del padre se ignoran. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | La altura deseada de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | La alineación horizontal de este Watermark. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | La propiedad que indica si la marca de agua debe colocarse en el fondo. Si es true, la marca de agua se coloca en la parte inferior; de lo contrario, se coloca en la parte superior (por defecto es False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | La configuración de márgenes de este Watermark. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | La opacidad de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | La configuración de páginas de este Watermark. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | El ángulo de rotación de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) en grados. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | La propiedad indica si se debe guardar información sobre las marcas de agua añadidas en los metadatos del documento. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | El factor de escala de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/), que define cómo el tamaño de la marca de agua depende del tamaño del elemento padre. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | El tipo de tamaño de la marca de agua. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | Las opciones para definir una marca de agua repetida. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | La alineación vertical de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | El ancho deseado de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | La coordenada x de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | La coordenada y de este [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
