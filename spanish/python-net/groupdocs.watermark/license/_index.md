## License class

Administra la licencia de GroupDocs.Watermark.

Las compilaciones con licencia desbloquean el conjunto completo de funciones del contenedor en
tiempo de ejecución. Las compilaciones sin licencia se ejecutan en modo de evaluación con la misma API
pero con limitaciones en el tamaño de salida y el contenido marcado.

El tipo License expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [set_license](/watermark/python-net/groupdocs.watermark/license/set_license/#license_source) | Aplica una licencia al proceso actual. |
