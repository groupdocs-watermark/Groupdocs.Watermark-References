Especifica en qué páginas se debe agregar una marca de agua.

## Campos

| Campo | Descripción |
| --- | --- |
|  | [ForegroundPages](#ForegroundPages) | Una marca de agua debe añadirse solo a las páginas de primer plano. |
|
|  | [BackgroundPages](#BackgroundPages) | Una marca de agua debe añadirse solo a las páginas de fondo. |
|
|  | [AllPages](#AllPages) | Una marca de agua debe añadirse a todas las páginas. |
|
|  | [SeparateBackgrounds](#SeparateBackgrounds) | Se deben crear páginas de fondo separadas con una marca de agua y asignarlas a todas las páginas sin fondo. |
|
|  | [Default](#Default) | Lo mismo que `#ForegroundPages.ForegroundPages`. |
|
