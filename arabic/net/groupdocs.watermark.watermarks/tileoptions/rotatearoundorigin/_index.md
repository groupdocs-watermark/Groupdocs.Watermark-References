## TileOptions.RotateAroundOrigin property

يحصل أو يضبط قيمة تشير إلى ما إذا كان يجب تدوير العلامات المائية المتكررة حول مركز المستند.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` إذا كان يجب تدوير العلامات المائية المتكررة حول النقطة السفلية اليسرى للمستند؛ وإلا، `false`، وفي هذه الحالة سيكون الدوران نسبياً إلى الحافة اليسرى للمستند. القيمة الافتراضية هي `false`.
