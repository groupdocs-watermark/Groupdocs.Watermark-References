توفر مساحة الاسم فئات لتحديد خيارات إضافية عند العمل مع المستندات والعلامات المائية.

## الفئات

| فئة | الوصف |
| --- | --- |
| [CreatePageStream](./createpagestream) | يمثل طريقة تُعيد تدفقًا لكتابة بيانات معاينة الصفحة. |
| [LoadOptions](./loadoptions) | يمثل خيارات تحميل المستند عند تحميل مستند. |
| [OoxmlLoadOptions](./ooxmlloadoptions) | يمثل خيارات تحميل المستند لمستند OOXML. |
| [PreviewOptions](./previewoptions) | يوفر خيارات لتحديد المتطلبات ومندوبات الدفق لإنشاء المعاينة. |
| [ReleasePageStream](./releasepagestream) | يمثل طريقة تُطلق الدفق الذي تم إنشاؤه بواسطة المندوب [`CreatePageStream`](../groupdocs.watermark.options/createpagestream). |
| [SaveOptions](./saveoptions) | يمثل خيارات حفظ المستند عند حفظه. |
| [WatermarkOptions](./watermarkoptions) | يمثل خيارات إضافة العلامة المائية عند إضافة علامة مائية إلى مستند. |
