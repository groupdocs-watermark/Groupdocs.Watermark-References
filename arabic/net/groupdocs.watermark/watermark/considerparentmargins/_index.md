## Watermark.ConsiderParentMargins property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان حجم العلامة المائية والإحداثيات تُحسب مع مراعاة هوامش العنصر الأصلي.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

إذا كانت القيمة true، يتم حساب حجم العلامة المائية والإحداثيات مع مراعاة هوامش العنصر الأصلي. بشكل افتراضي، تكون القيمة false، ويتم تجاهل هوامش العنصر الأصلي.
