## PdfContent.PageMarginType property

워터마크 추가 중에 사용할 pdf 페이지 여백을 가져오거나 설정합니다.

```csharp
public PdfPageMarginType PageMarginType { get; set; }
```

### Property Value

워터마크 추가 중에 사용할 PDF 페이지 여백.

### 비고

이 속성은 [`ConsiderParentMargins`](../../../groupdocs.watermark/watermark/considerparentmargins)가 true로 설정된 경우에만 작동합니다. [`ConsiderParentMargins`](../../../groupdocs.watermark/watermark/considerparentmargins)가 false인 경우, PDF CropBox가 워터마크 영역으로 사용됩니다.

기본값은 TrimBox입니다.
