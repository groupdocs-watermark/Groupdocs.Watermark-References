## LoadOptions.Password property

### Property Value

암호화된 문서를 열기 위한 비밀번호입니다.

### 비고

비밀번호는 null이거나 빈 문자열일 수 있습니다. 기본값은 null입니다. 내용이 암호화되지 않은 경우 null 또는 빈 문자열로 설정하십시오.

### 예제
