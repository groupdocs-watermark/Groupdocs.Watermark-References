## TileOptions.RotateAroundOrigin property

반복되는 워터마크를 문서 중앙을 기준으로 회전시킬지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true`이면 반복 워터마크가 문서의 왼쪽 하단 점을 기준으로 회전해야 합니다; 그렇지 않으면 `false`이며, 이 경우 회전은 문서의 왼쪽 가장자리를 기준으로 합니다. 기본값은 `false`입니다.
