## Watermarker.SearchableObjects property

워터마크 검색에 포함될 콘텐츠 객체를 가져오거나 설정합니다.

```csharp
public SearchableObjects SearchableObjects { get; set; }
```

### Property Value

워터마크 검색에 포함될 객체입니다.

### 비고

이 속성은 이미지 검색에 사용되는 콘텐츠 객체도 지정합니다. 자세한 내용은 [`Search`](../search) 및 [`GetImages`](../getimages) 메서드를 참조하세요.

워터마크 검색에 대해 자세히 알아보세요: [Searching watermarks](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks).

### 예제

PDF 문서에서 모든 XObjects 및 Artifacts를 제거합니다.

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\test.pdf"))
{
    // XObjects 및 Artifacts만 검색하도록 지정합니다.
    watermarker.SearchableObjects.PdfSearchableObjects
        = PdfSearchableObjects.XObjects | PdfSearchableObjects.Artifacts; 

    PossibleWatermarkCollection watermarks = watermarker.Search();

    // 찾은 모든 객체를 제거합니다.
    watermarks.Clear();

    // 변경 사항을 저장합니다.
    watermarker.Save();
}
```
