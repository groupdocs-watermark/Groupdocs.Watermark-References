## Margins class

객체의 각 가장자리에 대한 여백 설정을 나타냅니다.

Margins 유형은 다음 멤버를 노출합니다:

### 생성자
| 생성자 | 설명 |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) 클래스의 새 인스턴스를 초기화합니다. |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) 클래스의 새 인스턴스를 지정된 유형, 위치 및 크기로 초기화합니다. |

### 속성
| 속성 | 설명 |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | 하단 여백. 부모 하단 경계로부터의 수평 오프셋을 나타냅니다. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | 왼쪽 여백, 부모 왼쪽 경계로부터의 수평 오프셋으로 표현됩니다. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | 여백 유형은 여백이 해석되는 방식을 결정합니다; 새 값을 설정하면 모든 여백이 자동으로 기본값(0)으로 재설정됩니다. |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | 오른쪽 여백, 부모 오른쪽 경계로부터의 수평 오프셋입니다. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | 상단 여백. |
