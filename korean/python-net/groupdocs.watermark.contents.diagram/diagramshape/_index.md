## DiagramShape class

| 속성 | 설명 |

| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | 이 DiagramShape의 식별자입니다. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | 이 DiagramShape의 이미지입니다. |

| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | 이 DiagramShape의 상위 페이지입니다. |

| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | 이 DiagramShape의 너비(포인트 단위)입니다. |

| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | 페이지 하단 경계선으로부터 이 DiagramShape의 수직 오프셋(포인트 단위)입니다. |
