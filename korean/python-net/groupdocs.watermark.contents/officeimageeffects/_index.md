## OfficeImageEffects class

오피스 콘텐츠의 이미지 워터마크에 적용할 수 있는 효과를 나타냅니다.

OfficeImageEffects 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | 이미지 테두리의 선 형식 설정. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | 그림의 밝기. 0.0(가장 어두움)에서 1.0(가장 밝음) 사이의 부동 소수점 값이어야 합니다. 기본값은 0.5입니다. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | 투명하게 처리될 이미지의 색상 값입니다. 기본값은 완전히 투명한 색상입니다. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | 지정된 사진의 대비입니다. 0.0(최소 대비)과 1.0(최대 대비) 사이의 부동 소수점이어야 합니다. 기본값은 0.5입니다. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | 이 속성은 사진이 그레이스케일 모드로 표시될지 여부를 나타냅니다. |
