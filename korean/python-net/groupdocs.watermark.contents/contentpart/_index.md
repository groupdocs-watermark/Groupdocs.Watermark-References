## ContentPart class

워터마크를 배치할 수 있는 콘텐츠(페이지, 프레임, 헤더 또는 전체 콘텐츠)의 논리적 부분을 나타냅니다.

ContentPart 형식은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/#search_criteria) | 지정된 검색 기준에 따라 이미지를 찾습니다. 검색은 [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/)에 지정된 객체에서 수행됩니다. |
| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | 콘텐츠 내 모든 이미지를 찾으며, [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/)에 지정된 객체를 검색합니다. |
| [find_images_image_search_criteria](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images_image_search_criteria/) |  |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/#search_criteria) | 지정된 검색 기준에 따라 가능한 워터마크를 찾습니다. 검색은 [`Watermarker.SearchableObjects`](/watermark/python-net/groupdocs.watermark.search.objects/searchableobjects/)에 나열된 객체에서 수행됩니다. |
| [search](/watermark/python-net/groupdocs.watermark.contents/contentpart/search/) | 콘텐츠 내 모든 가능한 워터마크를 찾습니다. |
