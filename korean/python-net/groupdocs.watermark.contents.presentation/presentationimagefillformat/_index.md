## PresentationImageFillFormat class

PowerPoint 문서의 이미지 채우기 형식 설정을 나타냅니다.

PresentationImageFillFormat 형식은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | 배경 이미지입니다. 이미지가 설정되지 않은 경우 None을 반환합니다. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | 이미지는 True로 설정하면 배경에 타일링되고, 그렇지 않으면 늘어납니다. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | 배경 이미지의 투명도이며, 0.0(불투명)에서 1.0(완전 투명)까지의 값입니다. |
