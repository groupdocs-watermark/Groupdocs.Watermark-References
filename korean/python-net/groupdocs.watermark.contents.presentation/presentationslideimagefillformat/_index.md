## PresentationSlideImageFillFormat class

PowerPoint 문서의 슬라이드에 대한 이미지 채우기 형식 설정을 나타냅니다.

PresentationSlideImageFillFormat 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslideimagefillformat/background_image/) | 배경 이미지; 이미지가 설정되지 않으면 None를 반환합니다. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | 이미지가 True로 설정되면 배경 전체에 타일링되고, 그렇지 않으면 늘어납니다. ([`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)에서 상속됨) |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | 배경 이미지의 투명도는 0.0(불투명)부터 1.0(완전 투명)까지의 값입니다. ([`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)에서 상속됨) |
