## Watermark class

문서에 추가될 워터마크를 나타냅니다.

자세히 알아보기

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Watermark 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | 워터마크 크기와 좌표를 부모 여백을 고려하여 계산할지 여부를 나타내는 속성입니다. True로 설정하면 계산에 부모 여백이 고려됩니다; 기본값은 False이며 부모 여백은 무시됩니다. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 원하는 높이입니다. |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | 이 Watermark의 수평 정렬입니다. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | 워터마크를 배경에 배치할지 여부를 나타내는 속성입니다. true이면 워터마크가 하단에 배치되고, 그렇지 않으면 상단에 배치됩니다(기본값은 False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | 이 Watermark의 여백 설정입니다. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 불투명도입니다. |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | 이 Watermark의 페이지 설정입니다. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 회전 각도(도)입니다. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | 추가된 워터마크에 대한 정보를 문서 메타데이터에 저장할지 여부를 나타내는 속성입니다. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 배율 인자로, 워터마크 크기가 부모 크기에 어떻게 의존하는지를 정의합니다. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | 워터마크의 크기 지정 유형입니다. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | 반복 워터마크를 정의하기 위한 옵션입니다. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 수직 정렬입니다. |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 원하는 너비입니다. |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 x좌표입니다. |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | 이 [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/)의 y좌표입니다. |
