## PdfAnnotation class

PDF 문서의 주석을 나타냅니다.

자세히 알아보기:
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

PdfAnnotation 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | 이 [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/)의 유형. |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/height/) | 이 PdfAnnotation의 높이(포인트 단위). |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/page/) | 이 [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/)의 상위 페이지. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | 이 PdfAnnotation의 회전 각도(도 단위). |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | 이 PdfAnnotation의 너비(포인트 단위). |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | 이 PdfAnnotation이 페이지 왼쪽 경계에서 떨어진 수평 오프셋(포인트 단위). |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/y/) | 이 [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/)이 워크시트 하단 경계에서 떨어진 수직 오프셋(포인트 단위). |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | 이 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)의 서식이 지정된 텍스트 조각 컬렉션. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | 이 PdfShape의 이미지. 객체에 이미지가 없으면 None을 반환합니다. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | 이 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)의 텍스트. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
