## PdfArtifact class

PDF 콘텐츠의 아티팩트를 나타냅니다.

자세히 알아보기:
- https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithartifacts

PdfArtifact 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [artifact_subtype](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_subtype/) | 이 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/)의 하위 유형입니다. |
| [artifact_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_type/) | 이 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/)의 유형입니다. |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/height/) | 이 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/)의 높이(포인트 단위)입니다. |
| [opacity](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/opacity/) | 이 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/)의 불투명도입니다. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/page/) | 이 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/)의 상위 페이지입니다. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/rotate_angle/) | 이 PdfArtifact의 회전 각도(도)입니다. |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/text/) | 이 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/)의 텍스트입니다. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/width/) | 이 [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/)의 너비(포인트 단위)입니다. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/x/) | 페이지 왼쪽 경계에서 이 PdfArtifact의 수평 오프셋(포인트 단위)입니다. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/y/) | 페이지 하단 경계에서 이 PdfArtifact의 수직 오프셋(포인트 단위)입니다. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | 이 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)의 서식이 지정된 텍스트 조각 컬렉션. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | 이 PdfShape의 이미지. 객체에 이미지가 없으면 None을 반환합니다. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
