## PdfShape class

XObjects, Artifacts 및 Annotations에 대한 기본 클래스를 제공합니다.

PdfShape 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | 이 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)의 서식이 지정된 텍스트 조각 컬렉션입니다. |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/height/) | 객체의 높이입니다. |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | 이 PdfShape의 이미지입니다. 객체에 이미지가 없으면 None을 반환합니다. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/rotate_angle/) | 객체의 회전 각도(도)입니다. |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | 이 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)의 텍스트입니다. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/width/) | 객체의 너비입니다. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/x/) | 객체의 x좌표입니다. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/y/) | 객체의 y좌표입니다. |
