## PdfXObject class

PDF 문서에서 XObject를 나타냅니다.

자세히 알아보기

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

PdfXObject 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | 이 PdfXObject의 높이(포인트)입니다. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | 이 PdfXObject의 상위 페이지입니다. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | 이 PdfXObject의 회전 각도(도)입니다. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | 이 [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/)의 너비(포인트)입니다. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | 이 PdfXObject의 페이지 왼쪽 경계로부터의 수평 오프셋(포인트). 이 PdfXObject의 x좌표입니다. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | 이 PdfXObject의 페이지 하단 경계로부터의 수직 오프셋(포인트) (y좌표)입니다. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | 이 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)의 서식이 지정된 텍스트 조각 컬렉션. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | 이 PdfShape의 이미지. 객체에 이미지가 없으면 None을 반환합니다. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | 이 [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)의 텍스트. ([`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)에서 상속됨) |
