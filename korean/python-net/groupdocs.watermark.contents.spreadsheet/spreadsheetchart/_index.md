## SpreadsheetChart class

Excel 문서의 차트를 나타냅니다.

SpreadsheetChart 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | 이 [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/)와 연결된 설명(대체) 텍스트입니다. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | 이 SpreadsheetChart의 높이(포인트)입니다. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | 이 SpreadsheetChart와 연결된 하이퍼링크입니다. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | 이 SpreadsheetChart의 식별자입니다. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | 이 SpreadsheetChart의 이미지 채우기 형식 설정입니다. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | 이 SpreadsheetChart의 이름입니다. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | 이 SpreadsheetChart의 너비(포인트)입니다. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | 이 SpreadsheetChart의 상위 워크시트입니다. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | 워크시트 왼쪽 경계에서 이 SpreadsheetChart까지의 수평 오프셋(포인트)입니다. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | 워크시트 상단 경계에서 이 SpreadsheetChart까지의 수직 오프셋(포인트)입니다. |
