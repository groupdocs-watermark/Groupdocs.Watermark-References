## SpreadsheetImageFillFormat class

Excel 문서의 이미지 채우기 형식 설정을 나타냅니다.

SpreadsheetImageFillFormat 유형은 다음 멤버를 노출합니다:

### 속성
| 속성 | 설명 |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | 배경 이미지입니다. 이미지가 설정되지 않은 경우 None을 반환합니다. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | True인 경우 이미지가 배경에 타일 형태로 배치되고, 그렇지 않으면 이미지가 늘어납니다. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | 배경 이미지의 투명도이며, 0.0(불투명)에서 1.0(완전 투명)까지의 값입니다. |
