## SpreadsheetAttachment class

SpreadsheetAttachment 유형은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | 첨부된 파일에서 콘텐츠를 로드합니다. ([`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)에서 상속됨) |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | ([`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)에서 상속됨) |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | 첨부된 파일에 저장된 문서에 대한 정보를 검색합니다. ([`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)에서 상속됨) |
