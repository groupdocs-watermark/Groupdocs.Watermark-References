## PPT field

PPT 확장자를 가진 파일은 슬라이드쇼로 표시되는 슬라이드 모음으로 구성된 PowerPoint 파일을 나타냅니다. 이는 Microsoft PowerPoint 97-2003에서 사용되는 바이너리 파일 형식을 지정합니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하십시오.
