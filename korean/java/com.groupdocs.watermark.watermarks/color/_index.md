| 매개변수 | 유형 | 설명 |

|
|  | 빨강 | int | 새 Color의 빨간색 구성 요소 값입니다. 유효한 값은 0부터 255까지입니다. |
|
|  | 초록 | int | 새 Color의 초록색 구성 요소 값입니다. 유효한 값은 0부터 255까지입니다. |
|
|  | 파랑 | int | 새 Color의 파란색 구성 요소 값입니다. 유효한 값은 0부터 255까지입니다. |
