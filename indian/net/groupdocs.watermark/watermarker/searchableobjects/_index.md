## Watermarker.SearchableObjects property

वॉटरमार्क खोज में शामिल किए जाने वाले कंटेंट ऑब्जेक्ट्स को प्राप्त करता या सेट करता है।

```csharp
public SearchableObjects SearchableObjects { get; set; }
```

### Property Value

वॉटरमार्क खोज में शामिल किए जाने वाले ऑब्जेक्ट्स।

### टिप्पणियाँ

यह प्रॉपर्टी इमेज़ खोज में उपयोग किए जाने वाले कंटेंट ऑब्जेक्ट्स को भी निर्दिष्ट करती है। अधिक जानकारी के लिए [`Search`](../search) और [`GetImages`](../getimages) मेथड देखें।

वॉटरमार्क खोज के बारे में अधिक जानें: [Searching watermarks](https://docs.groupdocs.com/display/watermarknet/Searching+watermarks)।

### उदाहरण

एक PDF दस्तावेज़ से सभी XObjects और Artifacts हटाएँ।

```csharp
using (Watermarker watermarker = new Watermarker(@"D:\test.pdf"))
{
    // केवल XObjects और Artifacts की खोज की जानी चाहिए, यह निर्दिष्ट करें।
    watermarker.SearchableObjects.PdfSearchableObjects
        = PdfSearchableObjects.XObjects | PdfSearchableObjects.Artifacts; 

    PossibleWatermarkCollection watermarks = watermarker.Search();

    // सभी पाए गए ऑब्जेक्ट्स हटाएँ।
    watermarks.Clear();

    // परिवर्तनों को सहेजें।
    watermarker.Save();
}
```
