### Property Value

एन्क्रिप्टेड दस्तावेज़ खोलने के लिए पासवर्ड।

### टिप्पणियाँ

पासवर्ड null या खाली स्ट्रिंग हो सकता है। डिफ़ॉल्ट मान null है। यदि सामग्री एन्क्रिप्टेड नहीं है, तो इसे null या खाली स्ट्रिंग पर सेट करें।
