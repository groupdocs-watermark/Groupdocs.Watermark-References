### उदाहरण

किसी भी समर्थित प्रकार के Excel दस्तावेज़ को लोड और सहेजें।

```csharp
SpreadsheetLoadOptions loadOptions = new SpreadsheetLoadOptions();
using (Watermarker watermarker = new Watermarker(@"D:\input.xls", loadOptions))
{
    // एक विशिष्ट या सभी कार्यपत्रकों में वॉटरमार्क जोड़ने के लिए Add मेथड का उपयोग करें।

    // परिवर्तनों को सहेजें।
    watermarker.Save(@"D:\output.xls");
}
```
