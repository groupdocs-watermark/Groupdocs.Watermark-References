## TileOptions.RotateAroundOrigin property

यह दर्शाने वाला मान प्राप्त करता है या सेट करता है कि दोहराए गए वॉटरमार्क दस्तावेज़ के केंद्र के चारों ओर घुमाए जाने चाहिए या नहीं।

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` यदि दोहराए गए वॉटरमार्क को दस्तावेज़ के निचले बाएँ बिंदु के चारों ओर घुमाया जाना चाहिए; अन्यथा, `false`, ऐसे मामले में घुमाव दस्तावेज़ के बाएँ किनारे के सापेक्ष होगा। डिफ़ॉल्ट `false` है।
