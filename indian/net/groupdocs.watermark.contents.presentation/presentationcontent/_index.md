### उदाहरण

किसी भी समर्थित प्रकार के PowerPoint दस्तावेज़ को लोड और सहेजें।

```csharp
PresentationLoadOptions loadOptions = new PresentationLoadOptions();
using (Watermarker watermarker = new Watermarker(@"D:\input.ppt", loadOptions))
{
    // किसी विशेष स्लाइड या सभी स्लाइड्स में वॉटरमार्क जोड़ने के लिए Add मेथड का उपयोग करें।

    // परिवर्तनों को सहेजें।
    watermarker.Save(@"D:\output.ppt");
}
```
