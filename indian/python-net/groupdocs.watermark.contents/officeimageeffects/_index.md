## OfficeImageEffects class

ऑफ़िस सामग्री के लिए इमेज वॉटरमार्क पर लागू किए जा सकने वाले प्रभावों को दर्शाता है।

OfficeImageEffects प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### गुणधर्म
| गुणधर्म | विवरण |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | छवि सीमा के लिए रेखा स्वरूप सेटिंग्स। |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | चित्र की चमक। 0.0 (सबसे मंद) और 1.0 (सबसे उज्ज्वल) के बीच एक फ्लोट होना चाहिए। डिफ़ॉल्ट मान 0.5 है। |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | छवि का वह रंग मान जो पारदर्शी माना जाएगा। डिफ़ॉल्ट मान एक पूरी तरह से पारदर्शी रंग है। |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | निर्दिष्ट चित्र के लिए कंट्रास्ट। यह 0.0 (सबसे कम कंट्रास्ट) और 1.0 (सबसे अधिक कंट्रास्ट) के बीच का फ्लोट होना चाहिए। डिफ़ॉल्ट मान 0.5 है। |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | यह प्रॉपर्टी दर्शाती है कि क्या चित्र को ग्रेस्केल मोड में दिखाया जाएगा। |
