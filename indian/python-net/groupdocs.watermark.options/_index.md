विकल्प क्लासेस जो API के संचालन को कॉन्फ़िगर करती हैं।

### क्लासेस
| क्लास | विवरण |
| :- | :- |
| [`CreatePageStream`](/watermark/python-net/groupdocs.watermark.options/createpagestream/) | एक मेथड का प्रतिनिधित्व करता है जो पेज प्रीव्यू डेटा लिखने के लिए स्ट्रीम लौटाता है। |
| [`ILogger`](/watermark/python-net/groupdocs.watermark.options/ilogger/) | वॉटरमार्किंग के दौरान इवेंट्स और त्रुटियों को लॉग करने के लिए उपयोग किए जाने वाले लॉगर के इंटरफ़ेस को परिभाषित करता है। |
| [`LoadOptions`](/watermark/python-net/groupdocs.watermark.options/loadoptions/) | दस्तावेज़ लोड करते समय दस्तावेज़ लोडिंग विकल्पों का प्रतिनिधित्व करता है। |
| [`OoxmlLoadOptions`](/watermark/python-net/groupdocs.watermark.options/ooxmlloadoptions/) | OOXML दस्तावेज़ के लिए दस्तावेज़ लोडिंग विकल्पों का प्रतिनिधित्व करता है। |
| [`PreviewOptions`](/watermark/python-net/groupdocs.watermark.options/previewoptions/) | प्रीव्यू जनरेशन के लिए आवश्यकताओं और स्ट्रीम डेलीगेट्स सेट करने के विकल्प प्रदान करता है। |
| [`ReleasePageStream`](/watermark/python-net/groupdocs.watermark.options/releasepagestream/) | एक मेथड का प्रतिनिधित्व करता है जो [`CreatePageStream`](/watermark/python-net/groupdocs.watermark.options/createpagestream/) डेलीगेट द्वारा बनाई गई स्ट्रीम को रिलीज़ करता है। |
| [`SaveOptions`](/watermark/python-net/groupdocs.watermark.options/saveoptions/) | दस्तावेज़ सहेजते समय दस्तावेज़ सहेजने के विकल्पों का प्रतिनिधित्व करता है। |
| [`WatermarkOptions`](/watermark/python-net/groupdocs.watermark.options/watermarkoptions/) | दस्तावेज़ में वॉटरमार्क जोड़ते समय वॉटरमार्क जोड़ने के विकल्पों का प्रतिनिधित्व करता है। |
