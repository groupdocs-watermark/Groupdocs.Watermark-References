## PresentationImageFillFormat class

PowerPoint दस्तावेज़ में छवि भराव स्वरूप सेटिंग्स दर्शाता है।

PresentationImageFillFormat प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

### गुणधर्म
| गुणधर्म | विवरण |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | पृष्ठभूमि छवि। यदि छवि सेट नहीं है तो None लौटाता है। |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | जब True सेट किया जाता है तो इमेज बैकग्राउंड में टाइल्ड होती है; अन्यथा यह स्ट्रेच की जाती है। |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | पृष्ठभूमि छवि की पारदर्शिता 0.0 (अपारदर्शी) से 1.0 (पूरी तरह पारदर्शी) तक के मान के रूप में। |
