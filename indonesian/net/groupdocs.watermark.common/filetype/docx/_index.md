## FileType.DOCX field

DOCX adalah format yang terkenal untuk dokumen Microsoft Word. Diperkenalkan sejak 2007 dengan rilis Microsoft Office 2007, struktur format Dokumen baru ini diubah dari biner sederhana menjadi kombinasi file XML dan biner. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/word-processing/docx/).
