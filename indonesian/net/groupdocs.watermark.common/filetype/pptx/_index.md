## FileType.PPTX field

File dengan ekstensi PPTX adalah file presentasi yang dibuat dengan aplikasi Microsoft PowerPoint yang populer. Tidak seperti versi sebelumnya dari format file presentasi PPT yang berbentuk biner, format PPTX berbasis pada format file presentasi Microsoft PowerPoint Open XML. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/presentation/pptx/).
