Namespace menyediakan kelas untuk bekerja dengan dokumen apa pun yang didukung.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Content](./content) | Mewakili konten di mana watermark dapat ditempatkan. |
| [ContentPart](./contentpart) | Mewakili bagian logis apa pun dari sebuah konten (halaman, bingkai, header, atau seluruh konten) di mana watermark dapat ditempatkan. |
| [OfficeImageEffects](./officeimageeffects) | Mewakili efek yang dapat diterapkan pada watermark gambar untuk konten kantor. |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | Mewakili pengaturan format isi gambar dalam konten kantor yang didukung apa pun. |
| [OfficeLineFormat](./officelineformat) | Mewakili format garis bentuk. |
| [OfficeShapeSettings](./officeshapesettings) | Mewakili pengaturan yang dapat diterapkan pada watermark bentuk untuk konten kantor. |
| [OfficeTextEffects](./officetexteffects) | Mewakili efek yang dapat diterapkan pada watermark teks untuk konten kantor. |
## Enumerasi

| Enumerasi | Deskripsi |
| --- | --- |
| [OfficeDashStyle](./officedashstyle) | Mewakili gaya garis putus-putus. |
| [OfficeHeaderFooterType](./officeheaderfootertype) | Mengidentifikasi jenis header atau footer. |
| [OfficeLineStyle](./officelinestyle) | Mewakili gaya garis gabungan dari sebuah [`OfficeLineFormat`](../groupdocs.watermark.contents/officelineformat). |
