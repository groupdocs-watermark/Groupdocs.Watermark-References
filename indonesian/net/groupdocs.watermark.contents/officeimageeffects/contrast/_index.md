## OfficeImageEffects.Contrast property

Mendapatkan atau mengatur kontras untuk gambar yang ditentukan. Nilai properti ini harus berupa angka dari 0.0 (kontras terendah) hingga 1.0 (kontras tertinggi).

```csharp
public double Contrast { get; set; }
```

### Property Value

Nilai default adalah 0.5.
