## WordProcessingWatermarkPagesOptions.PageNumbers property

Mendapatkan atau mengatur nomor halaman untuk menambahkan watermark.

```csharp
public int[] PageNumbers { get; set; }
```

### Property Value

Nomor halaman untuk menambahkan watermark.

### Catatan

Semua nomor harus lebih besar atau sama dengan 1. Properti ini hanya digunakan saat menambahkan watermark ke dokumen. Jika nilai ini `null` atau kosong, watermark akan ditambahkan ke semua halaman.
