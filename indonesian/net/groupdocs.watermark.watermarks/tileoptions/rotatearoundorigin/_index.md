## TileOptions.RotateAroundOrigin property

Mendapatkan atau mengatur nilai yang menunjukkan apakah watermark berulang harus diputar di sekitar pusat dokumen.

```csharp
public bool RotateAroundOrigin { get; set; }
```

### Property Value

`true` jika watermark yang diulang harus diputar mengelilingi titik kiri bawah dokumen; jika tidak, `false`, dalam kasus tersebut rotasi akan relatif terhadap tepi kiri dokumen. Nilai default adalah `false`.
