## Watermark.IsBackground property

Mendapatkan atau mengatur nilai yang menunjukkan apakah watermark harus ditempatkan di latar belakang.

```csharp
public bool IsBackground { get; set; }
```

### Property Value

Jika nilainya true, watermark akan ditempatkan di bagian bawah. Secara default, nilainya false, watermark akan ditempatkan di bagian atas.
