## Watermark.ConsiderParentMargins property

Mengambil atau mengatur nilai yang menunjukkan apakah ukuran dan koordinat watermark dihitung dengan mempertimbangkan margin induk.

```csharp
public bool ConsiderParentMargins { get; set; }
```

### Property Value

Jika nilainya true, ukuran watermark dan koordinat dihitung dengan mempertimbangkan margin induk. Secara default, nilainya false, margin induk diabaikan.
