## WordProcessingVerticalAlignment enumeration

Menentukan perataan vertikal objek mengambang.

```csharp
public enum WordProcessingVerticalAlignment
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Inline | `-1` | Tidak terdokumentasi. Tampaknya merupakan nilai yang mungkin untuk paragraf dan tabel mengambang. |
| None | `0` | Objek diposisikan secara eksplisit menggunakan koordinat y-nya. |
| Top | `1` | Menentukan bahwa objek berada di bagian atas dasar penyelarasan vertikal. |
| Center | `2` | Menentukan bahwa objek berada di tengah relatif terhadap dasar penyelarasan vertikal. |
| Bottom | `3` | Menentukan bahwa objek berada di bagian bawah dasar penyelarasan vertikal. |
| Inside | `4` | Menentukan bahwa objek berada di dalam dasar penyelarasan horizontal. |
| Outside | `5` | Menentukan bahwa objek berada di luar dasar penyelarasan vertikal. |
