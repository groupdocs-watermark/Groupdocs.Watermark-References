## WordProcessingRelativeHorizontalPosition enumeration

Menentukan relatif apa posisi horizontal objek.

```csharp
public enum WordProcessingRelativeHorizontalPosition
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Margin | `0` | Menentukan bahwa posisi horizontal relatif terhadap margin halaman. |
| Page | `1` | Objek diposisikan relatif terhadap tepi kiri halaman. |
| Column | `2` | Objek diposisikan relatif terhadap sisi kiri kolom. |
| Character | `3` | Objek diposisikan relatif terhadap sisi kiri paragraf. |
| LeftMargin | `4` | Menentukan bahwa posisi horizontal relatif terhadap margin kiri halaman. |
| RightMargin | `5` | Menentukan bahwa posisi horizontal relatif terhadap margin kanan halaman. |
| InsideMargin | `6` | Menentukan bahwa posisi horizontal relatif terhadap margin dalam halaman saat ini (margin kiri pada halaman ganjil, kanan pada halaman genap). |
| OutsideMargin | `7` | Menentukan bahwa posisi horizontal relatif terhadap margin luar halaman saat ini (margin kanan pada halaman ganjil, kiri pada halaman genap). |
