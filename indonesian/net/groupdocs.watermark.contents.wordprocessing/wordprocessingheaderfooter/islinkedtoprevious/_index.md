## WordProcessingHeaderFooter.IsLinkedToPrevious property

Mendapatkan atau mengatur nilai yang menunjukkan apakah header/footer ini terhubung ke header/footer yang sesuai di bagian sebelumnya.

```csharp
public bool IsLinkedToPrevious { get; set; }
```

### Property Value

True jika header/footer ini terhubung ke header/footer yang sesuai di bagian sebelumnya; false jika tidak.

### Catatan

Default adalah true. Catatan, ketika Anda menautkan header atau footer, isinya akan dibersihkan.
