Namespace menyediakan kelas untuk menambahkan tanda air ke gambar dengan berbagai format.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [GifImageContent](./gifimagecontent) | Mewakili gambar gif di mana watermark dapat ditempatkan. |
| [ImageContent](./imagecontent) | Mewakili gambar di mana watermark dapat ditempatkan. |
| [ImageFrame](./imageframe) | Mewakili bingkai gambar di mana watermark dapat ditempatkan. |
| [ImageFrameCollection](./imageframecollection) | Mewakili koleksi bingkai dalam gambar multibingkai. |
| [MultiframeImageContent](./multiframeimagecontent) | Mewakili gambar multibingkai di mana watermark dapat ditempatkan. |
| [SystemDrawingImageFrame](./systemdrawingimageframe) | Mewakili bingkai gambar di mana watermark dapat ditempatkan (implementasi System.Drawing). |
| [SystemDrawingImageFrameCollection](./systemdrawingimageframecollection) | Mewakili koleksi bingkai dalam gambar multibingkai. |
| [TiffImageContent](./tiffimagecontent) | Mewakili gambar tiff di mana watermark dapat ditempatkan. |
| [WatermarkableImage](./watermarkableimage) | Mewakili gambar di dalam dokumen. |
| [WatermarkableImageCollection](./watermarkableimagecollection) | Mewakili koleksi gambar yang ditemukan dalam dokumen. |
