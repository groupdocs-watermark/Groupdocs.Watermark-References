Namespace menyediakan kelas untuk menentukan opsi tambahan saat bekerja dengan dokumen dan tanda air.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [CreatePageStream](./createpagestream) | Mewakili metode yang mengembalikan aliran untuk menulis data pratinjau halaman. |
| [LoadOptions](./loadoptions) | Mewakili opsi pemuatan dokumen saat memuat dokumen. |
| [OoxmlLoadOptions](./ooxmlloadoptions) | Mewakili opsi pemuatan dokumen untuk dokumen OOXML. |
| [PreviewOptions](./previewoptions) | Menyediakan opsi untuk menetapkan persyaratan dan delegasi aliran untuk pembuatan pratinjau. |
| [ReleasePageStream](./releasepagestream) | Mewakili metode yang melepaskan aliran yang dibuat oleh delegasi [`CreatePageStream`](../groupdocs.watermark.options/createpagestream). |
| [SaveOptions](./saveoptions) | Mewakili opsi penyimpanan dokumen saat menyimpan dokumen. |
| [WatermarkOptions](./watermarkoptions) | Mewakili opsi penambahan watermark saat menambahkan watermark ke dokumen. |
