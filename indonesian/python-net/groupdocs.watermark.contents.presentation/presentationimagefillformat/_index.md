## PresentationImageFillFormat class

Mewakili pengaturan format isi gambar dalam dokumen PowerPoint.

Tipe PresentationImageFillFormat menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | Gambar latar belakang. Mengembalikan None jika gambar tidak disetel. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | Gambar ditata berulang di latar belakang ketika diatur ke True; jika tidak, gambar akan diregangkan. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | Transparansi gambar latar belakang sebagai nilai dari 0.0 (opaque) hingga 1.0 (sepenuhnya transparan). |
