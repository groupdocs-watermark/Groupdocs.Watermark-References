## OfficeImageEffects class

Mewakili efek yang dapat diterapkan pada watermark gambar untuk konten kantor.

Tipe OfficeImageEffects menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | Pengaturan format garis untuk batas gambar. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | Kecerahan gambar. Harus berupa float antara 0.0 (paling gelap) dan 1.0 (paling terang). Nilai default adalah 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | Nilai warna gambar yang akan diperlakukan sebagai transparan. Nilai default adalah warna yang sepenuhnya transparan. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Kontras untuk gambar yang ditentukan. Harus berupa angka float antara 0.0 (kontras terendah) dan 1.0 (kontras tertinggi). Nilai default adalah 0.5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | Properti ini menunjukkan apakah gambar akan ditampilkan dalam mode skala abu-abu. |
