## PdfXForm class

Mewakili XForm dalam konten pdf.

Tipe PdfXForm menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/height/) | Tinggi objek. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/rotate_angle/) | Sudut rotasi objek dalam derajat. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/width/) | Lebar objek. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/x/) | Koordinat x objek. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxform/y/) | Koordinat y objek. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | Koleksi fragmen teks terformat dari [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (diturunkan dari [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | Gambar dari PdfShape ini. Mengembalikan None jika objek tidak memiliki gambar. (diturunkan dari [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | Halaman induk dari PdfXObject ini. (diturunkan dari [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | Teks dari [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (diturunkan dari [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
