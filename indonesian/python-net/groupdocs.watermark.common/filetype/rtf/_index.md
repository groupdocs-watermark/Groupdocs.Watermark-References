## RTF field

Diperkenalkan dan didokumentasikan oleh Microsoft, Rich Text Format (RTF) merupakan metode pengkodean teks terformat dan grafik untuk digunakan dalam aplikasi. Format ini memfasilitasi pertukaran dokumen lintas platform dengan produk Microsoft lainnya, sehingga berfungsi untuk interoperabilitas. Pelajari lebih lanjut tentang format file ini di sini.
