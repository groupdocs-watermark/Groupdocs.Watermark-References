## WEBP field

WebP, yang diperkenalkan oleh Google, adalah format file gambar web raster modern yang berbasis kompresi lossless dan lossy. Ini memberikan kualitas gambar yang sama sekaligus secara signifikan mengurangi ukuran gambar. Pelajari lebih lanjut tentang format file ini di sini.
