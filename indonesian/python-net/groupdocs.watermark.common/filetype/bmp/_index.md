## BMP field

File dengan ekstensi .BMP mewakili file Gambar Bitmap yang digunakan untuk menyimpan gambar digital bitmap. Gambar ini independen dari adaptor grafis dan juga disebut format file device independent bitmap (DIB). Pelajari lebih lanjut tentang format file ini di sini.
