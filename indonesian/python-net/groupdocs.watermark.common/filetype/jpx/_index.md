## JPX field

JPEG 2000 (JPX) adalah sistem pengkodean gambar dan standar kompresi gambar mutakhir. Dirancang dengan teknologi wavelet, JPEG 2000 dapat mengkode konten lossless dengan kualitas apa pun secara bersamaan. Pelajari lebih lanjut tentang format file ini di sini.
