## SpreadsheetImageFillFormat class

Mewakili pengaturan format isi gambar dalam dokumen Excel.

Tipe SpreadsheetImageFillFormat menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | Gambar latar belakang. Mengembalikan None jika gambar tidak disetel. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | Gambar akan ditile di seluruh latar belakang ketika True; jika tidak, gambar akan diregangkan. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | Transparansi gambar latar belakang sebagai nilai dari 0.0 (opaque) hingga 1.0 (sepenuhnya transparan). |
