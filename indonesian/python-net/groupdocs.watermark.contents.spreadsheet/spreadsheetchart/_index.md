## SpreadsheetChart class

Mewakili diagram dalam dokumen Excel.

Tipe SpreadsheetChart menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/alternative_text/) | Teks deskriptif (alternatif) yang terkait dengan [`SpreadsheetChart`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/height/) | Tinggi SpreadsheetChart ini dalam poin. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/hyperlink/) | Hipertautan yang terkait dengan SpreadsheetChart ini. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/id/) | Pengidentifikasi SpreadsheetChart ini. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/image_fill_format/) | Pengaturan format pengisian gambar dari SpreadsheetChart ini. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/name/) | Nama dari SpreadsheetChart ini. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/width/) | Lebar SpreadsheetChart ini dalam poin. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/worksheet/) | Lembar kerja induk dari SpreadsheetChart ini. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/x/) | Offset horizontal SpreadsheetChart ini dari batas kiri lembar kerja dalam poin. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetchart/y/) | Offset vertikal SpreadsheetChart ini dari batas atas lembar kerja dalam poin. |
