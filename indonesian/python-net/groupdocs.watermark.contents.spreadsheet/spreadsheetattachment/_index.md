## SpreadsheetAttachment class

Mewakili file yang dilampirkan ke dokumen Excel.

Tipe SpreadsheetAttachment menampilkan anggota-anggota berikut:

### Metode
| Metode | Deskripsi |
| :- | :- |
| [create_watermarker](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker/) | Memuat konten dari file yang dilampirkan. (diturunkan dari [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [create_watermarker_load_options](/watermark/python-net/groupdocs.watermark.common/attachment/create_watermarker_load_options/) | (diturunkan dari [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |
| [get_document_info](/watermark/python-net/groupdocs.watermark.common/attachment/get_document_info/) | Mengambil informasi tentang dokumen yang disimpan dalam file yang dilampirkan. (diturunkan dari [`Attachment`](/watermark/python-net/groupdocs.watermark.common/attachment/)) |

### Properti
| Properti | Deskripsi |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/alternative_text/) | Teks deskriptif (alternatif) yang terkait dengan file yang dilampirkan. |
| [content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/content/) | Konten file yang dilampirkan. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/height/) | Tinggi bingkai lampiran dalam poin. |
| [is_link](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/is_link/) | Properti ini menunjukkan apakah lampiran hanya berisi tautan ke file. |
| [preview_image_content](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/preview_image_content/) | Gambar pratinjau file yang dilampirkan sebagai array byte. |
| [source_full_name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/source_full_name/) | Nama lengkap file yang dilampirkan. |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/width/) | Lebar bingkai lampiran dalam poin. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/x/) | Offset horizontal bingkai lampiran dari batas kiri lembar kerja dalam poin. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetattachment/y/) | Koordinat y bingkai lampiran dalam poin. |
