## Margins class

Mewakili pengaturan margin untuk setiap tepi objek.

Tipe Margins menampilkan anggota-anggota berikut:

### Konstruktor
| Konstruktor | Deskripsi |
| :- | :- |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/) | Menginisialisasi instance baru dari kelas [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) class. |
| [__init__](/watermark/python-net/groupdocs.watermark.watermarks/margins/__init__/#margin_type-left-right-top-bottom) | Menginisialisasi instance baru dari kelas [`Margins`](/watermark/python-net/groupdocs.watermark.watermarks/margins/) dengan tipe, lokasi, dan ukuran yang ditentukan. |

### Properti
| Properti | Deskripsi |
| :- | :- |
| [bottom](/watermark/python-net/groupdocs.watermark.watermarks/margins/bottom/) | Margin bawah. Mewakili offset horizontal dari batas bawah induk. |
| [left](/watermark/python-net/groupdocs.watermark.watermarks/margins/left/) | Margin kiri, dinyatakan sebagai offset horizontal dari batas kiri induk. |
| [margin_type](/watermark/python-net/groupdocs.watermark.watermarks/margins/margin_type/) | Tipe margin, yang menentukan bagaimana margin diinterpretasikan; menetapkan nilai baru secara otomatis mengatur ulang semua margin ke nilai default mereka (nol). |
| [right](/watermark/python-net/groupdocs.watermark.watermarks/margins/right/) | Margin kanan sebagai offset horizontal dari batas kanan induk. |
| [top](/watermark/python-net/groupdocs.watermark.watermarks/margins/top/) | Margin atas. |
