## Watermark class

Mewakili watermark yang akan ditambahkan ke dokumen.

Pelajari lebih lanjut

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Tipe Watermark menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | Properti yang menunjukkan apakah ukuran dan koordinat watermark dihitung dengan mempertimbangkan margin induk. Jika disetel ke True, perhitungan mempertimbangkan margin induk; secara default nilai adalah False dan margin induk diabaikan. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | Tinggi yang diinginkan untuk [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) ini. |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | Perataan horizontal dari Watermark ini. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | Properti yang menunjukkan apakah watermark harus ditempatkan di latar belakang. Jika true, watermark ditempatkan di bagian bawah; jika tidak, ditempatkan di bagian atas (default adalah False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | Pengaturan margin untuk Watermark ini. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | Opasitas dari [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) ini. |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | Pengaturan penyiapan halaman untuk Watermark ini. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | Sudut rotasi dari [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) ini dalam derajat. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | Properti yang menunjukkan apakah informasi tentang watermark yang ditambahkan disimpan dalam metadata dokumen. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | Faktor skala dari [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) ini, yang menentukan bagaimana ukuran watermark bergantung pada ukuran induk. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | Tipe ukuran watermark. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | Opsi untuk mendefinisikan watermark berulang. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | Perataan vertikal dari [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | Lebar yang diinginkan dari [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | Koordinat x dari [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
