### Contoh

```python
from groupdocs.watermark import Watermarker

with Watermarker("D:\\input.pdf") as watermarker:
    # Gunakan metode Watermarker untuk menambahkan, mencari, atau menghapus watermark.
    watermarker.save("D:\\output.pdf")
```
