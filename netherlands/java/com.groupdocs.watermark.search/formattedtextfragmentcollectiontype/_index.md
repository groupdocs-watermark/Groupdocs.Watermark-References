Specificeert het aantal elementen dat een collectie van opgemaakte tekstfragmenten kan bevatten.

## Velden

| Veld | Beschrijving |
| --- | --- |

|
|  | [SingleFragment](#SingleFragment) | De volledige tekst kan worden opgemaakt met één stijl, de collectie kan slechts één fragment bevatten. |
|
|  | [NoFormattedText](#NoFormattedText) | Bovenliggend object ondersteunt geen tekstopmaak, de collectie is altijd leeg. |
|
