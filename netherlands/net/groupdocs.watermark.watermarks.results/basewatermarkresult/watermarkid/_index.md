## BaseWatermarkResult.WatermarkId property

Unieke watermerkidentificatie om het watermerk in het document te wijzigen via de Update- of Delete-methoden. Deze eigenschap wordt automatisch ingesteld nadat de Add-methode is aangeroepen. Als deze eigenschap eerder is opgeslagen, kan deze handmatig worden ingesteld om het watermerk te manipuleren.

public string WatermarkId { get; }
