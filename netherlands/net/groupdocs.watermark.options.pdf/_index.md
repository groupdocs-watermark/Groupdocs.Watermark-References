De namespace biedt klassen om extra opties te specificeren bij het werken met watermerken en PDF-documenten.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [PdfAnnotationWatermarkOptions](./pdfannotationwatermarkoptions) | Stelt opties voor het toevoegen van een watermerk voor wanneer een annotatiewatermerk aan een pdf‑document wordt toegevoegd. |
| [PdfArtifactWatermarkOptions](./pdfartifactwatermarkoptions) | Stelt opties voor het toevoegen van een watermerk voor wanneer een artefactwatermerk aan een pdf‑document wordt toegevoegd. |
| [PdfLoadOptions](./pdfloadoptions) | Stelt opties voor het laden van een document voor een pdf‑document. |
| [PdfPreviewOptions](./pdfpreviewoptions) | Biedt opties om vereisten en stream‑delegaten in te stellen voor het genereren van een voorbeeld van een PDF‑document. |
| [PdfSaveOptions](./pdfsaveoptions) | Stelt opties voor het opslaan van een document voor wanneer een pdf‑document wordt opgeslagen. |
| [PdfWatermarkOptions](./pdfwatermarkoptions) | Basisklasse voor opties voor het toevoegen van een watermerk aan een pdf‑document. |
| [PdfXObjectWatermarkOptions](./pdfxobjectwatermarkoptions) | Stelt opties voor het toevoegen van een watermerk voor wanneer een XObject‑watermerk aan een pdf‑document wordt toegevoegd. |
