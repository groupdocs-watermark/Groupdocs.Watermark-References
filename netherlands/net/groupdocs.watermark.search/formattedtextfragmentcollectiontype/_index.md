## FormattedTextFragmentCollectionType enumeration

Specificeert het aantal elementen dat een verzameling van opgemaakte tekstfragmenten kan bevatten.

```csharp
public enum FormattedTextFragmentCollectionType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| UnlimitedFragments | `0` | Meerdere stijlen zijn toegestaan, de collectie kan een onbeperkt aantal fragmenten bevatten. |
| SingleFragment | `1` | De volledige tekst kan worden opgemaakt met één stijl, de collectie kan slechts één fragment bevatten. |
| NoFormattedText | `2` | Bovenliggend object ondersteunt geen tekstopmaak, de collectie is altijd leeg. |
