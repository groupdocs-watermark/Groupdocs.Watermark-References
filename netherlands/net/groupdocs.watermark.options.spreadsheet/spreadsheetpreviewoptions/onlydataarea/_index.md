## SpreadsheetPreviewOptions.OnlyDataArea property

Haalt of stelt de vlag in voor het weergeven van alleen het gegevensgebied zonder kopteksten, voetteksten, marges.

```csharp
public bool OnlyDataArea { get; set; }
```

### Property Value

De vlag voor het weergeven van alleen het gegevensgebied zonder kopteksten, voetteksten en marges.

### Opmerkingen

Deze vlag zorgt ervoor dat het hele werkblad op één pagina wordt weergegeven. De standaardwaarde is `false`.
