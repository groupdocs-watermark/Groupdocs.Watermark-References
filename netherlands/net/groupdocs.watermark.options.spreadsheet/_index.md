De namespace biedt klassen om extra opties te specificeren bij het werken met watermerken en Excel-documenten.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [SpreadsheetBackgroundWatermarkOptions](./spreadsheetbackgroundwatermarkoptions) | Stelt opties voor wanneer het watermerk wordt toegevoegd als achtergrond aan een Spreadsheet-werkblad voor. |
| [SpreadsheetImageEffects](./spreadsheetimageeffects) | Stelt effecten voor die kunnen worden toegepast op een afbeeldingwatermerk voor een Excel-document voor. |
| [SpreadsheetLoadOptions](./spreadsheetloadoptions) | Stelt documentlaadopties voor een Spreadsheet-document voor. |
| [SpreadsheetPreviewOptions](./spreadsheetpreviewoptions) | Biedt opties om vereisten en streamdelegates in te stellen voor het genereren van een voorbeeld van een Spreadsheet-document. |
| [SpreadsheetSaveOptions](./spreadsheetsaveoptions) | Geeft de opties voor het opslaan van een document weer bij het opslaan van een Spreadsheet-document. |
| [SpreadsheetShapeSettings](./spreadsheetshapesettings) | Geeft de instellingen weer die kunnen worden toegepast op een vorm-watermerk voor een Excel-document. |
| [SpreadsheetTextEffects](./spreadsheettexteffects) | Geeft de effecten weer die kunnen worden toegepast op een tekstwatermerk voor een Excel-document. |
| [SpreadsheetWatermarkBaseOptions](./spreadsheetwatermarkbaseoptions) | Basisklasse voor opties om een watermerk toe te voegen aan een Spreadsheet-document. |
| [SpreadsheetWatermarkHeaderFooterOptions](./spreadsheetwatermarkheaderfooteroptions) | Geeft de opties weer bij het toevoegen van het watermerk aan een Spreadsheet-kop-/voettekst. |
| [SpreadsheetWatermarkModernWordArtOptions](./spreadsheetwatermarkmodernwordartoptions) | Geeft de opties weer bij het toevoegen van een modern woordkunst-watermerk aan een Spreadsheet-werkblad. |
| [SpreadsheetWatermarkShapeOptions](./spreadsheetwatermarkshapeoptions) | Geeft de opties weer bij het toevoegen van een vorm-watermerk aan een Spreadsheet-werkblad. |
