De namespace biedt klassen om extra opties te specificeren bij het werken met watermerken en afbeeldingen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [GifImageLoadOptions](./gifimageloadoptions) | Geeft laadopties weer voor een GIF-afbeelding. |
| [GifImageSaveOptions](./gifimagesaveoptions) | Geeft opslaanopties weer bij het opslaan van een GIF-afbeelding. |
| [GifImageWatermarkOptions](./gifimagewatermarkoptions) | Geeft opties voor het toevoegen van een watermerk weer bij het toevoegen van een watermerk aan een GIF-afbeelding. |
| [ImageLoadOptions](./imageloadoptions) | Geeft laadopties weer bij het laden van een afbeelding. |
| [ImageSaveOptions](./imagesaveoptions) | Geeft opslaanopties weer bij het opslaan van een afbeelding. |
| [MultiframeImageLoadOptions](./multiframeimageloadoptions) | Geeft laadopties weer bij het laden van een multiframe-afbeelding. |
| [MultiframeImageWatermarkOptions](./multiframeimagewatermarkoptions) | Stelt opties voor het toevoegen van een watermerk voor wanneer een watermerk wordt toegevoegd aan een afbeelding met meerdere frames voor. |
| [TiffImageLoadOptions](./tiffimageloadoptions) | Stelt laadopties voor een TIFF-afbeelding voor. |
| [TiffImageSaveOptions](./tiffimagesaveoptions) | Stelt opslaanopties voor een TIFF-afbeelding voor. |
| [TiffImageWatermarkOptions](./tiffimagewatermarkoptions) | Stelt opties voor het toevoegen van een watermerk voor wanneer een watermerk wordt toegevoegd aan een TIFF-afbeelding voor. |
