## SpreadsheetAttachmentCollection.AddAttachment method

Voegt een bijlage toe aan de [`SpreadsheetWorksheet`](../../spreadsheetworksheet).

```csharp
public void AddAttachment(byte[] fileContent, string sourceFullName, byte[] previewImageContent, 
    double x, double y, double width, double height)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| fileContent | Byte[] | De inhoud van het bestand dat moet worden bijgevoegd. |
| sourceFullName | String | De volledige naam van het bijgevoegde bestand (De extensie wordt gebruikt om de juiste toepassing te bepalen om het bestand te openen). |
| previewImageContent | Byte[] | De preview-afbeelding van het bijgevoegde bestand als een byte-array. |
| x | Double | De x-coördinaat van het bijlageframe (in punten). |
| y | Double | De y-coördinaat van het bijlageframe (in punten). |
| width | Double | De breedte van het bijlageframe in punten. |
| height | Double | De hoogte van het bijlageframe in punten. |
