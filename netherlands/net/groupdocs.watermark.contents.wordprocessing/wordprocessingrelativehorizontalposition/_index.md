## WordProcessingRelativeHorizontalPosition enumeration

Specificeert ten opzichte waarvan de horizontale positie van een object is.

```csharp
public enum WordProcessingRelativeHorizontalPosition
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Margin | `0` | Specificeert dat de horizontale positionering relatief is aan de paginamarges. |
| Page | `1` | Het object is gepositioneerd relatief aan de linkerrand van de pagina. |
| Column | `2` | Het object is gepositioneerd relatief aan de linkerkant van de kolom. |
| Character | `3` | Het object is gepositioneerd relatief aan de linkerkant van de alinea. |
| LeftMargin | `4` | Specificeert dat de horizontale positionering relatief is aan de linkermarge van de pagina. |
| RightMargin | `5` | Specificeert dat de horizontale positionering relatief is aan de rechtermarge van de pagina. |
| InsideMargin | `6` | Specificeert dat de horizontale positionering relatief is aan de binnenmarge van de huidige pagina (de linkermarge op oneven pagina's, de rechtermarge op even pagina's). |
| OutsideMargin | `7` | Specificeert dat de horizontale positionering relatief is aan de buitenmarge van de huidige pagina (de rechtermarge op oneven pagina's, de linkermarge op even pagina's). |
