## WordProcessingVerticalAlignment enumeration

Specificeert de verticale uitlijning van een zwevend object.

```csharp
public enum WordProcessingVerticalAlignment
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Inline | `-1` | Niet gedocumenteerd. Lijkt een mogelijke waarde te zijn voor zwevende alinea's en tabellen. |
| None | `0` | Het object is expliciet gepositioneerd met behulp van zijn y-coördinaat. |
| Top | `1` | Specificeert dat het object zich aan de bovenkant van de verticale uitlijningsbasis bevindt. |
| Center | `2` | Specificeert dat het object gecentreerd is ten opzichte van de verticale uitlijningsbasis. |
| Bottom | `3` | Specificeert dat het object zich aan de onderkant van de verticale uitlijningsbasis bevindt. |
| Inside | `4` | Specificeert dat het object zich binnen de horizontale uitlijningsbasis bevindt. |
| Outside | `5` | Specificeert dat het object zich buiten de verticale uitlijningsbasis bevindt. |
