De namespace biedt klassen om extra opties te specificeren bij het werken met watermerken en Word-documenten.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [WordProcessingImageEffects](./wordprocessingimageeffects) | Geeft effecten weer die op een afbeeldingwatermerk voor een Word-document kunnen worden toegepast. |
| [WordProcessingLoadOptions](./wordprocessingloadoptions) | Geeft documentlaadopties weer voor een Word-document. |
| [WordProcessingPreviewOptions](./wordprocessingpreviewoptions) | Biedt opties om vereisten en streamdelegates in te stellen voor het genereren van een voorbeeld van een WordProcessing-document. |
| [WordProcessingSaveOptions](./wordprocessingsaveoptions) | Geeft opslaanopties weer voor een document bij het opslaan van een Word-document. |
| [WordProcessingTextEffects](./wordprocessingtexteffects) | Geeft effecten weer die op een tekstwatermerk voor een Word-document kunnen worden toegepast. |
| [WordProcessingWatermarkBaseOptions](./wordprocessingwatermarkbaseoptions) | Basisklasse voor opties voor het toevoegen van een watermerk aan een Word-document. |
| [WordProcessingWatermarkHeaderFooterOptions](./wordprocessingwatermarkheaderfooteroptions) | Geeft opties weer bij het toevoegen van het watermerk aan een kop-/voettekst van een Word‑sectie. |
| [WordProcessingWatermarkPagesOptions](./wordprocessingwatermarkpagesoptions) | Geeft opties weer bij het toevoegen van een watermerk aan Word-documentpagina's. |
| [WordProcessingWatermarkSectionOptions](./wordprocessingwatermarksectionoptions) | Geeft opties weer bij het toevoegen van een vormwatermerk aan een Word‑sectie. |
