## WordProcessingLockType enumeration

Specificeert het vergrendelings type van een watermerk in een Word-document.

```csharp
public enum WordProcessingLockType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| AllowOnlyRevisions | `0` | Gebruiker kan alleen revisiemarkeringen aan het document toevoegen. |
| AllowOnlyComments | `1` | Gebruiker kan alleen opmerkingen in het document wijzigen. |
| AllowOnlyFormFields | `2` | Gebruiker kan alleen gegevens invoeren in de formuliervelden in het document. |
| ReadOnly | `3` | Het volledige document is alleen-lezen. |
| ReadOnlyWithEditableContent | `4` | Het document is alleen-lezen, maar alle inhoud behalve het watermerk is gemarkeerd als bewerkbaar. |
| NoLock | `-1` | Schakel elke vergrendeling op watermerk en document uit. |
