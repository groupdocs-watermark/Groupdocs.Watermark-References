De namespace biedt klassen voor het werken met documenten van elk ondersteund type.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [Content](./content) | Stelt een inhoud voor waarin een watermerk kan worden geplaatst. |
| [ContentPart](./contentpart) | Stelt elk logisch onderdeel van een inhoud (pagina, frame, header of de volledige inhoud) voor waarin een watermerk kan worden geplaatst. |
| [OfficeImageEffects](./officeimageeffects) | Stelt effecten voor die kunnen worden toegepast op een afbeelding-watermerk voor een kantoormateriaal. |
| [OfficeImageFillFormat&lt;TWatermarkableImage&gt;](./officeimagefillformat-1) | Stelt de instellingen voor afbeeldingvulling in elk ondersteund kantoormateriaal voor. |
| [OfficeLineFormat](./officelineformat) | Stelt een vormlijnindeling voor. |
| [OfficeShapeSettings](./officeshapesettings) | Stelt instellingen voor die kunnen worden toegepast op een vorm-watermerk voor een kantoormateriaal. |
| [OfficeTextEffects](./officetexteffects) | Stelt effecten voor die kunnen worden toegepast op een tekst-watermerk voor een kantoormateriaal. |
