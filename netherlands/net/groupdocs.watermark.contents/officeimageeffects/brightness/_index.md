## OfficeImageEffects.Brightness property

Haalt op of stelt de helderheid van de afbeelding in. De waarde voor deze eigenschap moet een getal zijn tussen 0.0 (donkerst) en 1.0 (helderst).

```csharp
public double Brightness { get; set; }
```

### Property Value

De standaardwaarde is 0,5.
