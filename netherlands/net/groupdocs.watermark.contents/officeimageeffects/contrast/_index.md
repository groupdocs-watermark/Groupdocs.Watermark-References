## OfficeImageEffects.Contrast property

Haalt op of stelt het contrast in voor de opgegeven afbeelding. De waarde voor deze eigenschap moet een getal zijn tussen 0.0 (het minste contrast) en 1.0 (het grootste contrast).

```csharp
public double Contrast { get; set; }
```

### Property Value

De standaardwaarde is 0,5.
