De namespace biedt klassen voor het toevoegen van watermerken aan afbeeldingen van verschillende formaten.

| Klasse | Beschrijving |
| --- | --- |
| [GifImageContent](./gifimagecontent) | Stelt een gif-afbeelding voor waarop een watermerk kan worden geplaatst. |
| [ImageContent](./imagecontent) | Stelt een afbeelding voor waarop een watermerk kan worden geplaatst. |
| [ImageFrame](./imageframe) | Stelt een afbeeldingsframe voor waarop een watermerk kan worden geplaatst. |
| [ImageFrameCollection](./imageframecollection) | Stelt een verzameling frames in een multiframe-afbeelding voor. |
| [MultiframeImageContent](./multiframeimagecontent) | Stelt een multiframe-afbeelding voor waarop een watermerk kan worden geplaatst. |

| [SystemDrawingImageFrameCollection](./systemdrawingimageframecollection) | Stelt een verzameling frames in een multiframe-afbeelding voor. |
| [TiffImageContent](./tiffimagecontent) | Stelt een tiff-afbeelding voor waarop een watermerk kan worden geplaatst. |
| [WatermarkableImage](./watermarkableimage) | Stelt een afbeelding binnen een document voor. |
| [WatermarkableImageCollection](./watermarkableimagecollection) | Stelt een verzameling afbeeldingen voor die in een document zijn gevonden. |
