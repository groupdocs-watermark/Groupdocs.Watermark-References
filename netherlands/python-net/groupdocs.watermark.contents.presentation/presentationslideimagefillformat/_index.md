## PresentationSlideImageFillFormat class

Stelt de instellingen voor het afbeeldingvulformaat van een dia in een PowerPoint-document voor.

Het PresentationSlideImageFillFormat-type biedt de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationslideimagefillformat/background_image/) | De achtergrondafbeelding; retourneert None als de afbeelding niet is ingesteld. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | De afbeelding wordt getegeld over de achtergrond wanneer ingesteld op True; anders wordt deze uitgerekt. (geërfd van [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | De transparantie van de achtergrondafbeelding als een waarde van 0.0 (ondoorzichtig) tot 1.0 (volledig transparant). (geërfd van [`PresentationImageFillFormat`](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/)) |
