## PresentationImageFillFormat class

Stelt de instellingen voor afbeeldingsvulling in een PowerPoint-document voor.

Het PresentationImageFillFormat type exposeert de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/background_image/) | De achtergrondafbeelding. Retourneert None als de afbeelding niet is ingesteld. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/tile_as_texture/) | De afbeelding wordt getegeld over de achtergrond wanneer ingesteld op True; anders wordt deze uitgerekt. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.presentation/presentationimagefillformat/transparency/) | De transparantie van de achtergrondafbeelding als een waarde van 0,0 (ondoorzichtig) tot 1,0 (volledig transparant). |
