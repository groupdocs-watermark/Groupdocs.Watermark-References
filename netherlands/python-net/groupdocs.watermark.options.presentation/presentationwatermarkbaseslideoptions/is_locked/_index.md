## is_locked property

De eigenschap geeft aan of bewerken van de vorm in PowerPoint verboden is.

Als de waarde True is, is bewerken van vormen verboden. Standaard is de waarde False, waardoor de vorm in PowerPoint kan worden bewerkt.
