## Watermark class

Stelt een watermerk voor dat aan een document moet worden toegevoegd.

Meer info

- More details about watermark properties: Adding text watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+text+watermarks)
- More advanced watermarking topics: Adding watermarks (https://docs.groupdocs.com/display/watermarknet/Adding+watermarks)

Het type Watermark bevat de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [consider_parent_margins](/watermark/python-net/groupdocs.watermark/watermark/consider_parent_margins/) | De eigenschap die aangeeft of de grootte en coördinaten van het watermerk worden berekend met inachtneming van de marges van de bovenliggende container. Indien ingesteld op True, worden de berekeningen uitgevoerd met de marges van de bovenliggende container; standaard is de waarde False en worden de marges van de bovenliggende container genegeerd. |
| [height](/watermark/python-net/groupdocs.watermark/watermark/height/) | De gewenste hoogte van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [horizontal_alignment](/watermark/python-net/groupdocs.watermark/watermark/horizontal_alignment/) | De horizontale uitlijning van dit Watermark. |
| [is_background](/watermark/python-net/groupdocs.watermark/watermark/is_background/) | De eigenschap die aangeeft of het watermerk op de achtergrond moet worden geplaatst. Als true, wordt het watermerk onderaan geplaatst; anders wordt het bovenaan geplaatst (standaard is False). |
| [margins](/watermark/python-net/groupdocs.watermark/watermark/margins/) | De marge‑instellingen van dit Watermark. |
| [opacity](/watermark/python-net/groupdocs.watermark/watermark/opacity/) | De doorzichtigheid van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [pages_setup](/watermark/python-net/groupdocs.watermark/watermark/pages_setup/) | De pagina‑instellingen van dit Watermark. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark/watermark/rotate_angle/) | De rotatiehoek van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/) in graden. |
| [save_result_in_metadata](/watermark/python-net/groupdocs.watermark/watermark/save_result_in_metadata/) | De eigenschap geeft aan of informatie over toegevoegde watermerken moet worden opgeslagen in de documentmetadata. |
| [scale_factor](/watermark/python-net/groupdocs.watermark/watermark/scale_factor/) | De schaalfactor van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/), die bepaalt hoe de grootte van het watermerk afhangt van de grootte van de bovenliggende container. |
| [sizing_type](/watermark/python-net/groupdocs.watermark/watermark/sizing_type/) | Het type grootte van het watermerk. |
| [tile_options](/watermark/python-net/groupdocs.watermark/watermark/tile_options/) | De opties om een herhaald watermerk te definiëren. |
| [vertical_alignment](/watermark/python-net/groupdocs.watermark/watermark/vertical_alignment/) | De verticale uitlijning van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [width](/watermark/python-net/groupdocs.watermark/watermark/width/) | De gewenste breedte van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [x](/watermark/python-net/groupdocs.watermark/watermark/x/) | De x-coördinaat van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
| [y](/watermark/python-net/groupdocs.watermark/watermark/y/) | De y-coördinaat van deze [`Watermark`](/watermark/python-net/groupdocs.watermark/watermark/). |
