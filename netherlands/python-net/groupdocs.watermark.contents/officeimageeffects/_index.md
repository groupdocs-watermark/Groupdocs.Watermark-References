## OfficeImageEffects class

Stelt effecten voor die kunnen worden toegepast op een afbeeldingwatermerk voor een kantoorinhoud.

Het type OfficeImageEffects bevat de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [border_line_format](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/border_line_format/) | De regelopmaakinstellingen voor de afbeeldingrand. |
| [brightness](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/brightness/) | De helderheid van de afbeelding. Moet een float zijn tussen 0.0 (donkerst) en 1.0 (helderst). De standaardwaarde is 0.5. |
| [chroma_key](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/chroma_key/) | De kleurwaarde van de afbeelding die als transparant wordt behandeld. De standaardwaarde is een volledig transparante kleur. |
| [contrast](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/contrast/) | Het contrast voor de opgegeven afbeelding. Moet een float zijn tussen 0.0 (minst contrast) en 1.0 (meest contrast). De standaardwaarde is 0.5. |
| [gray_scale](/watermark/python-net/groupdocs.watermark.contents/officeimageeffects/gray_scale/) | De eigenschap geeft aan of een afbeelding in grijstintenmodus wordt weergegeven. |
