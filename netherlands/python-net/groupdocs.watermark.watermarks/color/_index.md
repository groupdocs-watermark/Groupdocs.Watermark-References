### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [a](/watermark/python-net/groupdocs.watermark.watermarks/color/a/) | De alfa‑component van de kleur. Geldige waarden zijn 0 tot en met 255. |
| [b](/watermark/python-net/groupdocs.watermark.watermarks/color/b/) | De blauwe component van de kleur, met geldige waarden van 0 tot 255. |
| [g](/watermark/python-net/groupdocs.watermark.watermarks/color/g/) | De groene componentwaarde van de kleur. |
| [is_empty](/watermark/python-net/groupdocs.watermark.watermarks/color/is_empty/) | De eigenschap geeft aan of deze [`Color`](/watermark/python-net/groupdocs.watermark.watermarks/color/) structuur niet is geïnitialiseerd. |
| [r](/watermark/python-net/groupdocs.watermark.watermarks/color/r/) | De rode component van de kleur. Geldige waarden zijn 0 tot en met 255. |

### Voorbeeld

```python
from groupdocs.watermark.watermarks import Color, TextWatermark, Font
from groupdocs.watermark import Watermarker

with Watermarker("document.pdf") as watermarker:
    watermark = TextWatermark("CONFIDENTIAL", Font("Arial", 48))
    watermark.foreground_color = Color.red
    watermarker.add(watermark)
    watermarker.save("watermarked.pdf")
```
