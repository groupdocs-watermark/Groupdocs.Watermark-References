## __init__ {#left-right-top-bottom}

Initialiseert een nieuwe Thickness‑instantie met specifieke lengtes die op elke zijde van de rechthoek worden toegepast.

```python
def __init__(self, left, right, top, bottom):
    ...
```

| Parameter | Type | Beschrijving |
| :- | :- | :- |
| left | `float` | De dikte voor de linkerkant van de rechthoek. |
| right | `float` | De dikte voor de rechterkant van de rechthoek. |
| top | `float` | De dikte voor de bovenkant van de rechthoek. |
| bottom | `float` | De dikte voor de onderkant van de rechthoek. |

## __init__ {#uniform_length}

Initialiseert een nieuwe Thickness‑instantie met de opgegeven uniforme lengte op elke zijde.

```python
def __init__(self, uniform_length):
    ...
```

| Parameter | Type | Beschrijving |
| :- | :- | :- |
| uniform_length | `float` | De uniforme lengte die op alle vier zijden van de begrenzende rechthoek wordt toegepast. |
