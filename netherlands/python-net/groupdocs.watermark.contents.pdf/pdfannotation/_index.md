## PdfAnnotation class

Stelt een annotatie in een pdf-document voor.

Meer informatie:
- Working with annotations: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithannotations

Het PdfAnnotation-type geeft de volgende leden weer:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [annotation_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/annotation_type/) | Het type van deze [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/height/) | De hoogte van deze PdfAnnotation in punten. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/page/) | De bovenliggende pagina van deze [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/rotate_angle/) | De rotatiehoek van deze PdfAnnotation in graden. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/width/) | De breedte van deze PdfAnnotation in punten. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/x/) | De horizontale offset van deze PdfAnnotation ten opzichte van de linkerrand van de pagina in punten. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/y/) | De verticale offset van deze [`PdfAnnotation`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfannotation/) ten opzichte van de onderrand van het werkblad in punten. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | De collectie van geformatteerde tekstfragmenten van deze [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | De afbeelding van deze PdfShape. Retourneert None als het object geen afbeelding heeft. (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | De tekst van deze [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
