## PdfArtifact class

Stelt een artefact in pdf-inhoud voor.

Meer informatie:
- https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-Workingwithartifacts

Het PdfArtifact-type geeft de volgende leden weer:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [artifact_subtype](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_subtype/) | Het subtype van deze [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [artifact_type](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/artifact_type/) | Het type van deze [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/height/) | De hoogte van deze [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) in punten. |
| [opacity](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/opacity/) | De doorzichtigheid van deze [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/page/) | De bovenliggende pagina van deze [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/rotate_angle/) | De rotatiehoek van dit PdfArtifact in graden. |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/text/) | De tekst van deze [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/width/) | De breedte van deze [`PdfArtifact`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/) in punten. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/x/) | De horizontale offset van dit PdfArtifact vanaf de linkerrand van de pagina in punten. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfartifact/y/) | De verticale offset van dit PdfArtifact vanaf de onderrand van de pagina in punten. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | De collectie van geformatteerde tekstfragmenten van deze [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | De afbeelding van deze PdfShape. Retourneert None als het object geen afbeelding heeft. (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
