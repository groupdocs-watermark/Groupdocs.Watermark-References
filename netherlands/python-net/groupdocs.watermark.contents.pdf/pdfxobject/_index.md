## PdfXObject class

Stelt een XObject in een pdf-document voor.

Meer info

- Working with XObjects: https://docs.groupdocs.com/display/watermarknet/Existing+objects+in+PDF+document#ExistingobjectsinPDFdocument-WorkingwithXObjects

Het PdfXObject-type biedt de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [height](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/height/) | De hoogte van deze PdfXObject in punten. |
| [page](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/page/) | De bovenliggende pagina van deze PdfXObject. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/rotate_angle/) | De rotatiehoek van deze PdfXObject in graden. |
| [width](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/width/) | De breedte van deze [`PdfXObject`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/) in punten. |
| [x](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/x/) | De horizontale offset van deze PdfXObject vanaf de linkerrand van de pagina in punten. De x-coördinaat van deze PdfXObject. |
| [y](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfxobject/y/) | De verticale offset van deze PdfXObject vanaf de onderrand van de pagina in punten (de y-coördinaat). |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/formatted_text_fragments/) | De collectie van geformatteerde tekstfragmenten van deze [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [image](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/image/) | De afbeelding van deze PdfShape. Retourneert None als het object geen afbeelding heeft. (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
| [text](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/text/) | De tekst van deze [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/). (geërfd van [`PdfShape`](/watermark/python-net/groupdocs.watermark.contents.pdf/pdfshape/)) |
