## SpreadsheetImageFillFormat class

Stelt de instellingen voor afbeeldingsvulling in een Excel-document voor.

Het type SpreadsheetImageFillFormat exposeert de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [background_image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/background_image/) | De achtergrondafbeelding. Retourneert None als de afbeelding niet is ingesteld. |
| [tile_as_texture](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/tile_as_texture/) | De afbeelding wordt getegeld over de achtergrond wanneer True; anders wordt de afbeelding uitgerekt. |
| [transparency](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetimagefillformat/transparency/) | De transparantie van de achtergrondafbeelding als een waarde van 0,0 (ondoorzichtig) tot 1,0 (volledig transparant). |
