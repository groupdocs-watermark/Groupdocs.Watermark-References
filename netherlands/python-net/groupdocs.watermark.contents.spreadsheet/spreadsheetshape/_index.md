## SpreadsheetShape class

Stelt een tekenvorm in een Excel-document voor.

Het type SpreadsheetShape exposeert de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [alternative_text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/alternative_text/) | De beschrijvende (alternatieve) tekst die aan deze [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) is gekoppeld. |
| [auto_shape_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/auto_shape_type/) | Het automatische vormtype. |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/formatted_text_fragments/) | De collectie van opgemaakte tekstfragmenten van deze SpreadsheetShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/height/) | De hoogte van deze SpreadsheetShape in punten. |
| [hyperlink](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/hyperlink/) | De hyperlink die aan deze [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) is gekoppeld. |
| [id](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/id/) | De identificatie van deze SpreadsheetShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image/) | De afbeelding van deze SpreadsheetShape. Retourneert None als de vorm geen afbeelding heeft. |
| [image_fill_format](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/image_fill_format/) | De instellingen voor het opvullen van de afbeelding van deze SpreadsheetShape. |
| [is_word_art](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/is_word_art/) | De vorm is een WordArt-object. |
| [mso_drawing_type](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/mso_drawing_type/) | Het mso-teken type. |
| [name](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/name/) | De naam van deze SpreadsheetShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/rotate_angle/) | De rotatiehoek van deze [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/) in graden. |
| [text](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/text/) | De tekst van deze [`SpreadsheetShape`](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/). |
| [width](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/width/) | De breedte van deze SpreadsheetShape in punten. |
| [worksheet](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/worksheet/) | Het bovenliggende werkblad van deze SpreadsheetShape. |
| [x](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/x/) | De horizontale offset van deze SpreadsheetShape ten opzichte van de linkerrand van het werkblad in punten. |
| [y](/watermark/python-net/groupdocs.watermark.contents.spreadsheet/spreadsheetshape/y/) | De y-coördinaat van deze SpreadsheetShape ten opzichte van de bovenzijde van het werkblad in punten. |
