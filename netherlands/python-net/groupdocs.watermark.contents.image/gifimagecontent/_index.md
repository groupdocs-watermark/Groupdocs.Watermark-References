## GifImageContent class

Stelt een gif-afbeelding voor waarop een watermerk kan worden geplaatst.

Het type GifImageContent geeft de volgende leden weer:

| [find_images](/watermark/python-net/groupdocs.watermark.contents/contentpart/find_images/) | Zoekt afbeeldingen volgens de opgegeven zoekcriteria.
