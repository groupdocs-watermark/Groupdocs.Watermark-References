## DiagramShape class

Stelt een tekenvorm in een Visio-document voor.

Het type DiagramShape bevat de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [formatted_text_fragments](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/formatted_text_fragments/) | De collectie van geformatteerde tekstfragmenten van deze DiagramShape. |
| [height](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/height/) | De hoogte van deze DiagramShape in punten. |
| [hyperlinks](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/hyperlinks/) | De collectie van hyperlinks die aan deze [`DiagramShape`](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/) zijn gekoppeld. |
| [id](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/id/) | De identifier van deze DiagramShape. |
| [image](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/image/) | De afbeelding van deze DiagramShape. |
| [name](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/name/) | De naam van deze DiagramShape. |
| [page](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/page/) | De bovenliggende pagina van deze DiagramShape. |
| [rotate_angle](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/rotate_angle/) | De rotatiehoek van deze DiagramShape in graden. |
| [text](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/text/) | De tekst van deze DiagramShape. |
| [width](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/width/) | De breedte van deze DiagramShape in punten. |
| [x](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/x/) | De horizontale offset van deze DiagramShape vanaf de linkerrand van de pagina in punten, d.w.z. de x-coördinaat. |
| [y](/watermark/python-net/groupdocs.watermark.contents.diagram/diagramshape/y/) | De verticale offset van deze DiagramShape vanaf de onderrand van de pagina in punten. |
