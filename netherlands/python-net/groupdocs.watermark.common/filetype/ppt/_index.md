## PPT field

Een bestand met de extensie PPT vertegenwoordigt een PowerPoint‑bestand dat bestaat uit een verzameling dia's voor weergave als diavoorstelling. Het specificeert het Binary File Format dat wordt gebruikt door Microsoft PowerPoint 97-2003. Leer hier meer over dit bestandsformaat.
